The first after drive on this round's code had R1 without "Open in integrated browser": a new thread's draft has no
thread id until something allocates one, so the menu saw no thread. The reference's draft has its thread ref from the
start; the menu now counts a draft as a thread and allocates its id when the Browser opens (as addBrowserSurface does).
