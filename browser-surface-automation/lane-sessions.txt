Lane: ports 16750 (the app's embedded server) and 16751 (a fixture page server: /form, /b, /media). The lane has its own
HOME, CODEX_HOME, CLAUDE_CONFIG_DIR, XDG_*, T3_LOCAL_HOME and T3CODE_TELEMETRY_ENABLED=false. Its server has one ACP
Registry provider instance, "Lane browser agent", whose command is a lane-only fake ACP agent. For a prompt
"e2e <url>", that agent calls the server's preview MCP tools in order (status, open, status, snapshot, click, type,
press, wait_for, evaluate, scroll, set_appearance dark, evaluate, set_appearance system, resize fill, resize freeform,
navigate, snapshot, recording_start, recording_stop, navigate /media, evaluate play). It writes each result to a
JSONL file and replies with a summary that contains a Markdown link. App driven by scripts/agent.mjs macos
(agent mode, 1280x840); the build is this branch at 7fa518900 (45b857d3c after it adds only a test).
