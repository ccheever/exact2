**The Vello canvas keeps every decoded image** (2026-10-04, Blitz's crash). Dioxus Native's default renderer (vello_hybrid 0.0.9) panics with `AtlasLimitReached` after about 9,000 pt of a feed of 104 distinct photos. `canvas/vello/src/lib.rs`'s `images()` map holds every decoded image by the host's handle and nothing evicts it except `ecg_trim` (a memory warning on Apple). Whether `exact-vello`'s atlas behind it is bounded is untested. Drive a Canvas 2D surface through a few hundred distinct images and watch memory and errors.
