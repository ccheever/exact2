**Standing rule: a new optional web capability links by use** (2026-09-28, Charlie's ruling (a) on the web cores' growth). A feature an app may not use — a device request, a host command, a style or prop family — reaches the web core only through what the generated entry links (`Linked` / `HostLinks` / `RunnerLinks` / `DeviceLinks`), detected at build from the plan (`exact_runner::uses`: its rows, tags and `Command`s) or, for a data module's requests, from the bake's grant ceiling; a plan that uses it unlinked is refused at boot by name. The gate (since 2026-10-02, Charlie: gate what ships) is `metrics.mjs --long`'s app.js budgets, the JS target each app ships (Caltrain 19, RealWorld 30, video-player 9 KiB brotli-11); the wasm cores (what games, conformance and fixtures build) keep reported reference numbers (310 / 304 / 249 KiB) that print "over" and are not filed. Smaller is still better for both, so a lane measures its app cores and app.js before and after and says the difference in its commit. Precedents: Canvas 2D stage 2, `format`, `materials`, `backdrop`, `auth`, `share`, `documents`, `picker`, `text_transform`, `effects` (filter, clip-path), `animations`, `gradients`. Numbers in core crates read and print through `exact-num`, never `str::parse::<f64>` or `{}` of a float: either one brings back core's tables (~12 KiB and ~4.5 KiB).
