**A hardware keyboard on a headless simulator** (2026-09-26). This Xcode has no Simulator.app, so a simulator has no hardware keyboard and UIKit's focus system never starts. One HID keyboard event from SimulatorKit's `SimDeviceLegacyHIDClient` (`IndigoHIDMessageForKeyboardArbitrary`) attaches one for the rest of the boot, which is how perf/slow-frame reproduced the iPad's focus-search cost; the keys themselves did not reach the app, so a real Tab walk still needs a device or Simulator.app.
