**Native Markdown undo boundaries** (2026-09-22; [LLP 1045 D5](../llp/1045-markdown-editor.rfc.md)): UIKit must retain its specialized per-editor undo manager; source undo/redo across natural run-loop turns and independent histories are verified with it. Still owed on native: a source replacement and formatting command in one automatic event group can undo together, skipping the intermediate source. Three bounded automatic-group repairs did not establish a safe boundary; the final attempt was reverted after scheduled run-loop closure exceptions on both platforms. Preserve native grouping semantics; the one-command-one-undo requirement remains incomplete. Physical phone input and intrinsic editor sizing remain unproven.
