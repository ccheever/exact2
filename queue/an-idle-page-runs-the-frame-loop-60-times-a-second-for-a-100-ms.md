**An idle page runs the frame loop 60 times a second for a 100 ms timer** (2026-09-24, the activation lane). RealWorld's `every(100, settle)` falls inside timer-glue's 133 ms frame window (LLP 1043), so an idle page keeps `requestAnimationFrame` going forever. At 4× CPU that's about 35 ms of main thread per second, against React's none. Sleeping until one frame before the due time cut it to 30/s, with no latency change on the bench (a 3-second read: 252 against 249 ms). An interval longer than a few frames should wake only when due. This is for the app's settle poll or the clock rule's owner.
