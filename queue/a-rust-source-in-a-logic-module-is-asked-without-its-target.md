**A Rust source in a logic module is asked without its `Target`** (files F22, 2026-10-04, read in `logic/abi`, not reproduced). The ABI's ops 3/4 call `answer`/`parse`, whose defaults drop to `query` (the bake placeholder); in process (`Mixed`, `Storage`) the runner calls `answer_for`/`parse_for`. A source that parks a call by `Target` therefore answers its placeholder, silently, on the JS web target only. Carry the target across the ABI (both hosts' encoders, an ABI version), or refuse at load a module whose source overrides `answer_for` and not `answer`. No longer needed for `doc:` paths, which TypeScript reaches now (F2).
