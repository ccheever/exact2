**Agent-mode storage differs between the Linux host and the page** (2026-09-29, found by `conform.mjs --linux`, LLP 1071 §7). With no `--storage`, the web page refuses app storage in agent mode (`host/web/storage-environment.js`), so Messages' `savedComposer`, `chat` and `change` requests fail there and opening a thread writes nothing. On the Linux host the same drive's data sources store and answer (the thread is marked read, the draft thread is saved). A drive should get the same storage on every host; until it does, the Linux comparison of Messages stops at its first tap (`LINUX_APART`).
