**What LLP 1074 left** (2026-09-30, lane/taffy-css). (1) A height `aspect-ratio` derives is a floor, not a definite height: under a block or grid parent a child's `height: 100%` is `auto` where Chrome resolves it against the ratio's height (`min-height: 0` on the box is the way round it). The fix is two passes at the parent: measure the content, and give the box the ratio's height as definite when the content fits. Five cases in `kernel/tests/it/browser_position.rs` (`OWED`) fail the day it lands. (2) The automatic minimum of a width derived from a height. (3) An exclusion (`wrap-flow: both`) under a static parent is placed against a box further up and wraps nothing; the compiler could say so (`wrap-flow: both` needs a positioned parent) where today the text is only refused auto height. (4) Apps outside the repo (Weird Castle, Interview) are not swept for `position: static`: the parent of each absolute box, and each box with an inset and no position, needs `position: relative`. (5) The one deviation left, that a clipping box is a containing block, goes only when native hosts paint by stacking context and re-parent a positioned view to its containing block (LLP 1074 §7); `position: fixed` waits on the same. (6) Patches 10, 11, 12, 14, 17, 18 and 20 are marked to upstream and none has been sent. (7) The schema's alignment enums lack `start`/`end`/`self-start`/`self-end`, which Taffy has (LLP 1074 §5).
