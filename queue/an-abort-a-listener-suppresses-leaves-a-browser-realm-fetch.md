**An abort a listener suppresses leaves a browser-realm fetch pending until its reply** (2026-10-04, both families' round-5 reviews of the app-diary fixes, 4a8). Hermes watches a fetch's signal through Ibex's abort hooks; the wasm target's browser module realm loads prelude.js alone, so `watchAbort` is an `addEventListener` an earlier `stopImmediatePropagation` skips, and the fetch rejects only when its reply lands (fulfill rechecks `signal.aborted`). The default web build (the JS target) uses the browser's own fetch and is unaffected.
