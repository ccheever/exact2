**The expression VM costs about 6 ns an instruction** (2026-09-27, feat/contract-listmap). A crypto row's `points` is about 60 instructions and four string allocations a point: 23 us for 48 points, five times Rust's `format!`. Each instruction is decoded from bytes through the operand table (`vm::decode`), and a template's `+` allocates per part. A pre-decoded instruction array per code body, or an n-ary concatenation for templates, are the levers; measure on the crypto fling (row mounts) before building either.
