**Web first render, where it goes** (2026-09-29, F1–F5 on Chrome, localhost): HTML, `glue.js`, `navigation.js` and the preloaded `app.wasm` arrive by ~9 ms; streaming compile ends ~9 ms (Liftoff), but the boot task pays ~10 ms of lazy per-function compilation on first calls; the boot itself (plan decode, the component, the kernel's tree, the first batch, the DOM) is 22 ms for F4 and ~37 ms more for F1's 1,203-element SVG. F4's content then waits for the app's own first 16 ms tick. Nothing cheap was left: V8's compile hints (explicit eager compilation) would cut the lazy compile if they leave the flag. (Measured on the wasm target, now internal and for games: the JS target ships an app as one `app.js`, RealWorld's ~24 KB brotli. Re-measure on the JS target before acting.)
