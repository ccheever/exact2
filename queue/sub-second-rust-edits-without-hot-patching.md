**Sub-second Rust edits without hot-patching** (2026-10-05, [LLP 1029.000.001](../llp/1029.000.001-sub-second-rust-edits.rfc.md), Draft, awaiting Charlie). A one-line data-crate edit costs 2.3–3.2 s on the JS target's dev loop and 1.6–2.0 s with live replacement on native; the crate compiles in 0.13–0.55 s ([LLP 1029.000.000](../llp/1029.000.000-hot-patching-rust-measured.research.md)). The RFC builds the dev module in `logic-dev`, swaps the module in the page for a Rust-only edit, and builds only the variants connected clients run, in parallel; Subsecond-style function patching was weighed and declined.
