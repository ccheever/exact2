**A minimal iOS embed weighs 4.1–4.7 MB with every compiler lever pulled, not 1** (2026-09-30, measured: a one-text-node plan over `exact_apple::host!` with an empty data source, linked into a UIKit `main.swift` against a 73 KB UIKit floor, arm64 iPhone, `-dead_strip`, `strip`; harness and link maps in `~/bench/embedsize`, outside the repo). Today's shapes: the production profile (`release`: opt-level 3, thin LTO; `swift build -c release`) is 7.23 MB over the floor; a real app's `apple-dev` archive (Type Tour's) 8.45, of which wasmi 1.0 MB, linked into every app through `exact_logic::configured!` for the swappable data module (LLP 1029.000) whether or not the app swaps one, the app's data and plan 0.7, the kernel 1.33 unoptimized for size. The ladder on the probe: opt-level z + thin LTO 5.66 → fat LTO 5.42 → Swift `-Osize` 4.92 → `-Xfrontend -internalize-at-link -enforce-exclusivity=unchecked` 4.65 (the export penalty vanishes with it: ordinary exports cost 1.2 MB before, 5 KB after) → nightly `-Zbuild-std=std,panic_abort` with `optimize_for_size` 4.34 → `-Cpanic=immediate-abort` 4.22 (the backtrace machinery was 161 KB) → `-Zlocation-detail=none -Zfmt-debug=none` 4.21 → `-Xfrontend -disable-reflection-metadata` 4.09 (not free: `String(describing:)` of an enum then prints its type name, `State`, not its case, `ready`; the sample hosts and the agent print states that way). opt-level s in place of z costs +0.8–0.9 MB. What the 4.09 holds: ExactKit 1.98 MB (core presenter files ~0.8; Canvas, SVG, GPU, video, web, native modules, pickers, collections, navigation, menus, modals, swipe ~0.7; generic specializations and metadata ~0.2), Rust 1.75 (taffy 222 KB of which grid 161; runner 221; kernel 220; exact_apple 145; core, alloc and std 280; motion 30; markdown 28; plan 28; textflow and unicode-linebreak 41; url, idna and ibex2 46; route 11; raster and canvas 14), linker-synthesized stubs and unwind 0.14. The stable flags-only build (fat LTO, z, `-Osize -internalize-at-link`) boots and paints on the iPhone 17 Pro simulator; the nightly one is checked below it. Why 1 MB is out of reach without a different design: the feature code is linked by dispatch, not by use (every op handler is reachable from `Presenter.apply` and `NodeView`; every kernel row's grammar from the plan decoder), so removing it means separate artifacts a consumer links (CLAUDE.md's rule), and the core beneath — Swift ~1.0 MB, Rust ~1.3 — is still 2–3× the budget. Owed: (1) `ExactView.fit()` on iOS recurses without bound when the initial boot is refused (boot → `fit()` → `!booted` → boot …; a SIGSEGV in the stack guard, seen with a compat JSON whose store level did not match the linked adapter), where LLP 1031 D8 promises a contained failure; (2) whether `-Osize` and opt-level z cost frames on the iPad benchmarks, before either becomes the iOS production profile; (3) wasmi as a separate artifact for an app whose manifest names no swappable module.
