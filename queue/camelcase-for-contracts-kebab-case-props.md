**CamelCase for Contract's kebab-case props** (2026-10-03, [LLP 1081](../llp/1081-names-exact-invents.rfc.md) Q6). `scroll-start`, `scroll-restoration`, `initial-item-count` and `bitmap-width`/`bitmap-height` look like CSS properties and are props; camelCase, Contract's spelling for its own props, would make a kebab-case name always mean CSS or an HTML attribute.
