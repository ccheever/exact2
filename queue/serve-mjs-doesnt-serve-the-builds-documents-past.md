**`serve.mjs` doesn't serve the build's documents past `/`** (2026-09-23, render lane): `dist/404.html`, `sitemap.xml`, `robots.txt`, `shell.html` and `<location>/index.html` (from `pages=`) aren't in its `PUBLIC_FILES`, and its fallback answers any app path with `/index.html`, now `/`'s document; so a static origin serves a listed page's URL, or an unknown one, `/`'s page (200), which the runtime then replaces. LLP 1048.000 D7 says a static host serves these files as they are; the render server does.
