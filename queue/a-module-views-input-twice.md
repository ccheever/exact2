**A module view's input, twice** (2026-10-02, astra's delta review of the hooks' fixes). On both web targets a module view hears the page's own input as any element does (glue.js `attach`; rt.js `on` since e0ee5759f) and its module's reports (`event(code)`): a module whose own button reports `event(0)` for a click the page also sees delivers one press twice, and focus, blur and keys likewise.
