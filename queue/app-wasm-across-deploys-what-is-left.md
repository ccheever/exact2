**`app.wasm` across deploys, what is left** (2026-09-26, `6e0b8874`; [LLP 1047.000 §9](../llp/1047.000-staged-loading-by-capability.rfc.md)). A returning reader now gets the next build as a delta (9.5 KB against 238.6 after an app edit) when the render server runs with `--generations`, which only the bench passes: hosting should. A page left open across a deploy still loads the new build and can skew against its checkpoint; the server keeps the earlier builds now, so it could serve each at its own `?v=` (LLP 1048.000 D10's "kept for pages still open"). The stage files are named by content but go `no-cache`; `immutable` would drop their revalidation.
