**The JS target's data seam caps an answer at 16 MiB** (2026-10-04, LLP 1090 conformance). `rust-data.js` goes through the logic ABI, whose `MAX_MESSAGE` is `MAX_HOST_WORK_BYTES`; the runner's in-process data source has no cap, so an answer between 16 MiB and the runner's value bounds loads on wasm, native and Linux and fails on the JS target (docs/agent-pitfalls.md). Either bound answers alike on every host or let the JS seam carry what the runner does.
