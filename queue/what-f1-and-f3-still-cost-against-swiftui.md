**What F1 and F3 still cost against SwiftUI** (2026-09-29, M1 iPad Pro, LLP 1055.000 §0 "F1 and F3, the second round"). F3: the app's CPU 413 ms/s (120) and peak memory 145 MB (24), at 120 fps and main thread 73 (84). SwiftUI's filters run in the render server; ours render the sub-scene with `CARenderer` in process (its CPU scan converter fills the shapes, ~50 ms/s), submit two command buffers a frame (~95 ms/s in the driver) and keep the target, two working textures and four surfaces (~80 MB of GPU memory). A picture drawn only when something in it moves (the orbit's rate, not the display's) or a render-server path (a `CAFilter`-free chain in a `CALayer` the server composites) would close it. F1: launch lifetime peak 121 MB (99–116) and steady 88 (49), measured while the vignette was a mask island (23 MB); it is a gradient layer now (first ink below), memory not re-measured.
