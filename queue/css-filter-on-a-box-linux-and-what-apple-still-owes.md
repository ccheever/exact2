**CSS `filter` on a box, Linux and what Apple still owes** (2026-09-29, LLP 1055.000 §0 "CSS `filter` on a box"). Linux draws a filtered box unfiltered; `fx-box-filter` is declared unsupported there (`scripts/svgparity.mjs`). Linux can reuse its island painter (`paint/island.rs`) over the box's subtree. On Apple the picture is redrawn after each batch, so what changes a box without a batch (an image decode landing, a text raster painted later, a video frame) shows at the next batch; a `url()` filter on a box is not taken; the picture is drawn on the main thread at the box's full region (the live SVG path's off-main drawing would suit an animated one). On macOS the picture is `CALayer.render(in:)` of the box, which ignores `maskedCorners`: a filtered box with some corners rounded and others square (a layer-property box, `BoxLayerMac.swift`) is pictured with all its corners rounded; one radius on every corner is exact.
