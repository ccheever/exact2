**`exact release` signs a Mac app with the hardened runtime and no entitlements** (2026-09-27, found writing LLP 1069.008). `scripts/exact.mjs` runs `codesign --options runtime` with no `--entitlements`, so a notarised build that uses the microphone (grnl, through its Swift module) lacks `com.apple.security.device.audio-input` and gets no audio. Development builds aren't hardened, which is why nobody has seen it. LLP 1069.008 derives the entitlements from grants; a hand-written entitlements file for grnl would do until then.
