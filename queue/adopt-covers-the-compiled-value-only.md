**`adopt` covers the compiled value only** (2026-09-26, perf/adopt, LLP 1027 D11). A value carried across a reload, a kept store-reader answer or a document's seed is not adopted, and the TypeScript executor and a worker-placed source ignore it (their values cross as copies). A source that edits what it answers still rebuilds its data after a dev reload (the heavy-list port parses its JSON on first edit then). Extend it when a consumer shows the cost. The heavy-list port also still bundles its 7 MB messages.json into the device binary for the bake's sake; untouched, those pages are clean and not charged to the footprint.
