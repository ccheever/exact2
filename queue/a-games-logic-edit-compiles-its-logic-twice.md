**A game's logic edit compiles its logic twice** (2026-10-05, the garden edit-loop lane). The generated GPU crate's build script build-depends on the logic crate to write `.shells/surfaces.json` and bake the level, so each gameplay edit compiles the logic for the host as well as for wasm, relinks the build script (with the art baker's encoders) and runs it, all before the GPU crate may compile. Measured on Garden with the art re-encode already skipped: 3.9 CPU-s of Cargo per one-line edit, 2.6 without that build-dependency (a hand-edited shell, five runs each, under load 170–210), and the host chain is the critical path. Removing it means another producer for the declaration and the level in every bake (web, Apple, Linux, proofs) and in the dev loop on an `Args` edit (README: "Rust argument edits reach that declaration through the next GPU build"); a design change, not a profile one.
