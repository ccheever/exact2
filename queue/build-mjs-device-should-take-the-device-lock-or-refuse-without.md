**`build.mjs --device` should take the device lock, or refuse without one** (2026-09-29, the canvas GPU bake-off). It installs onto the phone as its last step, so a build started while another lane held the phone replaced that lane's installed app mid-run (the bake-off did this once). `--archive` (with `EXACT_IDENTITY` and `EXACT_PROFILE`) builds the same signed bundle without installing, and device scripts install it under the lock (`~/bench/canvasbake/dev.sh`). Proposal: `--device` takes `~/bench/devlock.sh`'s queue for the install (not the build), or refuses when `EXACT_DEVICE_LOCK` is unset and names `--archive`; the lock script is outside the repo, so the second is the smaller change.
