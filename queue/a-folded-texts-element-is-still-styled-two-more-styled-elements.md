**A folded text's element is still styled: two more styled elements a grid row than Solid's** (2026-10-02, LLP 1007.001 §5). A lone plain text is its box's content now (`display: contents`, the box a block), so the grid's layout tree is Solid's size (create 10,000: 220,022 against 220,033 layout nodes), but its element stays and is style-recalculated: 170,003 against 150,003 elements. Dropping the element too means the JS runtime writes a folded text's string into its parent, the agent's tree reads the node from the plan rather than an element, and the region anchors around it move; measure what the 20,000 recalculations cost first (create 10,000, mobile: style 354 against Solid's 289 ms).
