**Large wheel deltas scroll by different amounts in Chrome and Firefox** (2026-10-02, cross-browser conformance): RealWorld's single 1,400 px wheel step moves Chrome 930 px and Firefox 862 px even though both receive trusted wheel input at the same visible point. CSS does not define wheel-delta normalization, so neither engine is wrong; use smaller phased steps or define carrier normalization before treating intermediate scroll coordinates as cross-browser layout parity.
