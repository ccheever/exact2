**`contract types`' `Sources` demands the Rust half's sources from `app.ts`** (files F21, 2026-10-04). In a mixed app the generated `Sources` names every source, so the TypeScript half writes `Omit<Sources, …>` by hand. The composition that knows which sources are Rust's (`RUST_SOURCES`, `build_mixed_with`) is Rust code; `app.json` could name them, or the bake could emit a `TypeScriptSources` type from the composer it already runs.
