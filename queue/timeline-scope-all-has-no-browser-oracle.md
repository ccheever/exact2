**`timeline-scope: all` has no browser oracle** (2026-09-28, LLP 1057.003 phase 3). Chrome 154 drops the declaration (`CSS.supports('timeline-scope', 'all')` is false), so the kernel and the glue follow the specification's text, and the web's own CSS carries no `all`: phase 4's scroll timelines, which the browser resolves, would not see one. Recheck Chrome (and Safari) before phase 4, or refuse `all` until one parses it. The lookup's other 23 cases are Chrome's answers recorded in `kernel/tests/it/timeline_scope.rs` from a scratch page; `parity.html` rendering those trees with scroll timelines would make them a fixture.
