**Hosts outside the repository** (2026-10-03, Charlie: "out-of-tree is for like Amazon's new TV operating system thing"; `rules/DEFERRED.md` §Surfaces). An RFC beside LLP 1036.001 (apps outside the repository): what a host with its own UI stack consumes from exact2 (the plan and kernel wire, the runner, the agent protocol), and what exact2 would have to publish for it (a stable host ABI, `host/web-js/conform.mjs` runnable outside this repository, drivers that do not assume `host/*`). Amazon's Vega OS is the motivating case; first find out what native surface its SDK gives an app.
