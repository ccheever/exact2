**Shared ExactKit test classes never run on iOS** (2026-10-05, the Brooks port's feedback). `build.mjs --test --ios` runs only classes named `*IOSTests`, so a shared class with `#if os(iOS)` branches, such as `SurfaceControlTests`, is compiled for iOS and never run there: its `testContactIdentityIncludesCanvasAndReleaseRequest` failed on iOS until the macOS `!isSurfaceControl` blur guard was copied over, and no gate saw it. Run the shared classes on iOS too, fixing or marking what fails there. On a1ead713c, an iPhone 17 simulator (iOS 26.5) also failed nine assertions in `GroupedListIOSTests` (expects a 300×600 window, gets 402×874), `NavigationCollapseIOSTests` and `NavigationTabsIOSTests`, which an iPhone Duo (iOS 27) passed: the suite should pin its simulator or stop depending on it.
