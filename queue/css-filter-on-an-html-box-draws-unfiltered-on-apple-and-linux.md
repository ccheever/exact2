**CSS `filter` on an HTML box draws unfiltered on Apple and Linux** (2026-09-29, found by `~/bench/features` F3; an SVG `g`'s works everywhere). The kernel accepts the row on any node and only the web lowers it for a box; the native hosts ignore it without a word. Implementing it on Apple means rendering the box's subtree (`CALayer.render(in:)`, as an SVG island does) into the filter region, running `exact-svg-raster`'s chain over it (the kernel's `Resolver::filter` over the border box) and showing that in its place, re-rendered whenever anything under the box changes or animates, with hit testing left on the real views. Until then, at least say so once, as iOS does for `mix-blend-mode`. Charlie's call between building it and refusing it on those hosts.
