**A stream that can send: Supabase Realtime and Convex without polling** (2026-10-05, Depot feedback: an equipment-lending app built on Snapback4, Convex and Supabase polled on all three). `fetch(url, { exactStream })` reads SSE and a receive-only WebSocket (`docs/reference.md`, "An answer that keeps coming"), so a feed that waits for a subscribe frame (Phoenix's join, Convex's sync protocol) cannot be read. An RFC: frames sent on open, then app-to-socket sends tied to the resource's arguments, under `net.websocket`, on Hermes, the wasm web host and the JS target alike; Supabase and Convex as the proof.
