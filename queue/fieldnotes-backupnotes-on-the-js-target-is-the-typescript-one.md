**Fieldnotes' `backupNotes` on the JS target is the TypeScript one** (2026-09-29, LLP 1071 §7 "Files and storage"). The wasm target's Rust source owns it (`RUST_SOURCES`, `build_mixed_with`); the JS build takes a Rust module only from `rust.module` or a `contract::bake` web build script, so a `build_mixed_with` app without `rust.module` gets no Rust module and its TypeScript answers. A generated module over the app's composed Rust source would carry it.
