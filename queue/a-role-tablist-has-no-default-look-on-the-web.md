**A `role="tablist"` has no default look on the web** (2026-10-05, authoring bench iOS round 15, t1-tip): on iOS it is a `UISegmentedControl`; on the web its tabs are bare run-on labels ("15%18%20%25%") until styled, and the styling's track then shows as a rim around the native control on iOS. A web default for a segmented tablist, or a way to style only the web's, would let one view serve both.
