**Per-corner radii as a shape mask, not a CPU draw** (2026-10-02, Signal Clone). A box whose four corner radii differ (a chat bubble's 18/4 pt cluster corners) sets `boxDrawn` and paints its fill in `draw(_:)`, one CPU backing store per bubble, redrawn on every size change. Signal-iOS uses a solid colour or gradient view masked by a `CAShapeLayer` path (implicit animations off). `BoxLayerIOS` could do the same: layer background plus a shape-layer mask for non-uniform radii.
