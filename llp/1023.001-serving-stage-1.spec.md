## 1. The envelope

Emitted by `host/web/build.mjs` as `dist/exact.json` (static form) and
served live by `dev.mjs` at `/exact.json`:

```json
{ "exact": 1,
  "app":  { "name": "<resolveApp name>" },
  "plan": { "url": "./app.plan", "sha256": "<64 lowercase hex>",
            "bytes": 44799, "formatVersion": 1,
            "kernelSchema": "<16 hex>" },
  "seq": 3, "events": "./__dev" }
```

- `seq` and `events` are the live tier only; **their absence is the static
  signal** — a client boots once and does not subscribe.
- `plan.sha256` is payload integrity: full SHA-256 of the plan bytes,
  verified before decode by every client. `formatVersion` and
  `kernelSchema` are read out of the plan bytes at the generated header's
  fixed offsets — 4-byte magic, LE u32 version at 4, LE u64 format digest
  at 8, LE u64 kernel schema at 16 (plan/build.rs's encoder; the Node side
  cites, never re-derives).
- `app.id` waits for Stage 2's header identity. Unknown fields are
  ignored; an `exact` major other than 1 is refused with "rebuild the
  native host."
- MIME: `application/vnd.exact.envelope+json` from both servers;
  `application/vnd.exact.plan` for the plan.
- The discovery link, injected into `dist/index.html` at build time,
  before the glue script:
  `<link rel="alternate" type="application/vnd.exact.envelope+json"
  href="./exact.json">` — HTML's own other-representation spelling; the
  link is the contract, the filename a convention clients never derive.

## 2. The loader (all native hosts)

1. GET the app URL with
   `Accept: application/vnd.exact.envelope+json, text/html;q=0.9` — sent
   from day one; no server branches on it yet (Stage 2).
2. A JSON body is the envelope. An HTML body gets a **bounded parser-free
   scan of the first 16 KB** for the link (find the MIME type, back up to
   `<link`, forward to `>`, take `href`, `&amp;` unescaped); native never
   runs an HTML parser and never executes the page.
3. Envelope gates, in order: `exact` major = 1; a `plan` object with
   `url`/`sha256`/`bytes`; every referenced URL **same host:port as the
   page** (v1's same-origin rule). Apple resolves relative URLs against
   the final post-redirect response URL; Linux follows no redirects in v1
   and says so in its error.
4. Fetch the plan; refuse on byte-count mismatch, then on SHA-256
   mismatch — each refusal names the numbers and **keeps the running app**
   (Apple) or boots the baked plan with the reason on stderr (Linux,
   one-shot).
5. Boot through the host's existing dev-reload path, state carried.

## 3. The events protocol (Apple, live tier)

- `/__dev` opens with `{"hello":true,"seq":N,"digest":"<sha256>"}` before
  the client is added to the push set; every `{seq}` push carries
  `digest`. A client compares against what it booted and re-resolves on
  mismatch — the fetch-then-subscribe race and the reconnect catch-up are
  the same comparison. `dev.js` (the browser side) skips `hello`.
- `{rebuilt}` is **session-terminal**: the program changed; the client
  keeps the last good app, prints "rebuild the native host," cancels the
  stream, and re-fetches nothing until the menu's Reload. Held through a
  second rebuild in verification.
- `{error}` is surfaced and the app keeps running. Reconnect backs off
  1 s → 5 s; a whitespace edit (same plan bytes, new seq) boots nothing —
  the digest guard.

## 4. The locators and the menu

- `EXACT_DEV_PLAN` (and on Linux `EXACT_PLAN`) accept `http(s)://` —
  the same variable, no third name. A URL means the envelope flow; a path
  means the existing mtime poll (Apple) or file read.
  `host/apple/build.mjs --run` honors a caller-set `EXACT_DEV_PLAN` for
  macOS and the simulator (`SIMCTL_CHILD_*`); a device launch still
  carries no environment.
- The dev menu grows **Open Project…** (⌘O on macOS; the iOS sheet, URL
  keyboard), seeded from defaults key `exact.dev.url`; Connect opens the
  URL through the shared loader. Reload delegates to a live URL session
  and clears a terminal stop. App Info names the URL and its state.
- The iOS dev plist carries `NSAllowsLocalNetworking` +
  `NSLocalNetworkUsageDescription` — the dev client only.

## 5. The bind

`dev.mjs` and `serve.mjs` bind `0.0.0.0` by default; `--loopback` /
`EXACT_LOOPBACK=1` restores `127.0.0.1`. The printout lists loopback plus
every non-internal IPv4, private-range first, never silently picking one.
Hardened with the exposure: GET/HEAD only; containment is
`startsWith(dist + '/')` (the sibling-prefix hole closed); a directory GET
is a 404, not the uncaught EISDIR that used to kill the process; `.json`
and `.plan` join the MIME map. The agent carrier is untouched and never on
the LAN: stdio, the Unix socket, and `scripts/agent.mjs`'s 127.0.0.1
server.
