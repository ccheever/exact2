## Stream ownership

[decided] App-local T3MobileTerminalSessions and T3MobileTerminalOutput include the existing887b249 desktop session/buffer implementation with mobile type names. They use the existing T3Transport terminal attach/write/resize/detach protocol. Output stays native, acknowledgements occur after buffering, retained sessions replay their bounded buffer and resize uses the existing latest-wins queue.

[decided] The mobile adaptation gates attachment by the actual connected environment descriptor. Read-only attachment sends only threadId and terminalId; operating attachment includes the actual workspace/grid/environment. Permission checks come from the real auth session. Retained sessions from a previous focused environment are discarded before reconnect. The view queues writes in source-faithful65536 UTF16-unit chunks without splitting surrogate pairs and owns one-shot modifiers and explicit clipboard paste on the main thread. No synthetic terminal output is generated.

[observed] The parent and terminal implementer typechecked the mobile Swift sources with actual Ghostty headers. The module now registers t3-mobile-terminal and dispatches terminalRetain, mobileTerminalPermissions and mobileTerminalControl. Native ownership remains in the module, never a retained TypeScript native handle. Device behavior remains unverified.

## Root seam

[observed] terminal-mobile.ts exposes mobileTerminalPrepare(requestedId,scheme,palette,fontSize,now,native,client) and mobileTerminalAction(action,terminalId,value,native,files,client). Preparation reads real permissions and shared terminal metadata, then returns a strict snapshot plus a credential-free terminal-source JSON. Actions use real terminal RPCs or the app-owned mobileTerminalControl bridge. New/close update shared UI ownership only after RPC success. Persistence uses the existing native file seam.

[observed] Snapshot fields are revision, environmentId, threadId, terminalId, sessionKey, title, subtitle, ready, readOnly, sourceJSON, error, emptyTitle, emptyDetail, tabs, hostPlatform and colors. Native change events identify their session key and carry status, error, modifier or captured visible text. Continuous output bytes never enter the TypeScript inbox; explicit visible-output capture returns its frozen text for user selection.

## Permissions, controls and captured output

[decided] Preparation reads the auth session and caches authorization for the captured connection/thread owner before attachment. Input does not issue a fresh auth HTTP read per keystroke; native connection transitions and server enforcement continue to gate it. Downgrading to read-only detaches the old operating subscription, attaches with the smaller read-only payload, clears queued writes/modifiers and removes the keyboard accessory. Revoking read drops the native session and displayed buffer. Disconnect invalidates stream generations, write permission and remembered authorization. Reconnect waits for fresh authorization. The runtime keeps using the existing transport protocol and its server enforcement.

[observed] The UIKit input accessory contains the pinned ESC, host-specific modifier, TAB, paste, clear, arrow and punctuation actions. Its fixed dismiss button remains outside horizontal scrolling. Paste reads the device clipboard only on explicit input and sanitizes source-disallowed control bytes. Font size comes from unified mobile preferences; menu changes persist through that existing owner, with source6–14 bounds and0.5 steps. Known-session menu entries use actual metadata and filter closed sessions except the current one. Real stream exit selects a remaining live session or returns to the conversation.

[decided] The capture sheet freezes the native viewport text. Two line taps choose a range, with source64,000-character and200-context limits. The adapter allocates a real native UUID, rechecks environment/thread/draft ownership after that await, saves through the shared terminal context helper and applies the shared composer draft reducer synchronously. It uses the shared context URI and record format; no native editorInsert fallback or duplicate composer reducer is introduced. Source line numbers are relative to the frozen viewport. Blank output is refused.
