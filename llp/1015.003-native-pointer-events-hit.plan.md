# LLP 1015.003 — Native pointer-events:none hits

Status: implemented and qualified on the shared native Presenter. Implementer: Codex Windows owner,
2026-10-04. Encountered while qualifying LLP 1015.002; user authorized reviewed
engine papercut fixes. This adds no working-set entry or blocking gate.

## Evidence

Both existing schema metadata and native computed style correctly inherit
`PointerEvents::None`. Actual Chrome reports `elementFromPoint(25,15)` as the
canvas behind a 100×30 HUD with `pointer-events:none`, with or without an
unspecified child. Its computed parent and child values are both `none`.

The native simple HUD has computed `PointerEvents::None`, yet `Presenter::hit`
returns that HUD. The existing predicate checks containment, route visibility
and display permission but never this generic style. SVG shapes already use
pointer-events in their own hit implementation. Thus a simple overlay blocks
native wheel qualification too; the failure is not confined to inheritance.
The two retained regression tests fail explicitly. Wheel delivery must not skip
a real hit as a special workaround.

## Proposed correction

Apply the existing inherited computed `pointer_events` to the common native
box hit predicate: skip only `None`, alongside its existing geometry, clips,
inert/visibility and display checks. Do not prune a subtree: a child explicitly
setting `auto` can re-enable its own hit even under a `none` parent. Preserve SVG
shape-specific vocabulary and existing paint/inspection geometry. Do not add
schema rows, caches, wrapper rules or change keyboard focus/activation semantics.

Qualify simple and inherited-none overlays, an explicit-auto child that still
blocks/scrolls, and unchanged canvas/ordinary-control hits with no such style.
Keep the full existing native pointer/scroll/gesture regression set, and the
actual Chrome fixture as the semantic oracle. Re-run the real Skirmish native
and browser zoom/overlay drive. Native AppKit is not this Presenter and is not
claimed fixed by this slice; Windows and the shared Linux Presenter are.

The parent approved one bounded diagnostic round after the initial fixture
compilation repairs; that round established this independent hit-test defect.
Parent separately approved implementation, 2026-10-04, with explicit SVG
root-none/child-auto coverage. Resolve the SVG scene first: its shape-specific
hit remains authoritative, including use-instance styles. Apply the generic
none filter only to an ordinary box or the SVG root's fallback box. A root-none
must not discard an explicitly re-enabled SVG child.

Qualification boundary: generic CSS `visibility:hidden` was separately observed
to remain painted/hittable on this shared host. Its existing route visibility
handles route hiding and authored inert, not that CSS row (SVG handles its own
visibility). This slice tests actual `display:none` and inert refusal and makes
no claim to fix generic visibility painting/hits. The original inherited-none
and simple-none regressions remain enabled; none are skipped to make the gate pass.

Additional review, before changing the paint seam: parent approved capturing one
generic hit-eligibility bit in the existing PaintedBox and retained NodePaint.
Reading future tree B's style during hits on shown A would violate retained
scene ownership. Capture inherited eligibility at paint/publication time, replay
it with the retained geometry, and prove A remains authoritative until B is
acknowledged in an actual retained A/B test. This is metadata on the existing
picture, not a new cache. SVG's resolved scene still owns its shape-specific hits.

## Qualification, 2026-10-04

All 40 surface-control tests pass. The formerly failing simple/inherited-none
overlays now reach the canvas; an explicit-auto ordinary child still scrolls its
HUD, and an SVG root with none still permits its explicit-auto rectangle to hit.
Existing SVG integration tests pass 3/3. The actual retained-region A/B test
changes pointer-events in both directions while B is rendered but unacknowledged:
shown A's hit remains unchanged, then switches only after B is acknowledged.
Actual native/Chrome game zoom and HUD exclusion pass at three sizes; see
LLP 1015.002 for captures and the separately reported broad-suite limitations.
