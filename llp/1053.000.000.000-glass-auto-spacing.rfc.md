## Summary

`glassGroup="auto"`: the merge spacing is the element's own gap along its main axis — Apple's spacing-equals-gap pattern (shapes apart at rest, merging when a press swells one, LLP 1053.000.000 §2 row 3) — so the number is not written twice and follows the gap when it changes.

## 1. What exists

- `glassGroup` is prop 216, `float` (`kernel/tables/schema.json:1239-1242`). Contract types a float attribute as a number (`contract/lower/src/values.rs:538-544`) and range-checks a numeric literal to 0–10,000 (`values.rs:497-508`); a bound value is not checked, and the Apple host clamps every finite value into 0–10,000 (`GlassGroup.swift:93-95`, LLP 1053.000.000 D1).
- The Apple Rust host sends props by name as strings (`host/apple/src/host.rs` `props_for`) and style through `style_json_for` / `style_json_presented` (`host/apple/src/style.rs`), which drop `row_gap`, `column_gap` and `flex_direction` (`style.rs:45-70`): Swift never sees a gap or an axis. A gap change sends a style op and no props.
- `row_gap` and `column_gap` are `f32` points, default 0 (`schema.json:1927-1938`); `rem`/`em` are points by then; there is no percentage gap. Block layout places children with no gap.
- The web writes the attribute `glassGroup` with the number (`host/web/src/element.rs:728`, `css::num`); the JS target writes a bound prop's evaluated value directly (`host/web-js/src/emit.rs:1087-1100`).

## 2. Design

**D1. Spelling and encoding.** `glassGroup="auto"`, or a choice (a ternary or a `match`, nested) whose arms are numbers or `"auto"`. The type pass (`contract/types/src/checks.rs` `check_attr`) admits `glassGroup` as the one prop whose choice may mix the string literal `"auto"` with numbers; any other string literal there is refused. Before the value is compiled (`typed_code`, `contract/lower/src/lib.rs:1263`), every `"auto"` in it is rewritten to the number `-1`, so every arm is a float and the prop's kind, the wire and the runner do not change. Authored numeric literals — at the top and in every arm — are range-checked (0–10,000) before that rewrite, so `-1` is never an accepted authored literal. `-1` is reserved: a bound numeric `-1` is `auto` as well (written down, not checked); every other bound value still clamps.

**D2. The spacing.** The Apple Rust host resolves `-1` from the kernel's style, in points: `column-gap` when `flex-direction` is `row` or `row-reverse`; `row-gap` when it is `column` or `column-reverse`; for a grid the smaller of the two (a grid whose smaller gap is 0 joins touching neighbours on that axis, as `glassGroup=0` does); for any other display `0` (touching shapes merge, separated ones do not). The resolved points are clamped to 0–10,000 in Rust and sent two ways, so every change reaches Swift: in the props map `props_for` returns (`glassGroup` the points, `glassGroupAuto=true`), so a change to the prop sends a props op; and in the style dictionary `style_json_for` returns, as `glass_group_spacing` — the string the host compares to decide a style op (`paragraph.rs:273-298`) — so a gap, direction or display change, which today drops out with the rows the presenter ignores (`style.rs:45-70`), now changes the dictionary and sends a style op. When the prop is no longer `-1`, both the key and the flag are omitted. Swift's `glassGroupSpacing` uses `glass_group_spacing` when `glassGroupAuto` is set and the key is present, else the prop. The agent's `layout` adds `auto: true` to `native.glassGroup` (`GlassGroup.swift:158-172`).

**D3. The web.** Both targets write `glassGroup="auto"` for `-1`, the number otherwise: statically in `element.rs`'s float arm for `glassGroup`; for a bound value on the JS target, where `P` writes `String(v)` (`host/web-js/rt.js:558-562`), the emitter wraps the getter of a bound `glassGroup` so `-1` becomes `"auto"`. Nothing draws it, as today.

**D4. Tests.** Contract: `"auto"`, a choice of `"auto"` and a number, and a nested choice lowered to `-1` and the numbers; a negative or out-of-range literal refused at the top and inside an arm; a non-`"auto"` string refused; toggling `"auto"` ↔ a number at runtime. The Apple Rust host: the resolution for row, row-reverse, column, column-reverse, grid and block, a style op carrying the new spacing when the gap, the direction or the display changes, the key and flag gone when the prop becomes a number, the clamp. XCTests: a group's container spacing from `glassGroupAuto`'s channel, changed by a later style op. The web: the attribute's spelling on both targets. The fixture (`scripts/fixtures/glass-group.contract`) gains a row with `glassGroup="auto" gap=8` beside `glassGroup=8`, drawn alike.

## 3. Build

1. Contract: the type pass (`checks.rs`), the rewrite and the per-arm range check (`values.rs`, the prop lowering); tests.
2. Apple Rust: the resolution beside `props_for` and in `style.rs` (not in `host.rs`, at 1,482 of 1,500 lines); Swift's channel; tests.
3. The web's two writers (`element.rs`; the JS emitter's bound-prop path, `emit.rs`). Docs: LLP 1053.000.000 §5 points here and to LLP 1053.000.000.001; LLP 1001's glass paragraph.
