## Summary

Contract should stay an indent-grammar UI language with closed types, compiled to the plan exact2 already runs (LLP 1005). The restart is not a new face. It is the holes the diaries named after exact2 closed JavaScript, the generator, stale handler capture, and bake: child UI state (including on `each` rows), a default slot, provide/inject as implicit props, compile-time tokens, `when`/`match` in actions, a `submit` handler, `mutation`/`send`/`refresh` (1016 A — a restart can afford the second form; 1016 B was the right *patch*), kernel-typed attrs, three layout refusals, a real `has node testId` check, an app-local pure roster, and a formatter. Keep `testId`, `writes`, `derive`, keyed `each`, primary-argument sugar, bake, CSS defaults, eight agent ops, no JavaScript. Delete dual attr names, the attempt-counter mutation, and the ban on child state.

**On React/JSX: no.** Spend familiarity on CSS defaults and the web's fetch model, not on a JSX face whose braces invite JavaScript the runtime refuses. This family's timed lane: "I did not miss JSX as syntax. I missed the escape hatches" (0099).

## The shape

File: column-0 `shape`, `token`, `component`. Comments `//`. One indent step per nesting level; one node per line. Expressions as LLP 1006 §2, plus `{field: expr}` for a known shape and `[expr, …]` for `list<T>`. Canonical `and`/`or`/`not`; `&&`/`||`/`!` remain aliases. No `??`, `?.`, lambdas, `.map`, `null`, `undefined`. Roster calls only.

```
file       ::= decl*
decl       ::= shape | token | component
component  ::= "component" Name section* "view" node
section    ::= props | inject | state | derive | resource | mutation
             | action | task | slot | contract
node       ::= tag | use | when | each | match | provide | children
tag        ::= ident [primary-expr] attr* [block]
attr       ::= ident "=" expr | "token" "=" Name
```

**One attr table.** The names in today's two apps are the vocabulary (`size`, `weight`, `gap`, `align`, `justify`, `radius`, `background`, `label`, `testId`, …). Dual spellings (`size|fontSize`) are deleted. Unknown names are `lower-unknown-attr` with a did-you-mean to the Contract name and the CSS row. Values are typed against the kernel row: `width=true` is `lower-attr-type`, not a first-frame trap (1006 §8). Empty-string `testId` is omitted at lower (so a hot row does not need a duplicated subtree).

**Root vs child.** Root holds `state` / `derive` / `resource` / `mutation` / `action` / `task`. A child may hold `state` and `action` only. Local initializers are constants (`analyze-local-init` if they read a prop). A singleton use inlines to renamed root slots (today's inlining). A use inside `each` stores those slots on the keyed row — not per-row resources (1005 §8 stays closed for those). Child actions write only their own slots; they invoke parent work through `action` props, whose arity is inferred from the child's call sites and checked at the parent use (the 1006 §8 dispatch-only hole). `resource` / `mutation` / `task` / `derive` on a child is `analyze-child-resource`.

**Slot.** A child declares `slot` and writes `children` in its view. Indented nodes under the use fill it. Caltrain's `when skyOn` / `else` wrap becomes one call:

```
component SkyPage
  props
    on: bool
    material: string
    selectedId: string
    canvasColor: string
  slot
  view
    main testId="caltrain-main" width="100%" height="100%" background=canvasColor
      when on
        canvas surface=glass(material, selectedId) width="100%" height="100%" testId="sky"
          scroll width="100%" height="100%"
            children
      else
        scroll width="100%" height="100%"
          children
```

**Provide/inject** is not a runtime lookup. `inject p: Palette` is a prop the compiler fills from the nearest `provide Palette(...)`; missing on any path is `analyze-missing-provide`. Nested provide overrides. This is 0251 F8 without React context.

**Token.** Compile-time attr bundle; later attrs on the tag win. Constants only.

**Actions.** Assignments, commands, `send`, `refresh`, `when`/`else`, `match`. Still no `await`, no `then`. `writes` lists every slot assigned (0103). `send name = source(args)` requires `name` to be a mutation (`analyze-send-not-mutation`). `refresh name` requires a resource.

**Data.** `resource name = source(args) as shape T` unchanged: args from state, newest-wins, keep-previous, bakeable (1016 D1–D6). `mutation name as shape T` is `option<T>`, `none` at boot, never queried at bake, never re-sent on carry/shape-miss/focus. `send` snapshots args and makes one request; newest send wins on acceptance; assignment to the slot forgets the in-flight ticket (logout). `pending(name)` is the flag. Failure is data. `refresh` is invalidation of a *resource*, coalesced with an argument change, `cache: "reload"`. A `POST` is not a queried counter.

**Handlers.** Today's six, plus `submit` on `input` (and on `form` if that tag lands): Enter / return, no payload. Web standard for `queue/`'s Enter-to-submit without asking `key` to mean two things.

**View.** Tags as `tags.rs`; `when`/`else`; keyed `each`; `match` with `case some(x)` / `case none`; component uses. Primary-argument sugar stays (`text "Coffee"`, `button "Post" press=submit`).

**Layout refusals** (compile, all in one run): `lower-scroll-unbounded` — `scroll` without `height`, `maxHeight`, or `flex`; `lower-zero-size` — pressable with no children and no definite size (valet 0003); `lower-root-region` — `when`/`each`/`match` as the root (today a host `build.rs` crash).

**contract** compiles. v1 is `has node testId="…"` with a literal that must appear in this component's view tree. Conditional clauses wait. No ninth agent op.

**App roster.** The data crate may export pure functions into the same roster table as `stdlib.rs` (name, signature, opcode). A price string is not a compiler change. Same determinism rule as the stdlib.

**Formatter.** `contract fmt`: 2-space indent, wrap attrs at 100 columns. The indent grammar's answer to 0103's reindent, not a reason to take braces.

## Two worked samples

Same behaviour, same `testId`s as the exact2 files.

**(a) Weird Castle** — title → login → signed in, error line, logout. Login is a mutation; `attempt` / `submittedWho` / `submittedPassword` are gone.

```
shape Session
  ok: bool
  username: string
  token: string
  error: string

token field
  padding=12 radius=10 borderWidth=1 borderColor="#5b4a7a" background="#ffffff"

component WeirdCastle
  state screen = "title"
  state who = ""
  state password = ""
  mutation session as shape Session

  derive signedIn = match session { case some(s) => s.ok, case none => false }
  derive loginError = match session { case some(s) => s.error, case none => "" }
  derive username = match session { case some(s) => s.username, case none => "" }

  action openLogin writes screen
    screen = "login"
  action setWho(value) writes who
    who = value
  action setPassword(value) writes password
    password = value
  action submit writes session
    send session = login(who, password)
  action logout writes session, screen, who, password
    session = none
    screen = "title"
    who = ""
    password = ""

  view
    main testId="weird-castle-main" width="100%" height="100%" background="#12081f"
      when signedIn
        SignedIn(username=username, logout=logout)
      else
        when screen == "title"
          Title(open=openLogin)
        else
          Login(who=who, password=password, error=loginError, setWho=setWho, setPassword=setPassword, submit=submit)

component Title
  props
    open: action
  view
    button press=open label="Weird Castle — enter" testId="title" width="100%" height="100%"
      column justify="center" align="center" gap=12 width="100%" height="100%"
        text "Weird Castle" size=40 weight=800 color="#ffffff" testId="title-mark"
        text "tap to enter" size=14 color="#b8a1d9"

component Login
  props
    who: string
    password: string
    error: string
    setWho: action
    setPassword: action
    submit: action
  view
    column justify="center" width="100%" height="100%"
      column gap=14 padding=24 maxWidth=420 alignSelf="center" width="100%" boxSizing="border-box" testId="login-screen"
        text "Log in to Castle" size=24 weight=700 color="#ffffff"
        input value=who change=setWho placeholder="Username or email" label="Username or email" testId="who" token=field
        input value=password change=setPassword placeholder="Password" label="Password" testId="password" token=field
        when error == ""
          text " " size=13 color="#ff8a80"
        else
          text error size=13 color="#ff8a80" testId="login-error"
        button press=submit label="Log in" testId="login" width="100%"
          row justify="center" padding=12 radius=10 background="#7c4dff" width="100%" boxSizing="border-box"
            text "Log in" size=15 weight=700 color="#ffffff"

component SignedIn
  props
    username: string
    logout: action
  view
    column justify="center" align="center" gap=12 padding=24 width="100%" height="100%"
      text `Signed in as ${username}` size=20 weight=700 color="#ffffff" testId="signed-in"
      text "The deck surface goes here (llp/0000)." size=13 color="#b8a1d9"
      button press=logout label="Weird Castle — log out" testId="logout"
        text "Weird Castle" size=13 weight=700 color="#b8a1d9"
```

**(b) Caltrain stations + `StationRow`** — four search handlers, nearest/all/matches, hover, back. Hover and the search hint are local; `query` stays on the owner of `resource matches`.

```
shape Station
  id: string
  name: string
  zone: number
  distance: number

token stationLine
  justify="space-between" align="center" paddingTop=10 paddingBottom=10 borderBottomWidth=1 borderColor="#e0e0e0" width="100%"

component Stations
  props
    query: string
    nearby: list<Station>
    allStations: list<Station>
    matches: list<Station>
    setQuery: action
    selectStation: action
    goHome: action
  state searchFocused = false
  state lastKey = ""
  action focusSearch writes searchFocused
    searchFocused = true
  action blurSearch writes searchFocused
    searchFocused = false
  action searchKey(k) writes lastKey
    lastKey = k
  view
    section role="region" label="Stations" gap=12 testId="stations-screen" background="#ffffffd9" radius=16 padding=14 boxSizing="border-box"
      input value=query change=setQuery focus=focusSearch blur=blurSearch key=searchKey placeholder="Search stations" label="Search stations" testId="station-search" padding=12 radius=10 borderWidth=1 borderColor="#cccccc"
      when searchFocused
        text `searching · last key ${lastKey}` size=11 color="#999999" testId="search-hint"
      when query == ""
        column gap=8
          text "Nearest" size=12 weight=700 letterSpacing=0.8 color="#999999"
          each s in nearby key=s.id
            StationRow(station=s, press=selectStation)
          text "All stations" size=12 weight=700 letterSpacing=0.8 color="#999999"
          each s in allStations key=s.id
            StationRow(station=s, press=selectStation)
      else
        column gap=8
          text "Matches" size=12 weight=700 letterSpacing=0.8 color="#999999"
          each s in matches key=s.id
            StationRow(station=s, press=selectStation)
      button press=goHome label="Back" testId="stations-back"
        text "Back" size=13

component StationRow
  props
    station: Station
    press: action
  state hot = false
  action setHot(over) writes hot
    hot = over
  view
    button press=press(station.id) hover=setHot label=station.name testId=`station-${station.id}` width="100%"
      row token=stationLine background=hot ? "#f2f2f2" : "#00000000" testId=hot ? `station-hot-${station.id}` : ""

```

## Why

- **§2.1 silence.** Attr typing, `lower-scroll-unbounded`, `lower-zero-size`, `lower-root-region`, action-prop arity at compile time. 0102: "strict about the things it models (`writes` lists, `each` keys, expression purity) and mute about layout and navigation semantics, which is where I actually lost time." `height=` on `scroll` "quietly did not exist until I measured `clientHeight` in a probe." Valet 0003: a label-only button is "a silent zero-size trap."
- **§2.2 hatches.** App roster (0103's three-file sidecar; "13 imports → 13 hand-written descriptor entries"). `submit=` for Enter. Local hover instead of a capture-phase listener (0098: "the workaround that finally worked was not a better action"). Remaining hatch is the Rust data crate — 1004 D4, keep it closed.
- **§2.3 time.** Keep dispatch-time args (1005 §6; 0099's stale like). `mutation`/`send` so a login is an occurrence: no `attempt` cache-buster, no password in slots for the session's life, no re-`POST` on `boot_carrying` (1016 panel). Action `when`/`match` are still reducers. Do not restore `task … when [dep]` (0102's hydrate/type race) or `await` (0086's generation reducer, rebuilt by every author).
- **§2.4 composition.** Content's 31 props, written twice; StationRow duplicated for `hot`; bubble 22 props on one line; "every Coterie route repeats the same provider query and primary-navigation wiring" (0086); "All Aboard is a 219-line app deliberately written as one component because splitting it hit `event_unknown_action`" (0277 G5); 8-attr blocks on ~10 buttons (0277 G6). Slot, inject-as-props, child state, tokens, shape props.
- **§2.5 seam.** Keep closed. No generator, no TS, no second description of a shape. 0102: "the part I would take to any stack" — the *boundary*, not the codegen.
- **§2.6 valley.** Indent that is not HTML; one attr name; events `press`/`change` not `onClick`. 0098: "hyphenated attribute names can fail compilation for reasons that have nothing to do with HTML." 0532 §1.4: familiar forms, different rules.
- **§2.7 governance.** One RFC, constructs by fixture (1004 D6). No edition flags, no 0508's 22 open issues.

**Keep §3:** `testId` ("you emit the identifiers the choreography will click" — 0099); `writes` ("twice it caught me" — 0103); `derive` ("better than `useMemo`" — 0102); keyed `each`; primary-argument sugar ("genuinely nicer than `<Text>Coffee</Text>`" — 0103); one file; named refusals; 0278's unobserved-mutation diagnostic; the seam that cannot be bypassed. Restore `contract` only as compiled `has node testId`. Do not restore exclusive `async` arms: they fight 1016 D3's keep-previous (the web). `pending()` is the flag; a resource/mutation never mentioned in `pending(…)` in the view is a 0278-class warning.

## Familiarity

The case for JSX: model priors are JSX; 0477 will happen anyway; 0103 broke a view twice with a scripted reindent ("In JSX the braces make that mechanical"); a React hire starts faster on tags they know; the labs todo report found React faster.

The case against: 0477 "agents think JSX = React" — they will emit `useState`, `useEffect`, `className`, `onClick`, `.map`, fragments, `null` renders, and the compiler will become a tour of refusals. 0532 §1.4 is that valley, already paid in Option-only `??` and "don't invent syntax — copy the corpus." 0098's hyphenated attrs are what HTML-looking source produces. JSX's meaning is JavaScript in braces; 1004 D4 deleted JS; JSX without JS is XML with a second expression language — the valley again. This family's 0099: did not miss JSX, missed hatches. 0103: indent is "a smaller deal than it looks. After twenty minutes it reads like a well-formatted JSX tree with the noise removed." 0532 §1.2: "The core Contract forms were not the dominant complaint. The correction loop around them was." The todo report's React win was `useEffect` persistence, TypeScript, and sidecars — not `<div>`.

A JSX face would raise first-token fluency and lengthen the loop. The record says the loop is what cost. HTML-like is the 0098 trap. S-expressions have no prior and lose the sugar. SwiftUI braces are indent plus `@State` confusion. **Do not look like React.** Spend the familiarity budget where exact2 already did: CSS defaults, CSS-mapped rows, fetch as the executor, `clock settle`. Give models a formatter and a corpus, not a face they will fill with React.

## What it costs

Ground held: 1005's loop, bake, no threads, transactional settle, dispatch-time args, seekable clock, eight ops, no app JS before first pixel.

Delete: `analyze-child-state` as a ban; `size|fontSize` dual arms; hollow `contract` parse; the attempt-counter pattern. Crate files stay under 1,500. Dev loop: Caltrain 8–13 ms today; budget 20 ms p50 if row slots show up (1004 D5). Hosts: `submit` and 1016's `request`/`fulfill` only.

**DEFERRED trade.** Off 1006 §8's not-in-v1: per-instance *UI* slots (constant init; including `each` rows). Off the doing-list in the same step: syntactic inlining of *stateful* `each` children (they become row slots); the sky/plain double call as a thing apps invent. On DEFERRED: a JSX/`html` surface; exclusive `async` regions; `await` in actions; per-instance resources. React tier stays off. Nothing else comes off DEFERRED.

## Not doing

No JSX, HTML-with-braces, S-expressions, hooks, refs, `useEffect`, islands, app JavaScript, `.contract-meta.ts`. No `await` / `then` / completion callbacks (1016 panel: the view routes on the cell). No `task when [dep]`. No child `resource`/`mutation`/`derive`. No CSS cascade, no `className` strings, no spread/rest, no generics, no `any`, no `null`. No computed member access, no lambdas (0103 wanted `obj[key]`; closed fields stay; the data crate is the hatch). No ninth agent op (a `contract` smoke, if any, is `tree` assertions). No edition machinery (0508 §13). No speculative stdlib beyond the v1 apps and the app roster. No Design Mode, no LSP in this cut (formatter is the indent fix).
