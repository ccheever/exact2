## Summary

exact2's scope is derived from real consumers — Caltrain, then a reader,
Fieldnotes, Messages. The engine add-on would get the same treatment: one
small, finishable, actually-playable game whose every mechanic is there
because it forces exactly one missing seam, and whose "does it still work"
is answered by a script in seconds.

**Lanterns.** A fox on a small island at dusk. Twelve lanterns; light them
all before night falls. Third person, one level, three to five minutes. Run,
jump, push a crate to reach a high ledge, read a signpost. When the sun goes,
the lanterns you lit are the only light there is.

The game's central mechanic is the clock, which is exact2's central
mechanism: the sun's position is a function of simulation time, so
`clock +60000` moves it, deterministically, on every host.

## 1. Why this game — each mechanic and the seam it forces

| in the game | what it forces | LLP 1041 |

| capsule against terrain; a pushable crate; ledges | `rapier`: a kinematic character controller, dynamic bodies, sleeping — `clock settle` means "the crate came to rest" | F11 |
| dusk → night: a moving sun, one cascaded shadow, a sky | PBR-lite, a directional light, a shadow map, IBL from the sky | F21 |
| lit lanterns are point lights; at night there are up to twelve | clustered forward lighting earns its place incrementally, 1 → 12 | F21 |
| a lantern's light springs on | a spring from `exact-motion` driving an engine value (LLP 1041.002 F6) | — |
| chime, footsteps, wind, a night sting | audio out, spatialized, and its journal lines | F8, F16 |
| the island is grown from a seed | procedural terrain and props; the seed an explicit input | F17, F13 |
| the fox is a rigged glTF | the asset pipeline: glTF, textures, digest-addressed delivery | F9 |

## 2. What it deliberately does not test

Open worlds and streaming; networking; dynamic global illumination; more
than one skinned character; large entity counts (a stress scene — ten
thousand instanced fireflies — is a fixture, not a feature of the game);
an editor. A second level. A story.

## 3. Content, and who can make it

Everything but the fox is code: the island a seeded heightfield; rocks,
trees, the crate and the lanterns low-poly procedural meshes; sky and water
shaders; sound synthesized or CC0. The level is a text file — lantern
positions, the crate, the signpost's text, the seed — checked at build
against the component table (LLP 1041.002 F9), the way LLP 1009 D2 means a
`canvas`'s arguments to be checked against the surface roster (as built,
that check runs at delivery in `scripts/app.mjs`, not yet in the compiler).

The fox is the one imported asset. Candidates: Khronos's glTF sample *Fox*
(Survey / Walk / Run clips, no jump — the jump would be procedural; it is
also the reference viewer's own test asset, which makes it a renderer
fixture for free) or a Quaternius CC0 animal with a jump clip. Licences to
be confirmed before anything ships; none is asserted here.

## 5. Done means — the acceptance script

`smoke lanterns <web|macos|ios|linux>`, written in the eight operations
(LLP 1041.001), under the agent's clock, no sleeps. (Linux needs the host
to load the module at all — owed by LLP 1015 §7; until then its steps are
the simulation's, without pixels, LLP 1041.001 D7.)

1. The title is on screen before the game module is requested.
2. Start. Hold *forward* for 1,500 ms of clock; the fox's position is within
   ε of a pinned point; its animation state is `run`; the journal shows the
   footstep lines and no refusal.
3. Walk to lantern 1 and press *act*: `lanterns_lit` is 1, a light exists,
   the journal has `sfx chime`, the HUD child reads "1 / 12".
4. Push the crate off the ledge; `clock settle`; it rests at **pinned
   coordinates** — this game's 652 (LLP 1012 §5): the same number on every
   host, and it moves if any host's simulation does.
5. `clock +1000` in one seek and sixty seeks of one tick in a fresh session
   end in the same world hash.
6. The scripted route lights all twelve; `won` is true before night.
   In a second session nothing is pressed; night falls; `lost`.
7. **The world hash at the end of step 6 is equal on all four hosts.**
8. Save, end the session, start one from the save: the hash is the one
   that was saved.
9. The signpost's text node is in `tree`, its `layout` box is where the
   placement put it, and a `tap` on it lands.
10. Readback fixtures — the dusk frame, the night frame — sit inside their
    bands against Chrome (LLP 1009 D1), and against the reference path
    tracer if LLP 1041 F22 is built.

And one test of the claim the whole program rests on, run by hand when it
matters rather than as a check: **an agent given only the repository and
the agent API adds a thirteenth lantern on a new ledge, makes it reachable,
and proves it with a script** — in one session, with no human looking at
the screen.

## 6. Slices — each one ends driven

- **S0 — grey box.** A capsule on a plane. Ticks under the clock, held-key
  input, the world in `state`, a hash. No assets, no lighting. Proves F6,
  F7, F12, F13 and the seams of LLP 1041.002 §3 — the entire architectural
  risk, in the smallest game that has any.
- **S1 — physics.** Terrain collider, the crate, `settle`, hash parity
  across the four hosts.
- **S2 — a lit world.** glTF static meshes, PBR-lite, the sun, one shadow;
  the first readback fixture.
- **S3 — the fox.** Skinning, the blend, the state machine; a pose fixture
  (a named bone's position at time *t*).
- **S4 — lanterns.** Triggers, point lights, the spring, audio and its
  journal lines, the HUD from published values.
- **S5 — a game.** Dusk to night, win and lose, save and resume, the routes,
  touch controls, the signpost.
- **S6 — shipped.** A level edit delivered to an installed build; a
  performance pass; a physical iPhone.

S0 and S1 are the ones that say whether the add-on shape of LLP 1041 §5
works. Everything after them is ordinary engine work that could be stopped
at any slice and still leave a working game.

## 6a. The Godot twin (Charlie, 2026-09-17: worthwhile)

The same game built in Godot 4 — same level file's positions, same fox,
same twelve lanterns, same win and lose — so "as well as Godot" is a table
and not an opinion. It lives beside Lanterns in the add-on's directory, is
built by hand once Lanterns reaches S5, and is **diagnostic, never a
check**. What it measures, on the same machines and the same phone:

| | Lanterns | the twin |
|---|---|---|
| web download, compressed (engine + game + assets) | | |
| cold start to the title; to the first world frame | | |
| frame time, p50 and p95, dusk and night (12 lights) | | |
| memory at rest in the level | | |
| installed size on iOS and macOS | | |
| **agent iteration**: the thirteenth-lantern task of §5, wall time from the prompt to a passing proof, and how many times the agent needed pixels | | |
| what cannot be asserted at all (a bone's position at *t*; the same physics on two hosts) | | |

The last two rows are the ones the program is about; the first five keep it
honest. The twin's own determinism and headless story should be given their
best effort (`--headless`, fixed physics ticks, a test addon) — a strawman
twin measures nothing.
