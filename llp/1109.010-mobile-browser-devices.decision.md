The pinned HTML document functions generate the surrounding document, including source CSS and script escaping.

[decision] Existing mobile/ios/build.rs invokes a small embedded Bun/Rolldown expression before the normal Exact bake. The bake never installs packages, reads another checkout or accesses the network. Missing Effect gives that install command. Build inputs and the lockfiles are tracked for rebuilds.

## Connection and command ownership

[decision] Shared T3Client owns server RPCs and decoding. Device snapshots reuse shared watchDevice/deviceStateOf/deviceStateEvent. The mobile adapter adds only source mobile selection/presentation and explicit retry-marker handling; copied shared bodies remain unchanged. Browser list/event state follows pinned mobile state/preview.ts because the adopted shared closure has no equivalent reducer.

[observed] Browser lists carry server epoch and revision. At most 200 newer events replay over a list, preserving tab order. A changed epoch invalidates the list. Native entry.seq deduplication prevents repeated wrappers/drains from filling the replay buffer with duplicates. An invalidation arriving during an older list survives that list's completion. The selected fallback is pinned so another tab's activity cannot switch the view. These snapshots perform no I/O; selecting a fallback does update local view selection and clears the previous target's native status.

[decision] Read and mutation owners capture origin, environment, thread and connection generation. Read serials also guard every native await so an older permission response cannot override a newer read. Tab/device selection is checked separately around status reads. A native status report must name the current tab or host/device pair before it can enable input. Device joins use hostId and deviceId together. Shutdown captures the selected target before its permission await; only that operation releases its busy flag.

[observed] Permission reads use the actual session document and the existing mobileSessionGrants adapter: explicit permissions, including [], override legacy scopes. List/stream metadata requires orchestration:read. Browser mutations require preview:operate; device shutdown/input requires orchestration:operate. Browser navigation additionally requires the live stream's canOperate and controller=you. Server RPC and stream authorization remain authoritative.

[decision] Native `_retryDue` markers reopen subscriptions; authorization failures alone do not. Browser uses its own subscription key; device reopens the shared DEVICE_STATE_KEY and retains the shared reducer. Failed refresh attempts consume their own invalidation while preserving a newer one, so the root cannot retry indefinitely on every failed mutation completion. Parent's event hook observes decoded batches before shared acknowledgement, including chunked transfers.

## Native lifetime

[decision] T3MobileBrowser/T3MobileDevices own their WK views and invoke the existing T3Transport.deviceHubAccess ticket request. Native checks captured origin, descriptor environment and generation before requesting access and again after session/ticket replies. The fresh session grants also gate native input. Native messages expose status and controls, never media tickets. No native Exact reply is retained across stream notifications or user actions.

[observed] The local viewer uses the source file-document configuration, startup timeout 15s, process recovery, unauthorized handling and frame/input code. Native foreground/focus suspension stops inactive viewers. The view can retain an active PiP stream while it exists, but the current root destroys WK views when their route leaves the top position; off-route PiP continuation is not implemented. All delegate messages and errors require the current WK instance. Deferred identity checks also require the captured target and load serial. An in-progress access request is not restarted by repeated view props.

[decision] Each WK instance gets a separate app audio-session lease. Teardown suspends media and releases that instance's lease in the suspension completion. A retired view cannot release a replacement's hold. WebKit controls its own audio activation; the viewer does not deactivate AVAudioSession directly.

[observed] File pickers and remote dialog answers carry immutable chooser/dialog identity through native awaits. Replacement or lost control invalidates old callbacks. Upload multipart data is copied in 1 MiB chunks off the UI thread into an owned temporary file, then sent with uploadTask(fromFile:); there is no new size limit. Cancellation is checked between chunks. Downloads recheck target identity before presenting share/error UI. Destroy cancels tasks, workers, pickers, timers, motion updates and script handlers, and removes temporary files.

## Presentation and root seam

[observed] Browser and device components expose exact source actions and actual counts, loading/errors and controls. Parent-owned T3MobilePreviewMenu builds native UIMenus from the source menu rows. Its callback carries owner and selected source target; no asynchronous menu reply is held. Browser options include appearance, zoom, viewport, hard reload and site-data clearing. The source catalog has no Desktop preset despite its category union, so no Desktop item is invented.

[decision] Root owns route creation/teardown, safe-area input, PiP action and menu callbacks. The current browser header still uses the common 18-point heavy title; the source 17-point semibold title and full-screen device status/navigation bar handling remain to be implemented. Read resources prepare permissions/subscriptions, status resources watch native changes, and projections do no network reads. Root releases browser subscription ownership when its consumer leaves. Device state stays under the existing shared subscription owner.
