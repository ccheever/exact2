UNSOUND
1. **Major** — An `animation` shorthand is rewritten as if every word were a keyframes reference. `Rewriter::keyframes_text` (`contract/syntax/src/scope.rs:365`) runs each word through `Scope::resolve` (`contract/syntax/src/scope.rs:61`), which refuses a spelling declared in any other loaded file (`contract/cli/src/sources.rs:407`). A renamed in-scope name is substituted even when the word is a CSS keyword.

   Failing input: `ui.contract` declares `keyframes infinite` and `component Card`; `app.contract` is `use Card from "./ui.contract"` plus `view animation="pulse 1s infinite"`. Compile stops with `contract-use-missing` on `infinite`. If both files declare `keyframes infinite` and `keyframes pulse`, the library’s string becomes `"pulse__ui 1s infinite__ui"` (`sources.rs:310`). `infinite__ui` is a custom-ident, so the shorthand no longer means “repeat forever.”

2. **Major** — Primitive types and roster calls are resolved in the shape/fn namespace. `TypeExpr::Named` and `Expr::Call` are renamed with `Kind::Call` (`contract/syntax/src/scope.rs:212`, `contract/syntax/src/scope.rs:439`). `declared_elsewhere` (`contract/cli/src/sources.rs:407`) then treats any loaded shape or fn of that spelling as the only meaning. The type checker still prefers primitives only when the text is still `number` or `string` (`contract/types/src/lib.rs:294`).

   Failing input: `ui.contract` is `shape string` / `text: string` and `component Box`; `app.contract` is `use Box from "./ui.contract"` and `props label: string`. The prop type is `contract-use-missing`, not the primitive `string`. The same happens to `state n = length("hi")` if the library declares `shape length`. If both files declare `fn number(x: number): number = x`, the library’s signature is rewritten to `number__ui` and fails as an unknown type.

3. **Major** — The package root is the nearest ancestor `package.json` of the canonical file, not the manifest whose `exports` were used. `package` reads `exports` from the `node_modules` manifest (`contract/cli/src/resolve.rs:190`), then replaces `manifest` with `key.ancestors()` (`contract/cli/src/resolve.rs:236`). Containment (`resolve.rs:133`), bake staging (`js/bake/src/lib.rs:552`), and watchers (`host/web/src/dev.rs:56`, `contract/cli/src/lib.rs:350`) all follow that second file.

   Failing input: `@me/ui` has `exports: {".": "./src/card.contract"}`, `src/card.contract` contains `use Pad from "../styles.contract"`, and `src/package.json` exists. The root becomes `src/`, so the relative use is refused as leaving the package. A self-contained `src/card.contract` compiles, but the bake copies `src/package.json` to `node_modules/@me/ui/package.json` and then cannot resolve `"@me/ui"`. Edits to the real `exports` file are not on the watch list.

4. **Major** — Identical `font` families in two files do not merge. Merge keeps a second family unless `same_declaration` matches (`contract/cli/src/sources.rs:435`, `contract/cli/src/sources.rs:545`). That helper clears `source_id` and `end_col` only, so a different line or column is a different font. Lowering then refuses the duplicate (`contract/lower/src/fonts.rs:44`).

   Failing input: both `app.contract` and `ui.contract` contain `font "Inter"` / `400 "assets/Inter.ttf"`, and the app has `use Title from "./ui.contract"`. The declarations sit on different lines, both are kept, and the build fails with `lower-font-duplicate`.

5. **Minor** — An `exports` condition object does not fall through from `contract` to `default`. `condition` takes the first present key and only then recurses (`contract/cli/src/resolve.rs:284`), so a `contract` value that is not a usable path hides a sibling `default`.

   Failing input: `"exports": {".": {"contract": {"bun": "./index.contract"}, "default": "./index.contract"}}`. `entry` returns `None` and `use Card from "@acme/ui"` is `contract-use-package`, even though `default` points at the file.
