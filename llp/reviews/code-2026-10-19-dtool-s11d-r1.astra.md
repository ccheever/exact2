1. **BLOCKER — `describe.targets` is read in the wrong shape.**  
   [base.ts:57](/tmp/rv-dt-s11d/apps/design-tool/base.ts:57) stringifies `{target, column}` records, producing `"[object Object]"`; [base.ts:30](/tmp/rv-dt-s11d/apps/design-tool/base.ts:30) consequently marks no column as shipped. For a Mac-only app, every value starts hidden and “Set for this app” seeds iOS’s `16px` instead of Mac’s `10px`. Consume the supplied `column`; use the icon fallback only when targets are absent. The stub’s string array at [tamber-stub.ts:279](/tmp/rv-dt-s11d/apps/design-tool/stub/tamber-stub.ts:279) masks this mismatch.

2. **BLOCKER — The agreed base explanation breaks the branch editor, including app overrides.**  
   [app.ts:739](/tmp/rv-dt-s11d/apps/design-tool/app.ts:739) passes `x.whens` to `branchOf`, which immediately calls `.map`. The agreed `{kind: "base", name, base}` reply has no `whens`. Thus clicking an overridden `radius.md` cell fails before opening its editor. Furthermore, [app.ts:751](/tmp/rv-dt-s11d/apps/design-tool/app.ts:751) marks every base explanation read-only, even when `base.override` exists. Handle the base reply explicitly and preserve editable app overrides. [tamber-stub.ts:292](/tmp/rv-dt-s11d/apps/design-tool/stub/tamber-stub.ts:292) incorrectly uses the base explanation only for unoverridden names, hiding the override failure.

3. **SHOULD-FIX — Unoverridden base values have no route into the branch editor.**  
   [app.ts:666](/tmp/rv-dt-s11d/apps/design-tool/app.ts:666) gives these rows `cells: []`, while [app.contract:1720](/tmp/rv-dt-s11d/apps/design-tool/app.contract:1720) renders their platform values as plain text. Expanding `space.md` and choosing its Mac value cannot open the promised read-only branch. Avoiding fabricated tuple folds is correct, but platform values still need a selection action and corresponding branch representation.

4. **SHOULD-FIX — Package overrides copy display text instead of writable token text.**  
   [app.ts:663](/tmp/rv-dt-s11d/apps/design-tool/app.ts:663) takes `start` from `cells[0].css`, which contains `cellText`’s presentation formatting. For a package duration of `150ms`, “Set for this app” proposes invalid `150 ms`; typography becomes a description containing `·`, `weight`, and “unsaid” rather than a token value. See [dials.ts:160](/tmp/rv-dt-s11d/apps/design-tool/dials.ts:160). Seed the operation from the corresponding resolve value.

5. **SHOULD-FIX — Read-only status does not invalidate an existing branch draft.**  
   [app.contract:823](/tmp/rv-dt-s11d/apps/design-tool/app.contract:823) excludes ownership/read-only status from `branchKey`, and [app.contract:1888](/tmp/rv-dt-s11d/apps/design-tool/app.contract:1888) leaves Apply and Scrub live independent of `branch.readOnly`. Concrete case: draft an edit to an app override of `reading.measure = 640px`; another client removes that override, exposing a package value also equal to `640px`. The branch becomes read-only, but neither stale check changes, so an accepted refreshed proposal can revive the removed override. Invalidate branch drafts when ownership changes. The confirmation button at [app.contract:1832](/tmp/rv-dt-s11d/apps/design-tool/app.contract:1832) also lacks the read-only guard applied to its opener.
