Unresolved items below go to theme2.

1. **should-fix** — A popover whose only authored geometry is a non-uniform corner still gets the default glass, and that glass is then squared. A radius is not a surface (`contract/lower/src/popover_surface.rs:19-21`), so `border-top-left-radius` alone is marked. `writesCorner` is true (`Backdrop.swift:187-189`), and `applyMaterialRadius` uses the radius `BorderPaint.clip` returns (`NodeViewIOS.swift:1107-1110`). For corners that are not one circle, `clip` returns 0 and installs a mask (`BorderPaint.swift:34-41`). On iOS 26 the effect view's shape is `cornerConfiguration = .corners(radius: .fixed(0))`, so the glass is square. The hosted test only checks a uniform `border_radius` of 0, and only via `writesCorner` (`PopoverSurfaceIOSTests.swift:190-192`).

2. **should-fix** — A conditional class with a surface on only one arm suppresses the mark on both arms. `class.rs:57-84` turns a row that only one style sets into a written ternary (`value` / `none`). `implied` treats any written surface name as an authored surface (`popover_surface.rs:32`). The empty arm is then a bare popover: no glass and no border. The ruling's one boolean cannot tell the arms apart; this needs an owner decision.

3. **nit** — The web host emits `data-defaultsurface="true"` through the catch-all for props with no arm (`host/web/src/element.rs:1163-1168`). Nothing in CSS or JS reads it, so the UA popover style is unchanged. Same nit as round 2.

4. **nit** — Menu exclusion is the literal `role="menu"` (`popover_surface.rs:28-30`). A role bound to an expression is still marked; the host then drops the glass when `accessibilityRole` is `"menu"` (`Backdrop.swift:165`), and that path is untested. A menu-shaped popover with no `role="menu"` is marked. Production iOS hides that node and presents `UIMenu` without requiring the role (`MenusIOS.swift:153-162`, `207-247`), so the glass is not what a user sees. An agent-painted button-row popover does get the glass. The Mac decides menus by button-row shape (`MenusMac.swift:649-666`) and still draws its system popover, because no corner is sent. A confirmation (`accessibilityRole == "alertdialog"`, `MenusIOS.swift:112-114`) can be marked and build a glass effect on a node that stays hidden behind `UIAlert`.
