1. **[FlightScale.swift:27](/tmp/x21/host/apple/Sources/ExactKit/FlightScale.swift:27), [FlightsIOS.swift:252](/tmp/x21/host/apple/Sources/ExactKit/IOS/FlightsIOS.swift:252), [FlightsMac.swift:222](/tmp/x21/host/apple/Sources/ExactKit/Mac/FlightsMac.swift:222) — must-fix:** Changing the live node’s height does not scale its surface whole. For a 200×400 slot shown at 100×100, this changes its bounds to 200×200 before scaling. A vertical gradient therefore shows its entire gradient instead of its upper half; a bottom border appears where it should be clipped away. Fields, textareas, masks and material views also read these modified bounds, and autoresizing subviews resize with them. ([UIKit documentation](https://developer.apple.com/documentation/uikit/uiview/autoresizingmask-swift.property?language=objc)) **Fix:** retain the node’s laid-out bounds and scale it inside a separate container that owns the shown rectangle, clipping and interpolated radius.

2. **[FlightsIOS.swift:249](/tmp/x21/host/apple/Sources/ExactKit/IOS/FlightsIOS.swift:249), [FlightsMac.swift:217](/tmp/x21/host/apple/Sources/ExactKit/Mac/FlightsMac.swift:217) — must-fix:** `to.size` is the destination’s converted rectangle, not its layout size. With a 402-point-wide slot beneath an ancestor scaled to 0.5, `to.width` is 201. At progress 1 this computes scale 1 and changes the node’s width to 201, while its children retain their 402-point layout. Landing then visibly changes their size and positions. **Fix:** use `slot.bounds.size` for the layout dimensions and the converted rectangle for presentation; convert the destination radius into presentation coordinates too. Add a scaled-ancestor regression test.

3. **[FlightsMac.swift:121](/tmp/x21/host/apple/Sources/ExactKit/Mac/FlightsMac.swift:121) — must-fix:** The “place went” branch restores geometry only when `f.frame` exists. That property is populated only by a frame update during flight. Detach the slot without such an update, then land: the scale clears, but the temporary flight height remains. **Fix:** always restore the latest layout size, falling back to the retained slot’s size, while preserving the view’s new placement. Test this with `f.frame == nil`.
