1. **MATERIAL — D7: origin does not identify an invocation.** Serializing system calls and wakes does not make all `tool` work belong to the current call. A resource retains its previous origin for later device re-asks ([admit.rs:139](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1023/cap1/runner/src/runner/modules/admit.rs:139)); independent model callbacks also use `tool` ([invoke.rs:158](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1023/cap1/runner/src/runner/modules/invoke.rs:158)). Consequently, call B can inherit work descended from completed call A, wait for it, or cancel it on expiry. **Decision:** use invocation identities, or specify isolation and retirement rules covering every producer of that origin. The asserted equivalence in D7 is unsound.

2. **MINOR — D8: compatibility omits a compiled input.** The generated description comes from the tool literal, but the enumerated signature inputs omit that literal. A description-only plan update therefore leaves stale system metadata. Widgets already fingerprint their descriptions ([compat.rs:460](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1023/cap1/bake/src/compat.rs:460)). **Decision:** include every compiled field, including the description, in compatibility and face digests.

3. **MINOR — D10/D11: the chosen policy does not guarantee local unlock.** `.requiresAuthentication` permits execution on a locked iPhone when invocation originates on an unlocked Apple Watch; `.requiresLocalDeviceAuthentication` requires unlocking the executing device. **Decision:** choose authenticated invocation or local unlock, then align the default and wording. [Apple authentication policies](https://developer.apple.com/documentation/appintents/intentauthenticationpolicy/requiresauthentication).

4. **MINOR — D11/§10: pin cancellation has no platform response.** The substitute maps cancellation to `unavailable`, but Android sends no response when the person declines. Its immediate boolean reports request support; its callback reports successful pinning. **Decision:** define an immediate submission result or a success-only completion, without promising observable cancellation. [Android `requestPinShortcut`](https://developer.android.com/reference/android/content/pm/ShortcutManager#requestPinShortcut(android.content.pm.ShortcutInfo,%20android.content.IntentSender)).

5. **MINOR — D15 item 3: a custom action is not an ingress restriction.** Another app can explicitly address the exported activity with the same action and arbitrary data; intent filters do not authenticate callers. **Decision:** accept ordinary external deep links, or specify a verifiable restriction. Remove the claim that the action string prevents external opening. [Android intent-filter security](https://developer.android.com/guide/components/intents-filters#Receiving).

6. **MINOR — D17/§14: the tvOS cell lacks an established system caller.** Compiling App Intents and directly testing the door does not establish Siri discovery. Apple explicitly excludes App Shortcuts from tvOS, while this RFC excludes assistant schemas. **Decision:** mark the cell later until an actual system caller is documented or demonstrated. [Apple App Shortcuts platform considerations](https://developer.apple.com/design/human-interface-guidelines/app-shortcuts).

7. **MINOR — §11 and Summary: the shown failure expression does not type-check.** Shelf’s `changed` mutation reads as `option<Ack>`, so `not changed.ok` cannot access its reply directly. **Decision:** unwrap it with `match` and define the `none` case. See [mutation value semantics](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1023/cap1/docs/contract-for-agents.md:890).

8. **IMPLEMENTATION-PHASE — D4: mirror persistence needs publication recovery.** Writing the desired mirror before telling Spotlight is sound, but a crash between those steps must leave recoverable pending work; otherwise repeating the same snapshot produces an empty diff despite an unapplied addition or deletion. **Decision during implementation:** retain pending changes until acknowledgment or reconcile the whole kind after interruption, and drive that crash boundary. This does not require changing the mirror architecture.

### Dispositions (r2)

1. MATERIAL, origin does not identify an invocation: TAKEN at D7 ("An invocation knows its work by its id, not by its origin"): each invocation has an id the origin tables carry beside each origin; the dispatch commit stamps its requests, `then`s, held calls and queued sends, and the commits fulfilling them carry it on; a device re-ask and a model's `invoke` run carry none; ownership, expiry and supersession read only the id; the wake moves to it too. Also D15 item 5, §0 item 1, §12, §14 stage 1 (tests for a model handler's run and a device re-ask during a call), §15 question 1.
2. MINOR, the description is compiled but not in the id: TAKEN at D8 (every field the generated code compiles, the description included, in the id and the door's digest).
3. MINOR, `requiresAuthentication` allows a locked iPhone from an unlocked Watch: TAKEN at D10 and D11: the default stays `requiresAuthentication`, with the wording aligned to Apple's meaning (an authenticated person, not a locked phone in someone else's hand); `local` names `requiresLocalDeviceAuthentication`.
4. MINOR, pin cancellation unobservable: TAKEN at D11 and §10: `requestPinShortcut` answers `requested` or `unsupported`; no decline is promised.
5. MINOR, a custom action is no ingress restriction: TAKEN at D15 item 3 and D1: the claim is removed; a location from any app is a link with a link's origin, and quick actions and search results arrive with a link's origin on every host.
6. MINOR, tvOS has no established caller: TAKEN at D17 (intents on tvOS `later`, App Shortcuts "Not supported in tvOS" per the HIG; the tvOS bake leaves faces out) and §14 stage 2.
7. MINOR, `not changed.ok` does not type-check: TAKEN at the Summary and §11 (`match changed { case some(a) => not a.ok, case none => false }`).
8. IMPLEMENTATION-PHASE, mirror publication recovery: TAKEN as one sentence at D4 (each change pending until the platform acknowledges it; the next launch finishes it).
