**VERDICT: WRONG**

1. **Should-fix.** In right-to-left, the separator gap is the content box’s right padding, so the line does not sit under the text. `lineStart` (`GroupedCustomRowsIOS.swift:73-75`) sets `bottomSeparatorInsets.leading` to the cell width minus `x + box.maxX`. The sheet’s `padding-left` is physical, so that distance is the trailing padding (16 in the test’s box, `x: 56`, width 298, row 370). The line then runs from the cell’s left edge to the content’s right edge. `Kernel::grouped_separator` (`kernel/src/grouped/separator.rs:54-59`) runs from the content’s left edge (`border_left + padding-left`) to the row’s right edge (`grouped-separator-end` is 0 on iOS). A standard UIKit cell in right-to-left insets from the right by the symbol gutter. `GroupedCustomRowsIOSTests.swift:103` locks in the 16-point right gap and never compares it to the standard row in that test. `look` also reads this width too early: `carry` calls `look` (`GroupedListIOS.swift:1239`) before it moves the row into the cell (`1252-1260`), and `lineStart` (`GroupedCustomRowsIOS.swift:74`) treats `carried[id] != nil` as “already in the cell,” so the stored line is the home parent’s width. The handler later reads the live cell width, `resized` flips, and `willDisplay` (`GroupedListIOS.swift:1332`) asks for another projection sync on every right-to-left batch.

2. **Should-fix.** A mark survives when the image leaves a row that is not carried. `look` (`GroupedCustomRowsIOS.swift:26-36`) is only reached from `carry`, and `mount` carries visible cells only (`GroupedListIOS.swift:781-784`). `willDisplay` covers a cell as it appears. It does not cover a leading symbol reparented out of an offscreen custom row: `customLooks` still holds that view weakly, and `listSymbol`’s setter (`NodeExtrasIOS.swift:331`) keeps drawing it large, unclipped, and centered. `forgetLook` runs when the row is no longer custom or is dropped (`GroupedListIOS.swift:670`), when the cell is configured as a standard cell (`1045`), and when the list is removed (`1298`). `restore` (`1284`) puts the row home without clearing the mark. A visible row, a dropped row, and list removal are covered. An image that moves to some other shown place while its old row stays offscreen is not.

3. **Nit.** The large scale does not change layout, and it does not loop. `updateSymbol` (`NodeViewIOS.swift:587`) reports `SymbolMeasure.size` at the node’s point size and weight, with no scale. The sheet’s box is an explicit 24×20, and that report is the same size as before the mark, so the kernel does not relayout. `queueIntrinsicSize` (`PresenterIOS.swift:731-734`) is asynchronous. The setter returns when the flag is unchanged. Invalidation waits for `mount` (`GroupedListIOS.swift:799`). Agent frames and hit testing still use the 24×20 box; the glyph is about 25 points and `clipsToBounds` is false (`NodeViewIOS.swift:597`).

4. **Nit.** An authored box that is exactly the sheet’s slot cannot be told apart, and that limit is acceptable on the host. `leadingSymbol` (`GroupedCustomRowsIOS.swift:51-57`) marks the first shown `symbol:` child that is not an accessory, with `object-fit: contain` and a layout size within 0.5 of 24×20. Any other fit or size is left alone, and an authored font size, weight, and symbol rendering still feed `symbolConfiguration` (`Affordances.swift:117-132`). The host sees resolved rows, not who wrote them. A compiler-lowered marker on the sheet’s leading symbol is the way to separate an authored 24×20 contain image. That is for the RFC owner. The same owner owns the fixed slot: `grouped-symbol-width` / `-height` and `grouped-row-inset-symbol` stay 24, 20, and 56 at every body size (`kernel/tables/schema.json` metrics, not ramps), so at accessibility sizes the unclipped glyph overlaps the title while UIKit’s cell grows the inset. Point size of the body font plus scale `.large` matches `textStyle: .body, scale: .large` when the weight matches, bold text included, because the inherited weight is what `updateSymbol` reads.

5. **Nit.** Left to right, no-symbol rows, owned edges, and the caps check out. A row sent no content box falls back to the row’s leading edge.
