1. **SHOULD-FIX — `host/web-js/sounds.js:178` and `host/web-js/ts-data.js:155`.** `clock.agent` is set only in `mount()` (`rt.js:1393`), inside the gated `start()`. Sounds and the native page module are armed at module init, before that gate. `sounds()` schedules a frame and a timeout whose `load()` skips real audio only when `clock.agent` is already true. `ts()` calls `pageModule()`, and `painted()` resolves on the blank page's paint (observer, then one frame) during a wait of up to 100 ms, then `pageNative` connects with `agent: false` and is memoized. A face that is not loaded yet is exactly when this gate waits, and that wait is long enough for both callbacks. An agent session of an app with sounds or a native module then starts the real output, or `connect({agent:false})`, for the whole page. Set `clock.agent` before the gate (it depends only on the URL), or arm both callbacks inside `go()`.
