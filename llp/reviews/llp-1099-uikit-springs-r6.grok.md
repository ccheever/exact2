NEEDS REWORK

Round-5 dispositions match the text, and `bun motion/tests/fixtures/uikit-springs/fit.mjs` matches §4 (9,474 calls, 100 misses, all inside the band, 1,916 flagged, 27 refusals, worst matched `|g|/ε` = 0.059). 1. **MATERIAL.** The scale step bound is not an upper bound once a factor is critical or overdamped, so the parity test fails for legal scale springs. D6 (`llp/1099-uikit-springs.rfc.md:573-579`) sets `|f''| ≤ ω²·E·K²` with `K = 2` outside the underdamped branch. At `t = 0` on the bounce quirk (`b = −0.5`, `d = 0.4`, `v = 0`, `ω = 2π/d`) `|p''| / (4ω²E) = 3.24`. Sampling scale `1 → 2` (`S = 1`) with that step gives a midpoint chord of `1.54×10⁻³`, past `10⁻³·S`. The same shortcut on an accepted duration spring, `spring(3s, 1, velocity 20)` (`u = 60`, outside the band, `|g|` within `0.1ε`), chords `1.24×10⁻³` on that move. `spring(1s, 1, velocity 100)` chords `2.02×10⁻³`. The additive envelopes in D6 (`:564-566`) do bound the same quirk: a unit translate stays at `4.85×10⁻⁴`. Underdamped `K = 1` also holds (the `1 → 0.1 → 0.01` product ratio is 0.74). **Fix:** bound each factor with those additive branch envelopes, in factor units, and only then apply the product rule. Pin `scale spring(400ms, bounce -0.5)` and `scale spring(3s, 1, velocity 20)` to `10⁻³·S`.

2. **MATERIAL.** A scale release toward 0 is still contradicted by the target-0 rule, and its `S` is undefined. D5 (`:396-400`) collapses the live scale components when the target is 0. D5 (`:469-477`) and §8.4 (`:992-993`) require a release toward 0 to keep moving (0.018832 at 50 ms on `spring(400ms, 0.8)`, which checks out). The spec never orders the collapse against inserting that residual, and a residual is a scale component, so one reading deletes the motion the test pins. D6 (`:554`) also sets every scale `Δᵢ` to factor distance times the target, which is 0 when the target is 0, so a release from a nonzero scale has no `S`. **Fix:** collapse factor components only, and do it before the release residual is added. A residual’s `Δᵢ` is its displacement in scale units.

3. **MATERIAL.** The 65th-component fold still has two algorithms. D5 (`:417-428`) always folds the oldest two, and for scale always uses `f₁·f₂ − 1`. D5 (`:478`) says a fold combines only one kind, and does not say which pair when the oldest two differ. Two released residuals are additive offsets; the product rule does not describe them. A scale release plus later retargets, which §8.4 requires, builds a mixed list and can reach 65. **Fix:** fold the oldest pair of the same kind. Residuals add offsets and derivatives. Factors keep `f₁·f₂ − 1` and the product-rule derivative.

4. **MATERIAL.** A delayed retarget onto scale 0 has no value. D3 (`:319-323`) holds the new scale component at its starting factor `old/new` through the delay. The new target 0 makes that ratio undefined. Collapsing immediately, per D5 (`:398`), changes the presented scale at the commit, which breaks the same delay rule (`:321-323`). **Fix:** through the delay, hold the pre-retarget presented scale. When the delay ends, if the target is still 0, drop the factor components and present 0. Residuals keep running.

5. **MATERIAL.** The paint band and the colour parity harness disagree, so a colour spring has no single oracle. D6 (`:527`) allows `linear()` to miss the curve by `10⁻²` of the move. `color-spring` runs black to `rgb(255, 128, 0)` (`host/web/src/parity.rs:554-560`) and `check` allows one 8-bit channel (`:43`, `:941-946`); channels are compared in 0–255 (`:891-898`). One percent of a 255-wide channel is 2.55. A fitter that stops at the D6 limit fails that fixture. §8 has no colour case at `10⁻²`. **Fix:** keep physical paint springs on today’s `SpringConfig::easing`. For these spellings, place stops to within one channel of the move, or state that `COLOR_TOLERANCE` does not cover them and add a colour fixture at `10⁻²`.

6. **MINOR.** `R scale-to-zero` cannot be replayed raw. Every sample in `ios-27.0.txt:9669` is 0, including `t < t1`, and `fit.mjs:245` models that as 0 for the whole sweep because the probe seeks after both calls have written the model (`fit.mjs:255`). D5 (`:396-398`) requires 0 only from the retarget on. The first component is scale 2 → 1. §8.4 (`:975-978`) says to replay rows R. **Fix:** pin 0 from the retarget time on, and pin the pre-retarget samples from the first component alone.

7. **MINOR.** D3’s critical end is not a unique f64, while D2 (`:259-260`) says D3’s end times are bit-identical on every host. D3 (`:283-284`) says “bisection to f64 resolution” and does not fix the bracket or which side of the root is returned. `fit.mjs:71` returns the left endpoint of 200 iterations from a doubling bracket. **Fix:** specify that procedure, including the doubling bracket and the left endpoint, as the definition of the end.
