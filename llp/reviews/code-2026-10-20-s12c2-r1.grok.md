## BLOCKING

**Param folds are looked up under a mangled name — `contract/lower/src/anatomy.rs:412`**

`params::rewrite` has already turned a row's `param.op` into its token name (`param.f<hash>.Card.op`) before `check_anatomy`. The closure then does `strip_prefix("param.")` and runs `token_name` again, so `measure_values` is asked for `param.<hash>.Card.f<hash>.Card.op`. That misses, and `values` falls through to the raw token string, which `denied` does not treat as zero. `opacity="param.op"` (or a length param) whose default or any tuple is 0 is allowed. Fold the text that is already on the row; it is the name `MEASURES` holds.

**Unset base names and `calc` are assumed safe — `contract/lower/src/anatomy/slot.rs:313`**

`measure_values` does not do what D4 asks for on every chain value.

- A bare base name is not expanded per column. `scale::expanded` only rewrites values that contain `(`, and `scale::values` (the direct `width="radius.sm"` path) drops the terminal column (`contract/lower/src/scale.rs:33`). Every `radius.*` cell on the terminal is `0ch`. `width` / `max-width="radius.sm"`, or a token whose value is that name, is not refused.
- A literal the checker cannot read (`calc(0px)`, `min(0px, 10px)`, `clamp(0px, 0px, 0px)`) makes `number` return `None`, and `denied` then returns `None`. The kernel lays those lengths out. D4 says an unfoldable value is refused.

`0`, `0px`, `0%`, `-0`, `0.0`, and `1e-9` behave as they should. A length or number token that is already px or a unitless number, including `lib.op` in one tuple, is checked.

## SHOULD-FIX

**`denied` is not the whole rule the IR describes — `contract/lower/src/anatomy/slot.rs:46`**

`denied(row, value)` covers the longhands and SVG `transform` only. `font` is split into size and leading in the private `values` helper, and `hidden` / `inert` / `aria-hidden` / `popover` are decided by `denied_attr` on the AST. `chain` records both as ordinary `(row, value)` pairs (`slot.rs:377`), which is what stage D is told to pass to `denied`. `denied("font", "0px/1 system-ui")` and `denied("hidden", "true")` are both `None`. Attribute values also never walk `?:` / `match` / `let` leaves, so `hidden=(false)` is refused as computed.

**A vendored dependency re-exported by the entry is treated as this package's — `contract/cli/src/sources.rs:778`**

"Same package" is `canonicalize(path).starts_with(package_root)`. A dependency that actually sits under that root (`package/node_modules/...`) passes, and its components join `File::library`. Hoisted and linked deps canonicalize outside the root and are excluded. Compare package roots, not a path prefix.

**A re-export through a barrel is missed — `contract/cli/src/sources.rs:786`**

Only components declared in the file the entry `use`s are taken. `scope_of` follows Contract re-exports through that file's own uses (LLP 1091 D3). `index` → `barrel` → `card.contract#Card` is a real export and is not checked.

**A class row the node itself sets is still a hit — `contract/lower/src/anatomy/slot.rs:239`**

`class::rows` drops a class row when the node sets the same name, and D3 says the node wins inside a layer. The slot walk unions every class attribute with the node's, so `class=Gone` (`display: none`) plus `display="flex"` on the node is refused even though the merged row is `flex`. State-layer names (`:disabled opacity`) are distinct and should stay.

**SVG `transform` is not the kernel's grammar — `contract/lower/src/anatomy/slot.rs:68`**

`kernel/src/svg/transform.rs` parses case-insensitively, allows commas between functions, and treats `scaleX(0)` / `scaleY(0)` as a zero scale. `collapses` misses `Scale(0)`, `translate(0), scale(0)`, and `scaleX(0)`, and it uses `det == 0.0` rather than the kernel's `abs(det) < 1e-12`. `is_svg` (`slot.rs:265`) is also a subset of `svg::is_element`: `foreignObject` (which can hold the fill), `tspan`, and `symbol` skip the check. `scale(0)`, `scale(1, 0)`, and `matrix(...)` with an exact zero determinant do match.

## NIT

**Any letter run counts as a unit — `contract/lower/src/anatomy/slot.rs:40`**

`0auto` and `0none` parse as zero. Real units (`px`, `%`, `ch`) are fine.

## What checks out

D0's main path matches the spec. A package is in scope only when `private` is boolean `true` and `package_design` finds a file, including one named by `package.json` `"tamber"`. The entry is `exports` `"."` (string, `contract`, or `default`) or else `index.contract`, the same `entry()` stage 11 uses. Identities are assigned at load and `scope` does not rewrite `params`, so the pre-scope list still matches after renames. A direct `use` matches `UseName.name` (the declared name, not the alias). Public packages, packages with no design file, and helpers the entry never declares or `use`s are skipped. Hoisted and linked roots are the canonical manifest directory, so the entry path lines up with loaded sources.

Placement is once, at any depth, for `if`, `match`, and `for`, and any `children` under a `Use` is forwarding. Those flags stick through nesting, so a `children` inside a use inside an `if` is refused. `children` as a direct child of `view`, with an empty chain, is allowed: there is no ancestor that can hide it.

The longhands on the list are checked on every chain element, from class branches and from state layers, and a node off the chain is not. `inset` and `flex` are not mistaken for `width`. `display` / `visibility` are case-insensitive. `hidden=false`, `aria-hidden=false`, and bool `false` are not refusals; `popover` is refused for any value. The check runs for a library component that has `slot` even when it has no parts, and it only pushes errors, so a clean plan is unchanged.
