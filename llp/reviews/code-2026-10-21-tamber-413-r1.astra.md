1. **SHOULD-FIX — [scripts/tamber-request.mjs:13](/tmp/rv-dt-413-1-astra/scripts/tamber-request.mjs:13): closed requests retain the fallback timer.** It clears only on `end`, which an aborted request need not emit. Bun closing early therefore leaves the timer retaining `req` for five seconds; the shared reader’s listeners can retain nearly 1 MiB of chunks too. This is bounded retention, not a permanent leak, but repeated refusals accumulate it. Clear on request/socket closure and release the reader’s buffered chunks and listeners when settled. `unref()` does not release them.

2. **SHOULD-FIX — [scripts/tamber-server.mjs:1425](/tmp/rv-dt-413-1-astra/scripts/tamber-server.mjs:1425): GET/HEAD bypass body admission.** Previously every method passed through the bounded reader. 3. **SHOULD-FIX — [scripts/tamber-server.mjs:534](/tmp/rv-dt-413-1-astra/scripts/tamber-server.mjs:534): early refusal can expire before its answer.** If an authenticated remote request arrives while `ready` remains pending, `early` starts the five-second destroy timer, but the 413 waits behind `await ready`. A startup delay exceeding five seconds still produces a closed connection without the answer. Handle the oversized result before waiting for readiness. The remote connection deadline also remains active while that refused body is paused.
