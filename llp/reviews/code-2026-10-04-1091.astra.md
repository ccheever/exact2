1. **[Major] Deploy can read live library bytes after capturing the snapshot.** [scripts/deploy.mjs:193](scripts/deploy.mjs:193), [materialization:529](scripts/deploy.mjs:529).  
   Input: an app with a locked dependency `"ui": "file:/work/ui"` and `use Card from "ui"`. The new discovery captures `/work/ui`’s repository, but materialization preserves that absolute dependency string and reinstalls it unchanged. Editing `/work/ui/index.contract` after capture can therefore change the bake without changing the captured snapshot identity. `bun link` has the same problem with its external link destination. Contract dependencies need relocation or a closure check after installation.

2. **[Major] The entry file incorrectly determines the package boundary and manifest.** [contract/cli/src/resolve.rs:239](contract/cli/src/resolve.rs:239).  
   Input: `ui/package.json` exports `"./src/card.contract"`; `ui/src/package.json` contains `{"type":"module"}`; `card.contract` uses `"../styles.contract"`. Resolution treats `ui/src` as the package root and wrongly rejects that valid relative import. Without the relative import, baking still stages the nested manifest instead of the manifest whose exports were consulted, changing subsequent resolution. Conversely, an exported file symlink into another package adopts that destination’s boundary without verifying containment in the exporting package.

3. **[Major] Timeline literals inside `match` miss alias and collision rewriting.** [contract/syntax/src/scope.rs:386](contract/syntax/src/scope.rs:386).  
   Input: `use Activity as Shared from "exact:motion"`, a local `timeline Activity`, and two elements respectively using:
   ```
   animation-timeline="clock(Shared)"
   animation-timeline=match opt { case some(x) => "clock(Shared)", case none => "auto" }
   ```
   With `state opt = some(1)`, both should share the imported timeline. A read-only compiler probe confirmed the first becomes `clock(Activity__exact_motion)` while the second remains `clock(Shared)`. They consequently use different clock groups. The rewrite handles ternaries but omits `Expr::Match`.

4. **[Major] Animation rewriting treats CSS keywords as keyframe references.** [contract/syntax/src/scope.rs:368](contract/syntax/src/scope.rs:368).  
   Input: the root declares `keyframes linear` and imports `Spinner` from `ui.contract`; that library declares `keyframes spin` and renders `animation="spin 1s linear"`. Compilation wrongly reports `contract-use-missing` for the easing keyword `linear`. If the library also declares `linear`, collision renaming instead changes the easing token to `linear__ui`, corrupting the shorthand. This pass must distinguish animation names from easing, direction, iteration, fill, and play-state tokens.

5. **[Major] Package aliases lose their staging information on a diamond.** [contract/cli/src/sources.rs:223](contract/cli/src/sources.rs:223), [js/bake/src/lib.rs:542](js/bake/src/lib.rs:542).  
   Input: dependencies `"a":"file:../ui"` and `"b":"file:../ui"` both resolve to the same canonical `ui/index.contract`, exporting `Card`; the app imports `Card as A from "a"` and `Card as B from "b"`. Original compilation succeeds and correctly shares the declaration. However, the cache hit discards the second resolution’s origin, so the source graph records only `a`. Baking stages only `node_modules/a`; recompiling the staged app fails to resolve `b`. Declaration deduplication must retain both resolution edges.

6. **[Major] Curried local actions are resolved as top-level functions.** [contract/syntax/src/scope.rs:439](contract/syntax/src/scope.rs:439).  
   Input: `ui.contract` declares `fn pick(x: number): number = x` and a component `Card`. The root imports only `Card`, declares `state n=0` and `action pick(x: number)` assigning `n=x`, and renders `button press=pick(1)`. The rewriter checks that handler against the top-level call namespace and rejects it as an unimported `ui.contract` function. The local action is a valid binding and should win. Calls through action props and injects are exposed to the same failure.

7. **[Minor] Generated internal names bypass module visibility.** [contract/syntax/src/scope.rs:74](contract/syntax/src/scope.rs:74).  
   Input: root and `ui.contract` both declare `Helper`; the root imports only `Card` from `ui.contract`, then calls `Helper__ui()`. The library’s helper receives exactly that generated name. Because `elsewhere` contains authored names only, the unresolved reference passes through unchanged and later binds to the unimported library helper. An unknown authored name must not acquire visibility merely by matching a generated identifier.

8. **[Minor] Failed package resolutions omit the files needed to recover watching.** [contract/cli/src/sources.rs:211](contract/cli/src/sources.rs:211), [host/web-js/dev.mjs:96](host/web-js/dev.mjs:96).  
   Input: `use Card from "ui"` with installed `ui/package.json` containing `{"exports":"./missing.contract"}`. Start development, then fix that manifest to export an existing `index.contract`. The resolver fails before recording any package source or manifest, so no package watcher is installed; the app watcher ignores `node_modules`. The wasm watcher likewise lacks the manifest and suppresses recompilation when root bytes remain unchanged. The fix is invisible until another watched file changes.
