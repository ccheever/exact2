R2’s fixes for closure-based live/rebuild classification, attribute provenance, conditional-style refusal, relay permissions, authenticated capture delivery, held-state inspection and proposal acceptance are present. These issues remain:

1. **MAJOR — D3/D5: capture freshness is only partly fixed.** Captures now carry generation identity, but [selection still checks only epoch](/Users/admin/x2theme/rev-dtool/llp/1122-design-tool.rfc.md:270). Reloads can reuse epochs; host-only changes need not advance them. Pausing live-table batches also does not stabilize image loading or native presentation: the [screenshot driver stamps replies before waiting and capturing](/Users/admin/x2theme/rev-dtool/scripts/agent.mjs:493). **Fix:** bind point-picks to the complete capture identity, validate it during hit-testing, and include host presentation changes in capture invalidation. Specify a capture barrier covering pixels and geometry, beyond withholding design batches.

2. **MAJOR — D6: scrub sessions need concurrency and recovery semantics.** [Previewing without writing, then restoring “their snapshot”](/Users/admin/x2theme/rev-dtool/llp/1122-design-tool.rfc.md:353) leaves overlapping scrubs and intervening committed edits undefined. Restoring the gesture’s starting snapshot after another client commits would display obsolete values. Tamber’s [digest checks and reconnect snapshots](/Users/admin/x2theme/rev-dtool/llp/1121-tamber.rfc.md:916) do not define this temporary divergence. **Fix:** allow one bounded scrub owner; cancel or explicitly rebase it before competing writes; restore the latest committed file-derived snapshot. Define release failure, server loss and tile reconnection, including how preview state expires.

3. **MAJOR — D9: the revised commit guard still admits unrelated edits.** In [the specified guard](/Users/admin/x2theme/rev-dtool/llp/1122-design-tool.rfc.md:472), `server write → hand edit → another server write` passes: current content equals the server’s last write, and HEAD remains unchanged. The hand edit is nevertheless included. A temporary index also leaves committed paths’ entries stale in the real index unless reconciled. **Fix:** require uninterrupted ownership from a clean baseline, preserving evidence of intervening edits across later writes; check and reconcile affected real-index entries without disturbing other staging. Deferring `commit` from T1 would remove substantial complexity.

4. **MAJOR — D3: requested preferences do not guarantee the advertised mode.** [Tiles are described as scheme-pinned](/Users/admin/x2theme/rev-dtool/llp/1122-design-tool.rfc.md:218), but [`prefer prefers-color-scheme` changes the system preference; an app’s `setScheme` still wins](/Users/admin/x2theme/rev-dtool/scripts/agent.mjs:1277). A tile labelled Light can therefore remain dark. **Fix:** distinguish requested and effective traits, verify the effective combination before labelling a capture, and drive the app’s appearance setting or use D4’s explicit preview boundaries when necessary. Restore and verify pins after reload.

5. **MAJOR — D12/D13: remote authentication lacks a transport-security requirement.** [Pairing and authenticated sockets](/Users/admin/x2theme/rev-dtool/llp/1122-design-tool.rfc.md:525) do not protect credentials or captures in transit. The [existing JS dev loop serves plain HTTP](/Users/admin/x2theme/rev-dtool/host/web-js/dev.mjs:15); neither RFC requires an encrypted remote transport. **Fix:** require authenticated TLS or an explicitly trusted encrypted tunnel for remote pairing and subsequent traffic. Include rejection of unprotected remote connections in T6’s gate.

An initially unformatted file cannot survive that inverse byte-for-byte. **Fix:** define a server-issued, digest-guarded byte-restoration inverse that bypasses formatting.
