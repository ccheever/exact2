5. **Concrete language sketch.**

   ```contract
   // app.contract
   component T3Code
     include "./features/clock.contract"
     view
       text `${elapsed}`

   // features/clock.contract
   partial component T3Code
     state elapsed = 0
     task clock mount
       every(1000, tick)
     action tick
       elapsed = elapsed + 1000
   ```

   The short design should specify:

   - One primary declaration explicitly lists its parts; no automatic same-name merging, globs or reusable mixins.
   - Parts contain imports and member declarations. The primary owns the interface sections and view. Existing root-only restrictions apply **after assembly**.
   - Members share component scope; imports remain local to the file writing each expression. Relative paths resolve from that file within the existing app/package boundary.
   - Parts splice at their written position, preserving declaration and initialization order. Reject duplicate members under existing namespaces, reporting both locations; reject duplicate inclusion and cycles.
   - Parts introduce no runtime instance. Preserve primary component identity, member names and physical source spans. Require equivalent execution, correct navigation, and unchanged reload retention when merely moving declarations.
