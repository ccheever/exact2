3. **Major oversights**, ordered by severity:

- **MAJOR — D7: preserve semantics before choosing presentation.** Native lowering needs shared columns across row groups, span placement, captions, and header associations. A grid declaration plus ARIA roles does not establish those. Likewise, `dt dt dd` and `dt dd dd` are valid description-list groups; alternating cells in two columns misrepresents them. Specify the semantic model and a conforming layout subset, then platform presentation. A temporary Mac grid may be staged explicitly, but cannot be the claimed equivalent end state. [HTML description lists](https://html.spec.whatwg.org/multipage/grouping-content.html#the-dl-element)

- **MAJOR — D5: define fragment navigation, not just a settlement callback.** Retained detail pages can each contain `id="moves"`; document-wide lookup can select a hidden visit. Fragment-only links also interact with the root `<base>`, browser history, and router state. Define target selection within the active entry, raw/decoded fragment handling, repeated navigation, Back/Forward restoration, and cancellation when the user or author has already scrolled. Preserve focus navigation and target state as well as position. [HTML’s fragment algorithm](https://html.spec.whatwg.org/multipage/browsing-the-web.html#scroll-to-the-fragment)

- **MAJOR — D1/D3: web-only native discovery has no producer.** D3 removes the bake but retains an envelope supposedly consumable by native clients. Today that bake produces the native module artifacts; the JS builder copies them. An envelope alone cannot run `app.ts` natively. Separately, opening a dev URL starts resident producers without passing through an `ios`/`mac` verb. Choose an explicit native preparation boundary or a crate-free producer, and explain which artifacts exist before it. See [build.mjs:681](/Users/ccheever/projects/exact2/host/web-js/build.mjs:681) and [dev.mjs:1054](/Users/ccheever/projects/exact2/host/web-js/dev.mjs:1054).

- **MAJOR — D4: environment values must be captured build inputs.** Substitution alone leaves stale native builds, inconsistent grants, and unreproducible releases. Existing web fingerprints specially track only `EXACT_BACKEND_ORIGIN` and `PORT` ([agent-launch.mjs:989](/Users/ccheever/projects/exact2/scripts/agent-launch.mjs:989)). Capture selected names, values, sources, and missing-file dependencies once; use that snapshot for every producer, renderer, cache, and deploy. Specify public exposure explicitly. Also control Bun’s automatic dotenv loading: otherwise working-directory values can already occupy `process.env` and defeat the stated precedence. [Vite documents both exposure and Bun’s interaction](https://vite.dev/guide/env-and-mode).

- **MAJOR — D6: the importer silently changes theme behavior.** `.dark` and `[data-theme="dark"]` are author-controlled selectors, not necessarily system appearance. Admit a precise import subset, preserve explicit theme selection through Tamber modes, and refuse unsupported semantics rather than presenting retained text as a successful translation. CSS fallback depends on the custom property’s computed validity, not merely whether a declaration exists. [CSS Custom Properties](https://www.w3.org/TR/css-variables-1/#using-variables)

Shared crates also require explicit ownership: removing iOS must preserve macOS’s `apple/`; removing Linux must preserve Android’s crate. See [app.mjs:514](/Users/ccheever/projects/exact2/scripts/app.mjs:514) and [app-cli.mjs:196](/Users/ccheever/projects/exact2/scripts/app-cli.mjs:196).
