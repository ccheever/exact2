## Review (received 2026-08-29T11:03Z, verbatim)

## Overall assessment

The happy path works, but the implementation is not ready: kernel constraint handling breaks intrinsic ratios, and the macOS loader crosses undeclared security boundaries. Several parity claims also exceed what the tests establish.

## Findings

1. **HIGH —** Intrinsic ratios break under min/max constraints. Exact supplies Taffy an intrinsic `aspect_ratio` ([kernel/src/style.rs:560](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/kernel/src/style.rs:560)) while measurement independently returns the natural width and height ([kernel/src/layout.rs:176](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/kernel/src/layout.rs:176)). Taffy then clamps axes independently and only floors height from width ([vendor/taffy/src/compute/leaf.rs:161](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/vendor/taffy/src/compute/leaf.rs:161)). Thus a 320×120 image with `max-width:100px` can become 100×120, while `max-height:40px` can be overridden back to 120px. This is an undeclared browser divergence. Resolve it with CSS’s replaced-element constraint algorithm in the image measure path or a focused Taffy correction, plus width/height/min/max matrix tests.

2. **HIGH —** macOS performs unrestricted, unbounded file and network reads. Any source with a scheme—including `file:`—is accepted, while relative `..` paths are appended without canonical containment beneath `EXACT_ASSETS` ([Presenter.swift:80](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/apple/macos/Sources/ExactMac/Presenter.swift:80)). `Data(contentsOf:)` then buffers the entire resource without timeout or size limits ([Presenter.swift:93](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/apple/macos/Sources/ExactMac/Presenter.swift:93)). This permits local-file access and memory exhaustion that a web-origin `<img>` does not. Canonicalize and contain asset paths, define an explicit scheme policy, and use a capped, timed loader with pixel-dimension limits. FLAG: AppKit may defer decompression until `draw`; the code does not force or prove off-main decoding.

3. **MEDIUM —** Native `object-fit` uses the border box instead of CSS’s content box. Taffy frames include padding and borders, but Swift scales, centers, and clips directly against `bounds` ([Presenter.swift:237](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/apple/macos/Sources/ExactMac/Presenter.swift:237)). Any image with padding or borders therefore paints underneath those insets and gets different `contain`, `cover`, `none`, and `scale-down` geometry from the browser. Resolve padding and border values into a content rectangle and use that rectangle for scaling, centering, and clipping.

4. **MEDIUM —** The intrinsic-size boundary admits non-finite values. `Kernel::set_intrinsic_size` stores values without validation ([kernel/src/kernel.rs:207](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/kernel/src/kernel.rs:207)); the ABI clears NaN accidentally but accepts positive infinity ([host/apple/src/abi.rs:165](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/apple/src/abi.rs:165)). Infinite layout values can become `inf` in the hand-written batch JSON, which Swift rejects. Validate finite positive dimensions at the kernel seam, restrict reports to `Image` nodes, and make the ABI reject non-finite input while retaining the documented finite-≤0 clear operation.

5. **MEDIUM —** Source-string equality is not a sufficient load generation. The completion guard only checks `self.imageSource == source` ([Presenter.swift:96](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/apple/macos/Sources/ExactMac/Presenter.swift:96)), so an A→B→A sequence can accept the first stale A request. A source change also clears the bitmap immediately but leaves the old kernel intrinsic size until completion ([Presenter.swift:88](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/apple/macos/Sources/ExactMac/Presenter.swift:88)). Use a monotonically increasing request token and consistently either retain both old image and size while pending or clear both.

6. **MEDIUM —** The result-equality gate does not cover loaded images. `Kernel::rehydrate` clones the arena—and therefore intrinsic host state—despite LLP 1011 describing rehydration as losing that state ([kernel/src/kernel.rs:322](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/kernel/src/kernel.rs:322)). Conversely, replaying operation batches cannot restore an intrinsic report. The randomized equality test creates images but never calls `set_intrinsic_size`, so they remain 0×0 ([kernel/tests/layout_equality.rs:239](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/kernel/tests/layout_equality.rs:239)). Decide whether reports belong in the rehydration snapshot or are replayed host side-inputs, then test loaded images through rehydrate, replay, destroy, and slot reuse.

7. **MEDIUM —** The harnesses do not establish painting or browser parity. The web unit test only searches serialized batch text ([host/web/tests/host.rs:248](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/web/tests/host.rs:248)); the web smoke never asserts the logo, and the Apple smoke checks load/frame log strings only ([host/apple/smoke.mjs:24](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/apple/smoke.mjs:24)). Nothing exercises Swift `draw`, failed/cleared/changed sources, padding, or `cover`/`none`/`scale-down`. Add browser-layout fixtures and native pixel assertions for the sizing and fit matrix; mutation tests should cover success, failure, clear, A→B, and A→B→A.

8. **LOW —** Web images receive `aria-label` but no native HTML `alt` attribute ([host/web/src/host.rs:328](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/web/src/host.rs:328)). Although `aria-label` can supply an accessible name, it does not provide `<img>`’s standard text alternative or broken-image fallback. Special-case `accessibilityLabel` on `Image` to emit `alt`—optionally retaining `aria-label`—and test set and clear behavior.

9. **LOW —** Asset builds can preserve deleted images. `cpSync` merges into an existing `dist/assets` directory without clearing it ([host/web/build.mjs:27](/private/tmp/claude-501/-Users-ccheever-projects-exact2/5ff4e6b5-3538-4658-9897-2da74dac71b9/scratchpad/review-image/capsule/host/web/build.mjs:27)), so a removed source asset can continue loading on web while failing on macOS. Replace the destination atomically or remove it before copying.
