## Assessment

I found no actionable lifecycle or ownership defect in the inspected haptic
wiring. Keep the governing decision Draft. Source and isolated runner evidence
support command generation; combined-root and physical-device behavior remain
unverified.

The root records a baseline per route entry. Its descriptor checks loaded thread,
environment and thread identity against the actual shared client. The delayed
action also checks the current route and root data identities before emitting a
command. Removing a route prunes its baseline, so reopening hydrates silently.

The transition matches pinned ThreadDetailScreen.tsx lines 263-310 at
365aa87982a4d81cc8e0c085e8d1a40ca7daecdc. New message identity bypasses the 320ms
growth throttle. A throttled growth update still advances the baseline. Completion
clears the message identity; shrink and same-length edits remain silent. The task
key contains the descriptor, not elapsed time, so clock advancement alone cannot
emit a delayed pulse. The pinned effect has no focus guard, which supports keeping
the selected base-thread tracker beneath a child route.
