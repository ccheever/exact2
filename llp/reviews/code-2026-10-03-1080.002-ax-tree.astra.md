# Code review: LLP 1080.002 — tree --ax (astra)

**Reviewer:** Astra (codex gpt-6-astra, xhigh), 2026-10-03, diff cd7d2533..a6d847f1

**Verdict:** DO NOT SHIP — a test module cannot parse, and several collectors can report incorrect or falsely complete results.

1. **High — The partial test deletion breaks the entire app test module.**  
   [scripts/app.test.mjs:351](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/scripts/app.test.mjs:351) retains two assertions and `});` after deleting their enclosing test. Running `bun test scripts/app.test.mjs --test-name-pattern 'rendered tree'` fails with `Unexpected }` at line 353 before any tests execute. **Fix:** delete the remaining obsolete assertions and closing delimiter; retain focus-rendering coverage in a valid test.

2. **High — A reload can join the new document’s accessibility tree to the old document’s intent.**  
   [scripts/agent-ax.mjs:301](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/scripts/agent-ax.mjs:301) reads plain `tree` before `webAx`, but compares only epoch and incarnation. The nonce brackets only the later CDP reads and is discarded from their reply. JS pages restart with incarnation `1`, so a reload between these reads can reuse both tags and numeric IDs. An in-memory reproduction joined a new button to the old `testId` and emitted a false `exposed-hidden` finding without `spanned`. **Fix:** include the plain-tree read within the same document-nonce bracket and retry the whole collection on a mismatch.

3. **High — AppKit silently drops valid accessibility objects outside two concrete classes.**  
   [AgentAccessibility.swift:160](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/host/apple/Sources/ExactKit/AgentAccessibility.swift:160) accepts only `NSView` and instances of the `NSAccessibilityElement` class. An `NSCell` or another accessibility-conforming `NSObject` returned by AppKit matches neither; it gets no facts or children, while coverage remains complete. The installed SDK explicitly declares `NSCell` as an accessibility-protocol participant. **Fix:** read the accessibility protocol rather than restricting concrete classes, resolve cell ownership through its control, and restore checkbox and secure-field collector tests. Collector omissions must not be attributed to AppKit without this coverage.

4. **Medium — UIKit’s visit budget does not bound enumeration work.**  
   [AgentAccessibility.swift:134](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/host/apple/Sources/ExactKit/AgentAccessibility.swift:134) materializes every declared child or calls `accessibilityElement(at:)` for the entire reported count before `visit` checks its budget. The subsequent loops also continue calling `visit` after `w.stopped`. A large accessibility container therefore performs unbounded work on the main thread even with `limit: 1`. **Fix:** enumerate incrementally against the remaining visit budget, stop child loops immediately, and mark unfinished enumeration as unknown truncation.

5. **Medium — The 256 KB reply limit is not enforced.**  
   [scripts/agent-ax.mjs:167](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/scripts/agent-ax.mjs:167) measures UTF-16 string length, estimates one element reduction, and leaves all intent and findings intact. A reproduction with 2,000 permitted elements returned **895,494 bytes** after trimming, retaining 2,000 findings for only 234 returned elements. Native replies also cross the transport before this reduction. **Fix:** enforce an actual serialized UTF-8 budget at the producer, bound auxiliary fields, and rebuild findings/intent consistently when elements are removed.

6. **Medium — macOS never reports an attached sheet as modal.**  
   [AgentAccessibility.swift:40](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/host/apple/Sources/ExactKit/AgentAccessibility.swift:40) adds sheet content to the roots, but `w.modal` starts false and its only assignment is inside the iOS branch at line 108. Consequently, `outside-modal` cannot fire on macOS, even when background elements remain exposed beside an attached sheet. **Fix:** identify the session-owned sheet’s AX root, populate `modal.present`, `element`, and `by: "sheet"`, and test a background leak through the collector.

7. **Medium — UIKit returns modal-hidden siblings as exposed elements.**  
   [AgentAccessibility.swift:292](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/host/apple/Sources/ExactKit/AgentAccessibility.swift:292) merely writes `outsideModal: false` onto siblings hidden by the documented modal rule. It neither removes them nor marks them excluded. They remain eligible for `unnamed` and `exposed-hidden` findings and inflate exposed coverage. The new iOS test at line 105 explicitly expects this incorrect inclusion. **Fix:** apply modal exclusion to the exposed collection and change the test to require hidden siblings to be absent.

8. **Medium — Targeting a control inside a modal produces a false outside-modal finding.**  
   [scripts/agent-ax.mjs:152](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/scripts/agent-ax.mjs:152) removes AX ancestors before computing findings. The containment lookup at line 192 then cannot reach the removed modal element. A two-element dialog/button reproduction reports the button as outside its own dialog when targeting the button. **Fix:** compute containment and findings against the complete collected tree before filtering, or preserve the ancestry needed by the classifier.

9. **Medium — Projected segments never join to their originating tabs.**  
   [AgentAccessibility.swift:268](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/host/apple/Sources/ExactKit/AgentAccessibility.swift:268) implements ownership for node views, declared elements, and ancestry, but contains no segment-to-tab resolution. Both segment hosts hide authored tabs and place the native segmented control under the tablist; neither adopts `AgentOwned` for individual segments. Exposed segments therefore resolve to the tablist or remain unjoined, so targeting an authored tab misses its exposed control. **Fix:** resolve each platform segment through the existing member mapping and test distinct tab IDs, as D5 requires.

10. **Medium — The macOS roots omit the session’s projected toolbar.**  
    [AgentAccessibility.swift:32](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/host/apple/Sources/ExactKit/AgentAccessibility.swift:32) returns only the `ExactView` and attached-sheet content. Window toolbar elements live outside that subtree, while `ToolbarMac.swift:282` hides their authored originals. The resulting read omits these controls but can claim complete coverage. **Fix:** include the session-owned toolbar’s exposed AX objects and join projected commands using the toolbar’s ownership mapping; verify a toolbar command survives projection in `tree --ax`.

11. **Medium — Parity treats missing observable states as agreement.**  
    [scripts/agent-ax.mjs:249](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/scripts/agent-ax.mjs:249) substitutes `false` for absent states and explicitly suppresses heading-level differences when either side is missing. Reproducing web `level: 2` against missing AppKit level, and web `checked: false` against missing AppKit checked state, returns no findings. This contradicts D6’s observable-but-missing rule. **Fix:** distinguish unsupported, inapplicable, missing, and present states; report missing applicable states before comparing values.

12. **Medium — The web depth cutoff silently produces complete coverage.**  
    [scripts/agent-ax.mjs:127](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/scripts/agent-ax.mjs:127) stops traversal at depth 256 without recording truncation. Coverage depends only on the element-limit counter. A reproduction with ignored ancestors above an exposed button returned zero elements, `coverage.complete: true`, and `axClean: true`. **Fix:** record every traversal cutoff as incomplete coverage and truncation; account for omitted descendants when reporting the web’s omitted-element count.

13. **Medium — The native wire form ignores targeting and required validation.**  
    [AgentAccessibility.swift:21](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2-1080.002/host/apple/Sources/ExactKit/AgentAccessibility.swift:21) never examines `target` or `shallow`, and a non-integer `limit` such as a JSON string silently becomes 500. Thus a direct request with a stale target or `shallow: true` returns the full tree instead of refusing it. Driver-side handling does not repair the advertised wire API. **Fix:** enforce D1/D7 validation and target scoping at the native request boundary, with direct-wire tests.
## Disposition (Claude, fix round 1 of 3, 2026-10-03; rebased onto origin/main 2d461a0c)

1. **Fixed.** The orphaned assertions are gone; a valid test renders focus and no `name=` (`scripts/app.test.mjs`). `bun test scripts/app.test.mjs -t 'rendered tree'` passes.
2. **Fixed.** `webAx` reads stamp → plain tree → AX tree → snapshot → stamp inside one nonce and retries the whole read; the plain tree's tags must match the stamp. A native read checks the plain tree's tags before and after its `ax` read. Test: "the plain tree is read inside the document bracket…" (a reload between stamps yields the second document's intent, unspanned).
3. **Fixed.** Any participant other than a view or an element (a cell, AppKit's own parts) is read through the attribute protocol; a cell joins its control's view and takes its control's frame. Checkbox and secure-field collector test restored (`testCellsAreWalkedAndASecureValueIsOmitted`). r1's "absent from AppKit's tree" claims were the collector's; RFC §7 and QUEUE now say so, and Caltrain's macOS search field reads `textbox "Search stations"`.
4. **Fixed.** Children are taken only up to the visits left (`accessibilityElementCount` is indexed no further than that); child loops stop on `stopped`; an unfinished enumeration is `truncated.elements: "unknown"`. Test: `testAWalkStopsEnumeratingAtItsBudget` (100,000 reported, under 200 asked).
5. **Fixed.** The driver enforces 256 KB of serialized UTF-8 and rebuilds intent and findings from the kept elements; native producers stop emitting at 240 KB of element JSON. Test: 2,000 elements with 200-character UTF-8 descriptions fit, with findings only for kept elements.
6. **Fixed.** A session's attached sheet is emitted as the modal (`by: "sheet"`) and the driver judges the window behind it against it (`basis: "sheet"`). Test: `testASheetRootIsReportedAsTheModal`. Not driven in an app with a sheet.
7. **Fixed.** For a session-owned modal view UIKit's sibling rule removes the siblings (`excluded: ["modalSibling"]`, listed only with `excluded: true`); the test now requires them absent. For a modal view UIKit owns (a presentation's dimming view) the rule is not reproduced and coverage is incomplete, naming it.
8. **Fixed.** Findings are computed over everything collected, then the target scopes the elements and the findings. Test: a button targeted inside its dialog has no `outside-modal`.
9. **Narrowed.** The segment-to-tab join is not built. An element under a `UISegmentedControl`, `UITabBar` or `NSSegmentedControl` sets `coverage.limits: "segments"` (it joins its tablist). RFC §7.1 says so.
10. **Narrowed.** A window toolbar the session projected is not walked; coverage is incomplete with `excluded: [{root: "toolbar", …}]`. RFC §7.1 says so.
11. **Fixed.** A state that applies to the role (`checked` for a checkbox, `level` for a heading) and that both sources can observe is a `missing` finding when either side lacks it; `disabled`, reported only when true everywhere, treats absence as false. Test: web level 2 / checked false against AppKit without them gives two `missing` findings.
12. **Fixed.** A depth cutoff counts, makes coverage incomplete and the remainder `"unknown"`. Test: 300 ignored ancestors over a button give no elements, incomplete, never clean.
13. **Fixed.** The native wire refuses `shallow`, a non-integer or out-of-range `limit`, a non-boolean `excluded` and a stale `target`, and scopes a targeted read with its `ancestors`. Tests: `testATargetScopesTheReplyAndTheWireRefusesWhatD1Refuses` (iOS), `testATargetScopesTheReply` (macOS).

Found while fixing 3: on macOS, AppKit's name for a text field falls back to its placeholder; the walk now does too (before, Caltrain's search field read as unnamed).
