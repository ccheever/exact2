**1 BLOCKER, 2 SHOULD, 2 NIT.**

- **BLOCKER — Held-ticket disappearance is not proof of a reply.** [scripts/agent-held.mjs:19](/tmp/rv-held/scripts/agent-held.mjs:19). Three cases break the ruling:
  - An unrelated `looseFetch` removes held classifications temporarily. The driver returns success after `clock data`, although the original held fetch never replied.
  - Superseding a request also removes its ticket and produces false success on every host.
  - On web-js, a reply followed immediately by another held fetch in the same answer retains the answer’s ticket. Polling misses the transition and times out despite receiving the required reply. New requests therefore extend the snapshot’s wait.

  Reproduced these with the actual helper/accounting code, including the fetch wrapper. Completion needs request identity and reply evidence independent of the current held classification.

- **SHOULD — The owner filter retains disposed resources.** [host/web-js/held.js:8](/tmp/rv-held/host/web-js/held.js:8). Ending a resource’s scope sets `r.gone` but leaves `r.ticket` intact ([rt.js:542](/tmp/rv-held/host/web-js/rt.js:542)). Consequently, `heldAsks()` still names its request and subsequent `clock held` waits on a resource that has left the screen. Reproduced through the runtime’s actual scope disposal.

- **SHOULD — Freeze Apple’s clock before starting the wait.** [scripts/agent.mjs:1198](/tmp/rv-held/scripts/agent.mjs:1198). When `clock held` is the first clock operation under `--timing platform`, its early return bypasses clock takeover. State polling does not perform the takeover in [Agent.swift:700](/tmp/rv-held/host/apple/Sources/ExactKit/Agent.swift:700). Reply commits can advance the live runner clock, and hatch timers can fire while waiting. Take ownership before the snapshot. Default agent timing does remain frozen.

- **NIT — Reject non-finite bounds.** [scripts/agent-held.mjs:11](/tmp/rv-held/scripts/agent-held.mjs:11). The digit regex accepts numbers whose conversion or multiplication produces `Infinity`, disabling the timeout. Reproduced acceptance of a 309-digit duration. Validate the converted bound.

- **NIT — Failed-expect advice contradicts the new operation.** [scripts/agent-test.mjs:621](/tmp/rv-held/scripts/agent-test.mjs:621). It still says “no clock waits on” held requests and never suggests `clock held`. For an expected push, name that operation as the remedy.
