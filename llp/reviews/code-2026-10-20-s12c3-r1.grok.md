## BLOCKING

**1. A renamed library param, named the short way, still only warns.** `contract/lower/src/anatomy.rs:436`

`param_lines` emits `tamber-param-short-library` only when `resolve` succeeds, the name has no `#`, and the identity is in `file.library`. D8's other half — a short name that names no param while the component is one the package exports (`Card.gap` after `gap` is removed) — does not start with `{package}/`, so the arm is skipped and `params::unknown` (`contract/lower/src/params.rs:545`) leaves it as the warning `tamber-param-unknown`. The build succeeds. The test (`library_rules.rs:241`) only covers `Card.pad` while `pad` still exists. A full unknown name under `{package}/` does fail the build (`anatomy.rs:437`).

**2. `-exact-*` named lengths are refused on knob rows.** `contract/lower/src/anatomy/library.rs:45`

`named()` accepts `0`/`0px`, a bound theme entry, `measure_values`, `role_named`, or `scale::is_base`. `relative::parse` (`kernel/src/style/relative.rs:284`) accepts `-exact-hairline` and the length ramps through `named_length` (`relative.rs:76`) on padding, margin, gap, and radius. `padding="-exact-hairline"` is a real length and `lower-library-literal`.

**3. A box shorthand is judged as one string, so each side can name a knob and still be refused.** `contract/lower/src/anatomy/library.rs:100`

`rows_of` → `tags::rows` (`contract/lower/src/tags.rs:393`) returns every longhand of `padding`, `margin`, `gap`, `border-radius`, and `border-color` (`style_names.rs:147-175`). If any longhand is a knob, `literals` tests the whole attribute text. Lowering already splits that text per side (`shorthands::sides`, `contract/lower/src/shorthands.rs:703`; `style_values` at `shorthands.rs:603`). So `padding="space.sm space.md"`, `gap="0 space.md"`, `border-radius="radius.lg 0"`, `border-color="lib.ink lib.ink"`, and `padding="0px 0px"` are refused. `border` is worse: `shorthands::rows` (`shorthands.rs:10`) includes `BorderColor*`, so `border="1px solid lib.ink"` is a knob row and the whole shorthand is refused, including the width and style, which are not D1 rows. The colour longhand `lib.ink` would pass on its own.

**4. A colour expression over tokens is a knob only when that exact text is already a theme entry.** `contract/lower/src/anatomy/library.rs:45` and `:82`

`theme::names` is exact match on the bound table. Synthetic entries are the expression text (`theme.rs:453`), and `Said::of` collects them only from styles and the root view (`theme/scan.rs:115`). A param default is never scanned. `fill: color = color-mix(in srgb, lib.ink 40%, white)` is a token value the design folds, does not start with `param.`, and is `lower-library-literal`. The same predicate refuses `color-mix` / `light-dark` on a library component's own element when the app root is a different component: that view is not scanned, so the expression is not an entry. A colour function in a style, or on the root, that names a declared token (or a role the design overrides) does pass.

## SHOULD-FIX

**5. `input type="file"` is checked as a text field.** `contract/lower/src/anatomy/library.rs:253`

The `_` arm requires `value` and `aria-label` or `placeholder`. File is a supported control (`ast.rs:1171`, `controls.rs:189`) and is not in D6's text-kinds row. `input type="file" aria-label="Upload"` is refused for a missing `value`.

**6. `type` is matched case-sensitively.** `contract/lower/src/anatomy/library.rs:239`

`text()` compares `"checkbox"` / `"range"` exactly. `control_type` (`ast.rs:1229`) is ASCII-case-insensitive, and `controls.rs:12` canonicalizes the type. `type="CHECKBOX"` with `checked` and a label misses the checkbox arm and is asked for `value`. `type="RANGE"` misses `min`/`max`.

**7. Determinate `progress` is not required to carry `value` and `max`.** `contract/lower/src/anatomy/library.rs:279`

D6's table is `aria-label`, and `value` with `max` when it shows progress. Only `aria-label` is checked. `controls.rs` treats `progress` with `value` and `max` as `UIProgressView` and `progress` without `value` as the activity indicator.

**8. `displayMode` is not read everywhere.** `contract/lower/src/anatomy/library.rs:317`

The scan is view expressions, states, and derives, and the base must be a bare `Ident` that names an `exactViewport` resource. An action body is not walked, and `(cond ? a : b).displayMode` is not a hit. Resource declarations of `exactDelivery` and `exactSurface` are caught.

**9. `label` ancestry stops at the component that writes the control.** `contract/lower/src/anatomy/library.rs:185`

`labelled` follows a literal `label` ancestor, which the test covers. A checkbox passed into a helper whose view is `label > children` is checked in the writer's view, where no `label` wraps it, and the helper's view only has `children`. D6's "a `label` around it" is the rendered tree.

## NIT

## Checks out

- Knob longhands match D1: padding and margin sides, row/column gap, four radii, `color`, `background-color`, four border colours, `-exact-tint-color`, `accent-color`. Sources are the element's own attributes, the last same-file style each `class` ident names (both arms of a conditional class), and state parts (`rows_of` strips the `:state` prefix). Leaves of `?:`, `match`, and `let` go through `theme::leaves`. `0` and `0px` pass. A param token passes because rewrite runs before `declare_theme`, and the token is a theme entry. Role spellings go through `role_named` (bare name prefixed with `-exact-`, CSS system colours, `var(--exact-…)`). A type or family token is bound (`theme.rs:68`), so its name passes `theme::names`. `transparent`, `currentcolor`, and `auto` margins are refused on purpose. `tamber-range-column` is absent, as requested.
- Control roles match D6, and the native set is `input`, `textarea`, `select`, `progress`, and `button` unless `appearance="none"`. `input type="checkbox" switch` is the checkbox arm (`is_input_switch` is a positional word, `ast.rs:1157`). Date, time, and datetime-local require `aria-label` and do not count label ancestry. Range requires `value`/`min`/`max`/`aria-label`. Select requires `value`, options, and `aria-label`, not a label. An `option` child counts, and so does any non-element (`for` / `when` / `match` / a slot `Use`), which is the right lenience for dynamic options. A native button's face stays `check_native_button`. A redundant role on a native element is allowed.
- Platform applies to every component whose identity starts with a package in `File::library_packages`, so internal helpers are included. Literal and control apply only to identities in `file.library` (entry exports). The loader sets both after `scope()` returns (`sources.rs:246-248`), which overwrites `merge`'s empty vec (`sources.rs:1318`). `sources/library.rs:42` pushes a package when it is `"private": true` and ships a design. Recovery lint calls `anatomy::platform` (`lint.rs:507`) only from `with_lint` when types or analysis fail (`cli/src/lib.rs:968`), so a successful lower does not report it twice. The two D6 inputs this commit says are not built match the code: an `inject` whose provider reads the host (a provider component is covered for resources and for view/state/derive reads; an action read is finding 8), and a host entry (`app.json` `host.<platform>.entry` or per-platform variants), which no Contract syntax names.
- D3 ownership is per file, before scope and merge (`sources.rs:186`). A class that names another file's style is `missing` (`scope.rs` `resolve`), not retargeted, and a later rename moves that file's class and style together. Both arms of a conditional class count. A style on a slot fill counts for the component that writes the fill. Keyframes, a style nobody applies, and a style two components apply stay `tamber-param-scope`. An unknown `param.*` in a sole-owned style is `tamber-param-unknown`. `unused` counts reads in sole-owned styles after rewrite, and `Said::of` scans those styles, so the param token is retained. The sole-owner test compiles with an empty error list (`library_rules.rs:200`); class rows are inlined and parsed against the same theme table as an element row. Nothing asserts the plan value.
- D8 tokens: the namespace is the package's last segment (`packages.rs:79`), which stage 11 already forces the `tamber` header and every token to match, and two packages that would share a segment are refused earlier. An app line for a declared full name is skipped and wins at merge. An app's own unknown param stays the warning. A `.contract` row that names an unknown library token stays the existing unknown-token refusal, which is the split the commit describes. `library_packages` is ignored by scope and listed in `spans.rs`.
- Byte-identical outputs for the 45 apps were not re-run. D1, D6, and D8 only add errors. D3 rewrites `param.*` only inside styles, which previously failed `tamber-param-scope`, so an app that already builds has nothing to rewrite.
- The agent guide (`contract-for-agents.md:3601`) matches: exports for the literal and control rules, "nothing in the package" for platform, full names as the API. It omits the two unbuilt platform inputs, in line with the commit.
