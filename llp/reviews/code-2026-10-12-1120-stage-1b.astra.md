DO NOT LAND

1. **BLOCKING — Parking is not atomic or generation-safe.** [Parking]( /Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:611) tells the reader to park before requeueing or protecting admission. A successor can enter that gap and invalidate question 8’s refusal check. Worse, the old reader’s `Ended(ticket)` can decrement its replacement’s `live == 0`, panicking and poisoning the state lock ([749](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:749)). Commit parking atomically; generation-tag events and apply reader exit before allowing restart.

2. **BLOCKING — Retirement can permanently strand readers.** A sizing reader waits on [decision.recv()](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:506), but [retire](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:208) closes finishers without clearing `book.deciders`. A size reported afterwards receives no decision; four such readers exhaust uploads process-wide. The disposer also leaves `book.hops`, whose closures retain the machine. Disconnect deciders, dispose pending hops outside the lock, and reject late publications.

3. **MATERIAL — Next hops can exceed 32; uploads bypass origin limits.** [Selection](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:248) removes a hop without reserving capacity, then reserves new jobs. With 31 exchanges, one ready hop and one new job, execution reaches 33. File requests also omit [first-hop reservations](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:315); their ready uploads bypass the six-per-origin check. Reserve every selected exchange atomically and distinguish first upload hops from redirects.

4. **MATERIAL — Upload accounting misses failure paths and the later-of rule.** Charges installed at [622](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:622) are removed only by `Released`. A [read failure](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:545) constructs no `Upload`, so its charge leaks permanently. Conversely, [Released](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:754) releases immediately even if the sending hop remains alive. Track reader/hop lifetime and buffer release separately; release exactly once when both conditions permit.

5. **MATERIAL — File length undercharges the retained allocation.** [read_at_most](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_body.rs:267) grows a `Vec` in MiB chunks and truncates only its length. Tiny uploads retain MiB-sized allocations; larger ones can retain substantially more than their stat size, which is all the machine charges. Allocate within the charged capacity and probe growth separately, or reserve actual capacity.

6. **MATERIAL — Terminal classification depends on later events.** The [timer](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:781) flags timeout separately from posting its outcome; [classification](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:730) reads current abort/timeout flags. An over-limit result queued first can become `Aborted` or `Network` after the timer fires; an abort can also overtake a timeout already claimed. Record one immutable terminal winner before enqueueing publication.

7. **MATERIAL — Execution boundaries undermine deadlines.** Ordinary HTTP [arms its deadline](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:435) before lazy session creation and activation. File preparation calls [roots_for on the starter](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:473), which performs filesystem I/O; a stalled directory open prevents the next ordered job starting even after timeout. Arm ordinary HTTP at activation and move root opening into the bounded reader.

8. **MATERIAL — `Now` work skips scope validation.** The new [closure branch](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:387) executes work directly, whereas the [worker path](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_core.rs:1222) validates `request.grants` first. An invalid or widened scope now permits a continuation’s effects. Preserve that validation and test that a refused scope never invokes its closure.

9. **MATERIAL — The switch also changes Linux.** [Linux calls `Core::start`](/Users/admin/x2p2/apps/exact2-core/host/linux/src/executor.rs:46), which reaches the shared switch. It therefore selects [unaccounted threads per exchange](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:844), including accumulating timed-out ordered stragglers. Keep production opt-in at Apple’s executor until the bounded adapter lands; leave Linux and render on workers.

10. **MATERIAL — Selected handoffs execute after retirement.** The starter executes its entire [selected batch](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:238); the [handoff branch](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:367) never checks retirement. If retirement occurs during the first handoff, later, uninvoked handoffs still run. Recheck before each invocation and send abandoned work to the disposer.

11. **MATERIAL — Partial thread creation does not unwind.** [start](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async.rs:176) returns failure while successfully created threads remain waiting; [the caller](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_core.rs:344) only sets `failed`. Those threads and `LIVE_WORKERS` permits remain until the disabled core is dropped. Stop the partial base set immediately and test failure at every spawn position.

12. **MINOR — The fake cannot pin upload lifetime or cancellation-before-activation.** [Scripted::start](/Users/admin/x2p2/apps/exact2-core/host/apple/src/executor_async_tests.rs:65) discards the request/upload and drops an unactivated sink on cancellation without delivering `end`. Retain uploads through an explicitly controlled release, preserve exactly-once `end`, and add deterministic tests for the sequences above.
