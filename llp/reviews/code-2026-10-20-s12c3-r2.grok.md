## SHOULD-FIX

1. **Parenthesized arguments are false-refused.** `computed` (`contract/lower/src/anatomy/library.rs:107`) takes one function name via `split_once('(')` and strips a single trailing `)`. A word like `(space.md + space.sm)` has an empty name, so it is not a function, and `named` then rejects it. Valid library spacing such as `padding="calc((space.md + space.sm) * 2)"` and `calc((space.md))` is `lower-library-literal`. Nested `color-mix(...)` as one word still passes, and so does `calc(space.md * 2)`.

2. **Any number or percentage inside a function is treated as a knob.** Same function, line 128: `strip_suffix('%').parse::<f64>()` accepts every finite number. `padding="calc(100%)"` and `gap="min(100%, 100%)"` compile. D1 allows only `0` and `0px` as literal lengths. The `%` arm is required for `color-mix` shares; it should not bless spacing. `calc(12px)` and `min(8px, space.md)` are still refused.

3. **Literal param defaults outside `length` and `color` are skipped.** `literal` (`library.rs:179`) filters to those two kinds. D1 still says a param default that is a literal, of any kind. Round 1’s false refusal of duration and easing *token* defaults is fixed by this skip (`theme::names` already accepts a bound name). The skip also lets a library ship `duration: duration = "200ms"`, `easing: easing = "ease-out"`, or `shadow: box-shadow = "0 1px 2px #000"`. The commit and the agent guide state the narrowing on purpose.

4. **A helper labels every fill if one branch labels `children`.** `labels_children` (`library.rs:375`) ORs `when` and `match` arms. `if bare { children } else { label { children } }` makes `labels_children` true, and `Walk` (`library.rs:408`) then treats every fill of that helper as labelled. A checkbox inside `Field()` passes D6 on the bare branch. The element walk itself is path-sensitive; the helper summary is not. Same-file and merged cross-file helpers are seen, which is the round-1 fix.

5. **Any `.displayMode` member is a host read.** `platform` (`library.rs:566`) refuses the field name on every member, in view, state, derive, provide, and actions. `vp.displayMode`, `state.device.displayMode`, an alias, and an injected viewport are real host facts and should stay refused.
