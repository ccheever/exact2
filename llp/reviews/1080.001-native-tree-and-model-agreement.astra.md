# Review: LLP 1080.001 (Native tree and model agreement)

**Reviewer:** Astra (codex gpt-6-astra, max), requested by Charlie, 2026-10-03

**Verdict:** NOT READY — the comparison contract can reject correct hosts and miss the failures motivating it.

1. **High — The flat-leaf comparison inspects layers that may not paint anything.** D3 compares `FlatLeaves.leaves[id].layer.frame`, but `flush()` removes those layers and combines adjacent leaves into a different `CAShapeLayer`. That layer paints a path in the parent container’s coordinates; its frame is not assigned the constituent boxes ([FlatLeavesIOS.swift:235](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/FlatLeavesIOS.swift:235), [FlatLeavesIOS.swift:262](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/FlatLeavesIOS.swift:262)). Existing tests correctly inspect `path.boundingBoxOfPath` ([FlatLeavesIOSTests.swift:124](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Tests/ExactKitTests/FlatLeavesIOSTests.swift:124)). A displaced or stale mounted run can therefore pass the proposed per-leaf check.

   Edit D1/D3 to distinguish mounted singleton layers from merged runs and inspect their actual attachment, path and transforms. Either specify how merged geometry is verified or report it unavailable. Replace the proposed “move a layer frame” proof with mutations of the **mounted run**, leaving cached leaf data unchanged.

2. **High — Accounting for a parked tree exempts the “parked but still visible” bug.** D3 accepts a parked root and every descendant solely through pool membership. Parking removes the nodes from the presenter’s live maps, keeps their views mounted and hides only the root ([NodePoolIOS.swift:274](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/NodePoolIOS.swift:274)). Unhiding that root leaves it accounted for, with no live kernel row against which `hidden` can fail. Leaving views similarly lose live membership and rely on explicitly disabled interaction ([PresenceIOS.swift:17](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/PresenceIOS.swift:17)).

   Edit D3 so ownership classification does not imply correctness: parked roots must remain hidden and nonparticipating in hits; leaving roots must retain their input exclusion. Add negative tests that unhide a parked root and re-enable a leaving root. The current positive parking test cannot establish either guarantee.

3. **High — The JS web target has no independent model for the promised agreement checks.** Its `tree` walks the DOM itself, and its inspection implementation explicitly states that it keeps no kernel ([web-js/agent.js:57](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/web-js/agent.js:57), [web-js/agent.js:72](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/web-js/agent.js:72)). `Views` is populated lazily when an element receives an inspection/GPU ID, not maintained as an independent intended topology ([rt.js:607](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/web-js/rt.js:607)). Comparing DOM-derived parent/order/membership with that same DOM cannot detect an incorrectly removed, reparented or reordered element.

   Replace the shared “Web” stage with explicit wasm/JS capabilities. Mark independent model agreement unavailable on JS where no independent facts exist; retain useful DOM observations and use existing conformance fixtures for expected behavior. Do not introduce a second topology model merely to make this checker possible.

4. **High — Own native flags cannot be compared directly with inherited model flags.** `frames.bits` includes inherited inertness, but iOS sets `isUserInteractionEnabled` from the node’s **own** `inert` prop ([NodeViewIOS.swift:1006](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/NodeViewIOS.swift:1006)). A correctly inert subtree can therefore have enabled descendants. Existing inspection already walks ancestors to distinguish this ([AgentIOS.swift:333](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/AgentIOS.swift:333)). On macOS, `NodeView.inert` additionally incorporates route and dialog policy; it is not an independent AppKit interaction flag ([NodeViewMac.swift:150](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/Mac/NodeViewMac.swift:150)).

   Rewrite `hidden` and `interactive` to distinguish own state, effective ancestor state and native projection policy. Specify boolean polarity explicitly. Label macOS’s derived inertness as such rather than treating it as proof of platform hit behavior. Add nested hidden/inert fixtures.

5. **High — The clip predicate does not match either host’s clipping implementation.** An iOS scroll container puts scrolling inside a child `ScrollView`; its outer node can legitimately have neither `clipsToBounds` nor `clipBox` despite bit 16 being set ([NodeViewIOS.swift:1143](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/NodeViewIOS.swift:1143)). `clip-path` uses layer masks, which the proposed predicate ignores ([BoxMaskIOS.swift:91](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/BoxMaskIOS.swift:91)). macOS also clips clamped text independently of the two proposed bits ([NodeViewMac.swift:1094](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/Mac/NodeViewMac.swift:1094)).

   Replace this Boolean comparison with narrowly specified checks against the actual scroll container and mask attachment, preserving axis distinctions. State whether mask geometry is checked or only its presence. Prove that valid scroll/clip-path/clamped-text cases pass and removing the actual mask fails.

6. **High — The `frames` packet cannot supply the promised order and transform expectations.** Used z-index depends on `position_type` and the parent’s display mode, neither of which the packet carries ([NodeViewIOS.swift:768](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/NodeViewIOS.swift:768)). Bit 4 omits `rotate_axis` and `translate_z`; perspective is applied separately to the container’s `sublayerTransform` ([SpaceTransform.swift:106](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/SpaceTransform.swift:106)). Even with initial authored transforms, native transforms can include press feedback, keyboard lift and context transforms ([PressFeedback.swift:113](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/PressFeedback.swift:113)).

   Specify the independent expected facts and host composition inputs needed for each check, or cut these kinds from r1. Extract a pure mapping helper if sharing transform math; `applyTransform()` itself mutates presentation. Add static-versus-flex z-index, held-press, keyboard-lift and 3D fixtures.

7. **High — The hit oracle both misclassifies valid targets and excludes important negative cases.** Eligibility requires only that the kernel box intersect the viewport, while `tapPoint` uses the actual transformed native box’s midpoint ([Agent.swift:38](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/Agent.swift:38)). Existing tap handling explicitly rejects partially visible targets whose midpoint is outside the viewport ([AgentIOS.swift:408](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/AgentIOS.swift:408)). The RFC does not define the coordinate conversion or clipping/stacking calculation needed to judge higher-painted kernel boxes. Furthermore, excluding inert and hidden targets means the sampler never directly tests their required rejection. Actual hit behavior includes clip paths, visible overflow and CSS opacity semantics ([NodeViewIOS.swift:688](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/NodeViewIOS.swift:688)).

   Cut generic hit disagreements from r1, retaining bounded hit observations and fixture assertions at known points. Include explicit negative inert/clipped cases and partial-visibility, scrolling and transformed cases. This is cheaper and avoids constructing a second CSS occlusion model.

8. **High — The bounds do not bound the response, and incomplete inspection can pass as agreement.** The ordinary layout reply already enumerates every mounted view ([AgentIOS.swift:213](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/AgentIOS.swift:213)); appending a limited diagnostic does not bound that payload. The new `frames.nodes` list and each `flat:[id…]` list are also unbounded. A 20,000-**view** cap does not bound nodes or flat layers. D2 simultaneously promises complete counts and says that the remainder of a truncated walk is uncounted. D5 fails only on listed disagreements, so an incomplete walk with an empty list can pass.

   Define bounded envelopes for these forms, including runner facts, layer membership and scoped reads. Add explicit completeness and per-kind coverage/skipping fields, including hit sampling. Require the smoke to reject missing responses, walk truncation and unexpectedly skipped required checks; disagreement-list truncation may retain complete counts. Remove the unconditional “counts complete” and “zero disagreements” claims for incomplete walks.

9. **Medium — Native projections invalidate more comparisons than the `positioned` exception covers.** Native segments hide their authored tabs ([SegmentsIOS.swift:198](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/SegmentsIOS.swift:198)); popovers move into viewport/modal containers ([MenusIOS.swift:256](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/MenusIOS.swift:256)); macOS toolbar projection hides its authored rendering ([ToolbarMac.swift:277](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/Mac/ToolbarMac.swift:277)). These affect `hidden`, `parent` and potentially interaction, which are not † checks. Toolbar geometry is already explicitly system-owned ([AgentMac.swift:282](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/Mac/AgentMac.swift:282)). D2 also skips all positioned geometry while D3 promises size comparisons.

   Replace the blanket exception with a per-projection, per-kind applicability table. Resolve logical parents through existing owners, and preserve unavailable system geometry. A cheaper first slice should explicitly exclude unsupported projections rather than discover exemptions until smoke turns green.

10. **Medium — The proposed ownership predicate can hide strays and does not cover legitimate ownership.** Calling every otherwise-unrecognized non-`NodeView` scroll child “indicator/chrome” would accept a forgotten `UIView` under a list. The cited pool predicate is actually a private, narrow eligibility test for five known objects, rejecting other platform children ([NodePoolIOS.swift:179](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/NodePoolIOS.swift:179)). Freeze snapshots are added without retaining a dedicated identity reference ([NavigationIOS.swift:59](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/NavigationIOS.swift:59)), and app element hooks legitimately receive native views to customize ([ElementHooks.swift:123](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/ElementHooks.swift:123)).

   Delete the catch-all scroll-child exemption. Specify exact owner identities where available and explicitly opaque coverage where platform/module interiors cannot be attributed. Keep pool eligibility separate from broader inspection ownership. Add a stray-child test inside a real scroll container.

11. **Medium — The walk roots omit retiring modals and cannot infer sheet ownership per session.** iOS tracks `layers`, `retiring` and `dismissing`; removal transfers a presentation into `retiring` before native dismissal completes ([ModalIOS.swift:129](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/ModalIOS.swift:129), [ModalIOS.swift:301](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactKit/IOS/ModalIOS.swift:301)). Walking only `layers` misses precisely that retained native lifetime. On macOS, the sample’s two `ExactView`s share one window ([ExactHostMac/main.swift:53](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/host/apple/Sources/ExactHostMac/main.swift:53)); “its window’s attached sheets” does not establish which session owns a sheet.

   Define deduplicated roots from each owner’s full active/retiring lifecycle. Require explicit ownership for sheets or mark foreign/system roots outside coverage. Add a dismissal-in-progress test and a two-session ownership test.

12. **Medium — The advertised smoke proof neither exercises Messages pooling nor has the claimed asynchronous wiring.** Steps 4 and 5 are inside `if (caltrainFixture)` ([smoke.mjs:620](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/scripts/smoke.mjs:620), [smoke.mjs:748](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/scripts/smoke.mjs:748)). The asynchronous lane’s check list does not invoke this smoke ([async.mjs:51](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/scripts/async.mjs:51)).

   Replace the Messages step-5 claim with a named collection fixture and explicit drive that demonstrates retirement/reuse. Define when retained pool occupancy must be nonzero. Add the selected smoke invocations to the existing asynchronous lane, preserving aggregate failure reporting and the five-check gate.

   Validate logical liveness first. Specify targeted results for flat, inline and SVG nodes, using an owner/layer root or explicit unavailable reason. Reserve “stale” for retired logical IDs. Move `pending` out of the missing-node-view exemptions and continue checking its wrapper.

14. **Medium — The wire contract leaves cross-host interpretation and snapshot identity ambiguous.** `frames` omits `clock`, unlike the existing tagged runner observations ([runner/src/agent.rs:73](/Users/admin/.config/tuft/sessions/1791014443.232549/worktrees/exact2/runner/src/agent.rs:73)).
