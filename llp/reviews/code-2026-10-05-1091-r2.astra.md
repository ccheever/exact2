2. **[Major] Staging package aliases destroys declaration identity.** [js/bake/src/lib.rs:567](js/bake/src/lib.rs:567), [contract/cli/src/sources.rs:425](contract/cli/src/sources.rs:425).  
   Install `"a":"file:../ui"` and `"b":"file:../ui"`, both exporting `Card`. Import `use Card from "a"` and `use Card from "b"`. Original compilation accepts both imports because they identify the same canonical declaration. Baking now copies the library into two independent directories. Recompilation sees two declarations and reports `contract-use-duplicate`. Using distinct aliases avoids that diagnostic but still duplicates nominal shapes and splits shared timelines. Recording both package names fixes missing files, not identity preservation.

3. **[Major] Animation keywords that actually name keyframes are never rewritten.** [contract/syntax/src/scope.rs:482](contract/syntax/src/scope.rs:482).  
   Have the root and `ui.contract` each declare different `keyframes linear`; import a library component rendering `animation="linear 1s linear"`. The library definition becomes `linear__ui`, but both occurrences in the shorthand remain `linear`. The downstream parser consumes the first as easing and the second as the animation name, so the library plays the root’s keyframes. `animation="'linear' 1s"` fails similarly because tokenization discards the distinction between a quoted name and an easing keyword. Both unchanged strings pass compilation.

4. **[Major] A computed prefix suppresses subsequent literal keyframe rewriting.** [contract/syntax/src/scope.rs:452](contract/syntax/src/scope.rs:452), [contract/syntax/src/scope.rs:458](contract/syntax/src/scope.rs:458).  
   With different root/library `keyframes pulse`, let the library component declare `state timing="1s"` and render ``animation=`${timing} pulse` ``. Whitespace following the computed part sets `named=true`, so literal `pulse` remains unchanged instead of becoming `pulse__ui`. The animation silently selects the root’s definition. Function depth also resets between template parts: ``animation=`steps(${n}, jump-end) pulse 1s` `` treats `jump-end` as a potential keyframe name and misses `pulse`.
