1. **[Major] Staging still splits a declaration reached through a package re-export.** [js/bake/src/lib.rs:592](js/bake/src/lib.rs:592).  
   Put `Card` in `/app/ui/index.contract`, link `/app/node_modules/ui → ../ui`, and install a regular `/app/node_modules/wrapper` whose `index.contract` contains `use Card from "ui"`. The TypeScript app imports `Card` from both `"ui"` and `"wrapper"`. Original compilation sees one canonical declaration. Baking links `ui` to `/stage/ui`, but keeps `wrapper` at its original location; wrapper’s import therefore reaches `/app/ui`. Staged compilation sees two declarations and reports `contract-use-duplicate`. The direct round-5 cases are fixed, but this diamond remains broken.

2. **[Major] Canvas surface names are incorrectly resolved as Contract functions.** [contract/syntax/src/scope.rs:449](contract/syntax/src/scope.rs:449).  
   Let `ui.contract` declare `fn chart(n: number): number = n` and `component Card`. The root imports only `Card` and renders `canvas surface=chart() width=10 height=10`. The scope pass reports `contract-use-missing` for `chart`. However, a surface call’s head names the external drawing surface; only its arguments are Contract expressions, as [checks.rs:1315](contract/types/src/checks.rs:1315) explicitly implements. Downstream compiler probes accept this surface alongside the unrelated function. Loading the library must not turn the surface into a function reference.

3. **[Minor] A missing export in a linked package can terminate the TypeScript dev server.** [host/web/dev.mjs:475](host/web/dev.mjs:475), [dev.mjs:563](host/web/dev.mjs:563).  
   During a working `--wasm` session, add an import from `node_modules/ui → /work/ui`, whose manifest exports `./src/card.contract` while `src` is absent. `contractGraph()` returns both `/work/ui` and the nearest existing logical directory, `/app/node_modules/ui`. The latter is a symlink, which `watchModuleSources` rejects with `module source root is not a regular directory`. This escapes the producer’s new `finally` block. Executing the actual callbacks with filesystem stubs reproduced the uncaught exception.

4. **[Minor] Retargeting a linked package does not invalidate the wasm session.** [contract/cli/src/resolve.rs:210](contract/cli/src/resolve.rs:210), [host/web/src/dev.rs:54](host/web/src/dev.rs:54).

Successful resolution records the canonical manifest and sources, but not the installation link. Every recorded dependency stamp remains unchanged, so `Session::poll` suppresses compilation and continues serving v1.

5. **[Minor] Installing a newly imported package still fails to recover the TypeScript producer when `node_modules` was absent.** [host/web/dev.mjs:559](host/web/dev.mjs:559).

The refreshed graph contains missing-file candidates, but its directory set is empty; the producer consumes only that directory set. The JS loop’s new shallow watches do not cover this producer.
