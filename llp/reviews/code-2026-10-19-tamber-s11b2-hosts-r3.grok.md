The sheet declares all nine `--exact-*` names, or none. An app definition of a base name is left out of that set and is written on the token path (`--x-space-md` in dev, the length in a release). An unset alias stays `var(--exact-…)`; an SVG attribute bakes the column length. B2 does not move the schema digest. The Stretch cell is queued.

The bytecode walk does not miss a base name a length row can return. An untyped read, a string read, a string/`any`/`option<string>` call, an unhandled opcode, a stack or local mismatch, or a concatenation that is not proven base-free becomes “any string” and declares all nine. A concatenation is base-free only when a part, trimmed the way JavaScript trims (including U+FEFF), is non-empty and not a substring of any of the nine, so it cannot trim back to a base name. Region depth matches the compiler and the VM, including `when` frames; a constructed list or `some` keeps its element, and `none` keeps the other side. `reads_length` probes with `1px`, which takes the same px path as the column lengths (`4`…`32`, `9999`).
