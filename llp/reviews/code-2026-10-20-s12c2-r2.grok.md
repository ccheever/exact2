## SHOULD-FIX

**`font` / `font-size` refuses live text styles** — `contract/lower/src/anatomy/slot.rs:143` and `:147-149`

`denied` allows a `font-size` when it parses as a length or `starts_with("-exact-")`, case-sensitive. `font()` (`contract/lower/src/shorthands.rs:295-312`) accepts any `text_style`, ASCII case-insensitive, including WebKit `-apple-system-*`, and those ramp sizes are non-zero. `font="-apple-system-body"` and `font-size="-EXACT-body"` come back as unreadable. `typeface::parts` (`kernel/src/style/theme/typeface.rs:30-31`) uses the same case-sensitive prefixes, so the `font` row refuses them before the size check. Lowercase `-exact-body` is allowed.

**In-svg `text` skips `transform`** — `contract/lower/src/anatomy/slot.rs:252-254`

`is_svg` is `tags::tag(tag).node_type.name().starts_with("Svg")`. `tags::tag("text")` is `NodeType::Text` (`contract/lower/src/tags.rs:113-114`). Inside an `svg` that node lowers to `SvgText`. A collapsing `transform` on it is never passed to `denied`. `foreignObject`, `tspan`, `g`, and `symbol` are `Svg*` and are checked.

**A node longhand does not beat a class shorthand** — `contract/lower/src/anatomy/slot.rs:312`

`own` compares the attribute name before expansion. A class `font-size=0` still counts when the node sets `font="-exact-body"`, and a class `font` whose size is `0` still counts when the node sets `font-size=16px`. Lowering expands first, and the node wins on the style id. The same-name case (`display="flex"` over a class `display=none`) is fixed and tested.
