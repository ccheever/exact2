## MAJOR

**1. D6 — "live" is still a property of the rung, and T2 schedules params before they exist.** The table marks param, token, and dial live (`llp/1122-design-tool.rfc.md:264-266`). Tamber applies the live table only when the closure stays inside the token table and nothing affected is substituted at build; a `duration` or `easing` token, and any dial or param folded into one, rebuilds (`llp/1121-tamber.rfc.md:897-903`). Stage 7's own gate says a duration `set-param` rebuilds (`llp/1121-tamber.rfc.md:1257`). T2 takes the param rung "with Tamber stage 4" (`llp/1122-design-tool.rfc.md:472-477`); params are stage 7, and T3 is the workbench. A live scrub that commits every tick also makes "re-scope as the inverse, then the new write" (`:278-279`) invert only the last tick. **Fix:** the chip reads Tamber's closure, not the rung. A scrub is one transaction, committed on release; earlier frames are previews; re-scope inverts that transaction. A param whose value is a token or an expression offers those inputs, and a literal is D15's pin, named on the chip before release. Move the param rung to T3.

**2. D6 — `set-row` still does not name the attribute it patches.** The map records the element's line and columns and the winning longhand's origin, not an attribute span (`contract/cli/src/map.rs:52-59`, `:219-227`). "Compiles the candidate file" misses package checks. Detach "leaves the param to its other readers" (`llp/1122-design-tool.rfc.md:285-286`); the last reader is `tamber-param-unused` (`llp/1121-tamber.rfc.md:1087-1091`) and the compile writes nothing. **Fix:** record the winning attribute's file, span, and source digest, using the shorthand's span when the row is an expansion. `set-row` splices that value token. The style rung addresses `style <Name>` plus the row, resolved in the package. Compile the package. Detach of the last reader removes the param in the same transaction. If the row is not that one attribute, refuse.

**5. D12–D13 — a paired client cannot see the tiles, and a window capture is not viewport space.** Captures are loopback handles (`llp/1122-design-tool.rfc.md:421-423`). **6. D8 — a held `hover` or `focus-visible` is specified as a press.** The hold "applies overlays, ease and Reduce Motion exactly as a real press does" (`llp/1122-design-tool.rfc.md:340-341`). Disabled refuses all three. After a reload the server re-applies the tile's hold.
