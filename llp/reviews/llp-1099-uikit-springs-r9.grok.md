2. **MATERIAL.** Component 0’s end is not a pinned f64, and on scale its state is not assigned a kind. D5 (`:509–512`) ends it at “the time its rest rule gives, capped at today’s 10 s”. D3 (`:316–318`) states the rest predicate, not the time. The time today is `SpringConfig::settle_time`: the first 240 Hz sample at rest, else 10 s (`spring.rs:145–157`), and the property end is the max over axes (`transition.rs:402–411`). A continuous root of the same predicate differs by up to one sample, so §8.4’s form-change retarget (`:1090`) cannot pin the snap. On scale, “current residual” is undefined: a factor matches value and velocity only at the join, then diverges; a release is already an additive residual (`:530–536`). **Fix:** component 0 is an additive residual (presented minus the old target) with its current derivative. Its end is `settle_time` of that residual, max over axes, measured from the retarget instant.

3. **MATERIAL.** Collapsing into a restart uses “the summed actual derivative” (`:506–508`). For scale the presented velocity is T·Σ fᵢ′∏_{j≠i} fⱼ + Σ r′, which the fold already states (`:472–474`). Velocity follows the precedence list: authored v·Δ when the incoming spelling has one, otherwise the derivative of the presented value.

4. **MATERIAL.** The form-change rule (`:502–513`) keeps the live spring as component 0 and adds another component, for any property. Opacity is a replacement (`:429`, `:562–576`) and paint keeps no list (`:410–414`). Every opacity retarget follows the replacement rule. Every paint retarget interrupts as CSS.

5. **MATERIAL.** A release “starts one component” (`:517–525`) while a physical or response spring without an end “keeps LLP 1003 §5’s restart” (`:500–501`, and §5 at `:962–966`). An endless component collapses only when offset and velocity are below 10⁻⁶ of its own Δ (`:457–459`). A zero-distance release has Δ = 0, so that test does not fire while velocity is nonzero, and the 10 s snap is waived only for a component that has an end (`:334–335`). Today’s release settles by `|x| < 10⁻³ ∧ |v| < 10⁻³` or 10 s (`spring.rs:51–56`, `transition.rs:354`; `hold.rs:328`). §8.4 (`:1100–1105`) checks that the release plays and how S is set, and does not pin its end. **Fix:** a release into a restart form stays an LLP 1003 §5 restart (absolute rest, 10 s cap, per-axis max `settle_time`). A release into a duration or bounce form is one component whose end is the authored end.
