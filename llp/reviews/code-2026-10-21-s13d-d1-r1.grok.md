1. **Major** — `contract/lower/src/theme/rows.rs:149` and `contract/lower/src/type_tokens.rs:273`. `grouped` turns each arm of a `?:` or `match` into its own row, and `judge` then calls `tokens_named` on that single arm. Lowering calls `tokens_named` once on the whole attribute. Two consequences:
   - A varying type or family token inside a choice is refused with `tamber-inherited-axis` at the arm string (`a.value.span()` after the split). The build reports that same id and message at the choice expression's span (`type_tokens.rs:315`).
   - Cross-arm failures never fire in the check: mixed token and non-token (`tamber-kind` at `type_tokens.rs:273`) and two type tokens that write different longhands (`tamber-type-longhands`). If one arm also fails `bundled_faces`, the check treats the row as newly broken and refuses with `lower-font-face`. The build already rejected the choice and still rejects it for the cross-arm reason, so this blocks a write that does not change the build's result.
   - **Fix:** Do not split `font` or `font-family`. Call `tokens_named` on the authored attribute, spans included. Keep arm splitting for `font-weight` and `font-style`, which go through `check_style_value` and already walk every arm.

2. **Major** — `contract/lower/src/theme/rows.rs:444`. `judge` turns `font_use`'s `Err` into no fonts (`.ok()`) and keeps going. In lowering, `nodes.rs:478` is `let font = self.font_use(expanded)?`, so a bad literal family list aborts the element before `type_font` or `family_token`. On a node that also has `font="type.body"`, the check can refuse a token write as `lower-font-face` while `contract build` reports only `lower-font-family-list` and never reaches the face check. The before-pass gate is wrong too: the check thought the type row passed. A literal `font-family` that names no family token is the same hole in the other direction: `tokens_named` returning `Ok(None)` becomes `Ok(())` (`rows.rs:452`), so `family_stacks` never runs.
   - **Fix:** If `font_use` fails, return that error and do not call `tokens_named` with an empty face list. For `font` and `font-family`, an `Ok(None)` from `tokens_named` should fall through to the shorthand or `family_stacks` path the build uses, not succeed.
