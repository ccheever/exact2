1. **MATERIAL** — D7.3, Web. Binding `PropId::TabIndex` never becomes the HTML attribute the browser focuses, and a third synthesis site is unnamed.
   **Problem.** `props_of` has no `TabIndex` arm, so the prop is emitted as `data-tabindex`. Neither renderer’s synthesis consults that prop: both append a literal `tabindex=0` whenever the node has a focus, blur, or key handler. The live wasm path does the same in `glue.js`, which D7.3 does not cite. Dynamic updates take the name `prop_name` discovers by diffing `props_of`, then `P()` / `applyProps` call `setAttribute`. A `box tabindex=0` with no handler stays unfocusable, and `tabindex=-1` on a handler node does not leave the Tab order.
   **Evidence.** `host/web/src/element.rs:851-856` (fall-through `data-` name); `host/web/src/document.rs:481` (`props_of`) and `:618-619` (unconditional push); `host/web-js/src/emit.rs:940` and `:971-976`; `host/web-js/src/rows.rs:470`; `host/web-js/src/style.rs:422`; `host/web/glue.js:534`.
