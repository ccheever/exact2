# Review round 2, LLP 1121 stage 12 B1 (package components' params), Grok (grok 4.7, xhigh)

**RIGHT WITH CHANGES**

Round 1 is fixed. `short` now uses every param identity plus Contract identities, the same rule as `called`, and the two-package and app/package tests both expect no `short`. The server cache key includes each package design's components, so a param added after priming is a retention root and a varying override is `rebuild`. A package param's default is refused when it names another package's token, an app token, or a dial, at the default in the package file; a sibling `param.…` is allowed; an app-set value is not held to the rule.

Identity is `<package>/<file>#Name` from the design's home: the `package.json` name plus the path inside that package, not the absolute path. A link, a `node_modules` symlink, and a vendored package all resolve to that same home. `set-param` and `unset-param` write the app's design; package files are not in the server's file list. Retention roots are the param tokens. An unset param keeps its default's chain and not a sibling token; a set one keeps the app's value. `uses` for a package Contract component is unchanged. With no package `component … params`, no new tokens enter retention, so release output is unchanged. Line counts: `theme.rs` 1454, `sources.rs` 1424, `tamber_serve.rs` 1318, `packages.rs` 393.

1. **SHOULD-FIX** — `contract/lower/src/theme/packages.rs:317`. The param check only reads names on `folding.tokens`. A whole alias of a profile colour is replaced with `transparent` in `profiles` (`contract/lower/src/theme.rs:639`) before the fold, so `names` is empty and `pin: color = ink` builds when `ink` is `color(--…)`. An icon param is laid on `icons`, not `tokens` (`tamber/src/params.rs:153`), so the `find` misses and the loop skips it. `glyph: icon = icon.home` is accepted when `icon.home` is the app's icon. Judge the written default against `folding.design.icons` as well as tokens. A literal `icon(sf "…")` stays legal.

3. **NIT** — `contract/lower/src/theme/packages.rs:321`. "The app set this param" is decided with `resolve` over this package's params only.
