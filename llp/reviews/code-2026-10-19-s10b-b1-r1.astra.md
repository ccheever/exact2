**Two blockers remain.**

- **Blocker — Cookies remain readable downstream.** [scripts/tamber-remote.mjs:99](/tmp/rv-b1-1/scripts/tamber-remote.mjs:99) deletes only `req.headers.cookie`. An in-memory Bun check confirmed that both `req.rawHeaders` and `req.headersDistinct.cookie` still contain the cookies. **Fix:** remove every case-insensitive Cookie entry from the raw headers and clear all parsed header views, including an already-populated `headersDistinct`. Test duplicate and mixed-case Cookie headers through each view.

- **Blocker — The local token authenticates remotely.** [scripts/tamber-remote.mjs:114](/tmp/rv-b1-1/scripts/tamber-remote.mjs:114) calls the real wire, whose [authentication check](/tmp/rv-b1-1/scripts/tamber-server.mjs:488) checks the token but ignores `access.local`. A read-only probe through the real handler returned **200** for a remote request carrying its local token; its default scope is `write`. **Fix:** explicitly refuse remote API requests until A lands, then distinguish local tokens from paired tokens. Add an integration test using the real wire.

- **Should-fix — Certificate generation fails randomly.** [scripts/tamber-remote.mjs:21](/tmp/rv-b1-1/scripts/tamber-remote.mjs:21) does not remove redundant INTEGER leading zeros. After masking the serial’s first byte, roughly 1/256 serials have an invalid redundant zero. Generation failed on attempt 150 with `INVALID_INTEGER`. **Fix:** encode a minimal positive DER INTEGER and ensure a nonzero serial; test leading-zero and sign-bit cases deterministically.

- **Should-fix — Accepted IPv6 hosts disappear from the certificate.** [scripts/tamber-remote.mjs:39](/tmp/rv-b1-1/scripts/tamber-remote.mjs:39) silently drops IPv6 SANs, although the flag accepts `[::1]:0`. The resulting certificate’s `checkIP("::1")` returns `undefined`. **Fix:** encode IPv6 SANs as sixteen-byte `iPAddress` values and canonicalize addresses for Host comparisons.

- **Should-fix — Network-path request targets reach the wire.** [scripts/tamber-remote.mjs:109](/tmp/rv-b1-1/scripts/tamber-remote.mjs:109) accepts `//foreign/__tamber`, `///foreign/__tamber`, and `/\foreign/__tamber`. The handler dispatches `/__tamber` with `url.origin === "https://foreign"`. The existing `//__tamber` test misses this. **Fix:** reject network-path and backslash targets before URL parsing, and ensure the parsed authority remains the validated listener authority.

- **Should-fix — Remote startup failures bypass cleanup.** The failure handlers in [serveAlone](/tmp/rv-b1-1/scripts/tamber-server.mjs:1057), [JS dev](/tmp/rv-b1-1/host/web-js/dev.mjs:1029), and [wasm dev](/tmp/rv-b1-1/host/web/dev.mjs:1495) exit without awaiting `tamber.close()`. Detached Cargo builds can outlive that exit. Conversely, the dev loops’ “no design” rejection calls `stop()`, which exits **0**. **Fix:** use shared asynchronous cleanup accepting a failure exit code; validate the design before starting work.

- **Should-fix — The plaintext test does not prove the claimed refusal.** [scripts/tamber-remote.test.mjs:71](/tmp/rv-b1-1/scripts/tamber-remote.test.mjs:71) accepts any HTTP-client error, including parser errors after receiving bytes. **Fix:** capture raw TCP output, assert no HTTP response, connection closure, and zero wire calls.

Static-file realpath containment, dot-file rejection, socket-derived peer identity, and the local `serveTool` guard appear sound. The installed Bun implementation does enforce the configured connection and request/header limits.
