2. **MAJOR — Source-string compilation silently discards members.**  
   [contract/cli/src/lib.rs:281](/Users/ccheever/projects/exact2-wt-review-members/contract/cli/src/lib.rs:281).

   ```rust
   contract::compile(
       "component App\n\
        \x20 members \"./effects.contract\"\n\
        \x20 view\n\
        \x20   text \"ok\"\n"
   )
   ```

   This returns a plan containing the view without resolving—or refusing—the members line. The file need not even exist. `compile()` checks unresolved `use` declarations, but nothing checks `Component.members.lines`; downstream passes ignore them.    **Fix:** Make every source-string entry point reject unresolved members lines with a diagnostic directing callers to a path-based API, and reject unlisted members blocks. Do this before type checking or lowering.

3. **MAJOR — `fmt --uses` writes imports that create members cycles.**
