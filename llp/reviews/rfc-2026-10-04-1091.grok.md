SOUND WITH CHANGES

1. **Major — "existing plans stay byte-identical" is not a consequence of collision-only renaming.** `same_declaration` (`sources.rs:419`, `sources.rs:462`) merges textually identical shapes, fonts, styles, fns, and components. D7 stops that. Every shape is still emitted, in order, as a plan type (`lower/src/lib.rs:310`), so a second `shape Item` that today collapses becomes `Item__other`, shifts later type ids, and changes the compat id. Identical fonts do not rename: `declare_fonts` refuses the second family regardless of the faces (`fonts.rs:45`). The byte-identity tests only cover unused fns (`source_locations.rs:283`, `source_locations.rs:360`). `equivalent_duplicate_declarations_do_not_become_conflicts` (`source_locations.rs:289`) compiles today and becomes `contract-use-duplicate` under D1+D7. Keeping bytes means still lowering every loaded shape, font, and keyframes, in today's load order, and treating a D7 split of a shape or font as a plan change.

2. **Major — D5 misses `exit-animation`, and the warning does not cover the names the runner actually resolves.** `check_animation_names` treats `animation` and `exit-animation` alike (`svg.rs:569`), including native buttons (`controls.rs:730`). Styles carry it too (`host/web-js/conformance/listexit.contract:23`). A renamed `leave` left in that string fails `lower-animation-name`, or, for a template, is dropped at runtime (`motion/src/animation/parse.rs:131`). Lower then reparses the shorthand and rebuilds it (`svg.rs:686`). The new warning only fires when the first word is non-literal, so `animation={`${name} 1s, pulse 2s`}` and `1s ${name}` stay silent. The per-file clock pass has to keep local shadowing (`clock.rs:44`, test at `clock.rs:141`); running today's global pass after the merge binds the other file's timeline.

3. **Major — `{name}__{stem}` is not always a Rust identifier.** Contract idents may contain hyphens (`lexer.rs:247`). `contract rust` prints the shape name raw as the struct (`rust.rs:107`); only fields are sanitized (`rust.rs:20`). `user-id__pkg` does not parse. The suffix does make it a CSS custom-ident (`motion/src/animation/parse.rs:484`), a `clock()` name (`kernel/src/timeline.rs:83`), and a quoted Lean string (`lean.rs:92`). `contract types` never uses the name as an ident (`typescript.rs:30`). Uniqueness via `_2` does not fix the hyphen.

4. **Major — record constructors are resolved again, globally, across kinds.** D4 renames only within a kind. `type-fn-shape-name` (`types/src/lib.rs:1098`) still refuses a `shape Item` and a `fn Item` anywhere in the merged file, and both `is_record_call` (`types/src/records.rs:11`) and `record_constructors` (`inline.rs:142`) decide `Item(...)` from that flat set. Two libraries, each locally unambiguous, still fail. Types staying unchanged preserves that.

5. **Major — D9/D10 does not match capture, relocate, the dev loop, or deploy.** The TS bake compiles `stage/app.contract` and skips `node_modules` (`js/bake/src/lib.rs:552`, `js/bake/src/lib.rs:755`). A package mirror has to be a byte copy: symlinks are refused (`js/bake/src/lib.rs:583`), and `Sources::relocate` is one prefix strip (`sources.rs:17`), so a `file:` package outside the app cannot be mapped back. An `exact:` path in that list fails the same strip (`js/bake/src/lib.rs:763`). The web build does not compile in the stage: it compiles the real `app.contract` (`host/web-js/build.mjs:59`), and its capture copies only `.ts` and `.json` (`host/web-js/build.mjs:157`). The JS dev loop already rebuilds on any in-app file and explicitly drops `node_modules` (`host/web-js/dev.mjs:25`, `host/web-js/dev.mjs:99`). The one-file watch is the wasm `Session` (`host/web/src/dev.rs:4`) and `cargo:rerun-if-changed=../app.contract` (for example `apps/caltrain/linux/build.rs:7`). Deploy excludes `node_modules` (`scripts/deploy.mjs:115`) and freezes every byte the bake can read (`scripts/deploy.mjs:303`). Name, version, and sha256 without the `.contract` bytes cannot rebuild offline. Conditional `exports` objects are also unspecified: `".": { "default": "./index.contract" }` does not "end `.contract`".

6. **Minor — `provide` / `inject` keys stay one string namespace.** The inliner matches them by name across every component (`inline.rs:397`), and they are not in the rewrite list. Two nested libraries that both `inject theme` share a channel, with no rename and no diagnostic. D11 depends on that and never says it.
