## SHOULD-FIX

**`no-regressions` passes when the release file names too little, and it never checks the reading apps.** `scripts/stage12-gate.mjs:579-606`

`releaseIdentity` returns PASS when every non-exempt row is `identical` or `both failed`. An empty array, a file that lists only `apps/library-gate/app.contract`, or a file that omits every other app all take that path (`unnamed.length === 0`). `noRegressions` greps `@exact/reading` users and writes them as "in release identity" (`:601-602`) without requiring each path to appear as `identical`. §5 (`:545-546`) requires byte-identical release output for apps that use no library component, and `@exact/reading`'s users unchanged. `both failed`, and library-gate's own `DIFFERS` / `build failed`, match the rule you stated (stage 11 passes `both failed` the same way). The test at `scripts/stage12-gate.test.mjs:125` encodes those two. The hole is a file that names too little.

**A bad release file crashes the gate before the line is written.** `scripts/stage12-gate.mjs:581` and `:588`

`JSON.parse` is uncaught. Any row that fails the exempt statuses is rendered with `r.commits[0]`; a missing or empty `commits` throws. `lines()` has no try/catch (`:673-678`), so the throw skips the remaining lines and the output file.

**The design-server client can hang, and killing it can leave the lock held.** `scripts/stage12-gate.mjs:425-445`

Ids are assigned with `++next` and matched with `waiting.get(reply.id)`. The waiter is registered before the write, so a reply still in flight is settled when the process exits. `exit` only settles waiters that already exist, and nothing latches a dead process. A server that dies between requests, or a reply `{id: null, error}` (the server's bad-JSON response, `contract/cli/src/tamber_serve.rs:711-716`), leaves the next `ask` pending forever. There is no reply timeout. There is no `child.on('error')` and no `stdin` error handler, so a failed spawn or a broken pipe is an uncaught exception and the gate file is never written. `close` is `child.kill()` with no process group. The dev-loop client (`scripts/tamber-server.mjs:131`, `:1185`) spawns detached and signals the group. A leftover `tamber serve` keeps the design lock, and the next run's server refuses.

On the path that does answer: `!ok` throws (`:477`) and `restyle` returns FAIL (`:510`). A drive that throws is caught per host and fails that host (`:540`). Those two are closed.

**`no-forks` fails when `target/stage12-gate` does not exist.** `scripts/stage12-gate.mjs:632`, `contract/cli/src/build.rs:307-323`

`write_output` opens `{path}.{pid}.tmp` with `create_new` and does not create the parent. `--only no-forks`, or any run that has not already created that directory, fails the build on the missing directory. A full run happens to create it first inside `restylePlan` (`:452`). The failure evidence is `built: NO` and drops the compiler's message (`:634`). The check itself is real when the build runs: `lower-library-platform` is applied to library-package components during the app build (`contract/lower/src/lint.rs:508-510`, `contract/lower/src/anatomy.rs:519-533`).

**A plan that fails to compile is reported without the diagnostic.** `scripts/stage12-gate.mjs:286-292`, `:450-457`, `:374`, `:518`

`libraryPlan` and `restylePlan` return null and discard the compiler output. slot-rendered then says `apps/library-gate did not compile`; restyle says `library-gate did not compile: …`.

**`slot-rendered` passes with zero markers.** `scripts/stage12-gate.mjs:344-381`

`markerIds()` is every PostCard placement. An empty list makes `rows` empty and the line PASS (`web: 0 of 0 markers rendered with both glyphs`). The current app has six marked PostCards, and PostCard is the only slotted export, so a normal tree is fine. A placements miss, or a fixture that loses its slots, satisfies "every marker" with nothing rendered.

## NIT

The output never mentions them. A required host that is missing does fail the line.

**The allowlist's 10% cap is not checked.** `scripts/stage12-gate.mjs:60-74`, `:211-218`. §5 (`:527-528`) says each rectangle has a reason and may not cover more than 10% of any library component's box. `allowOf` builds the caret (leading 4px, height `min(h, 40)`) and, when `keyboard-inset-height` > 0, `[0, view.h, view.w, kb]`. `comparePixels` unions both sides' rects and ignores pixels inside them. Nothing measures a rect against a library component's box. The current keyboard rect starts at the viewport's bottom edge, and the caret is the app's own field; this review does not show either one covering a library box.

**Baseline provenance records `size: 420x900` for iOS and macOS, which are driven without `--size`.** `scripts/stage12-gate.mjs:130`, `:158`. The pixel compare uses the shots, so this does not flip the line. The recorded size is wrong for those two hosts.

## Restyle oracles

These match the components and `kernel/tables/schema.json`. `expected` (`scripts/stage12-gate.mjs:496-500`) quantizes with `cellsOf` (nearest cell, tie toward zero, `kernel/src/style/cells.rs:36-44`) only when the read has an axis and the layout has a cell. Tolerance is 0.5px, the same as scale-check; a cell error is 8px.

`space.md` before: iOS 16, macOS 10, web and Linux 16, Android 16, terminal 8 (1×8). Set `24px` stays 24 on the terminal (exactly 3 cells).

- PostCard end padding (`post-pc-base` vs `postcard-content-pc-base`) is `cards.pad-end` = `space.md`. `pc-base` is not `inThread`. The card has a top border only, so the right-edge gap is the padding. `is`.
- ActionRow gap `bookmark.x - (2*like.x - repost.x)` equals the outer `gap` when the three `flex:1` columns (`1 1 0%`) have equal border widths. The reply column's `actions.row-lead` (−6px, −8px once the terminal snaps it) cancels in that difference. `justify-content: space-between` adds nothing more while the counted row is under `actions.row-max` (320). The app column is `max-width="23rem"` (`apps/library-gate/app.contract:52`); root rem is 16, so that cap is 368px, 46 terminal columns exactly. Tightest case is the terminal: hit and trail are 0 cells, three 18px icons plus an 8px gap leave the counted row near 306px, about 14px under 320. Icons snapped to 16px still leave about 8px.

`cards.pad-start` before is `space.sm` = 8 on every host, including the terminal (1 cell). Set `20px` is 20 in points and 16 on the terminal (2.5 cells, tie toward zero). The read is the avatar column's border x minus the card's x, which is `padding-left` on `pc-base`. The avatar's own `cards.avatar-start` sits inside that border box.
