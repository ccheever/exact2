## SHOULD-FIX

**Variant props are any `?:` / `match` in the view, not only a class or a row.** `contract/lower/src/anatomy.rs:446` walks every element attribute and every use-argument (`:452`). Any ident inside a ternary condition or an option-`match` subject is kept (`:460-476`), then `described` (`:407-421`) records it when the prop is an enum or a bool. The comment at `:379` states the narrower rule. `hidden=(dense ? true : false)`, `aria-label=(tone == "quiet" ? "a" : "b")`, and `Child(label=(tone == "quiet" ? "a" : "b"))` all become variants. Class conditions and a row's own `?:` are included, so this is extra axes in the IR `library` block, not a dropped one. `the_ir_lists_parts_slot_and_variants` only covers a class ternary and a `gap` ternary.

**One element may carry two different `part` names.** `take_marks` (`contract/syntax/src/anatomy.rs:78-92`) records every `part=` on the element, all with the same node span. The duplicate check (`contract/lower/src/anatomy.rs:220`) fires only when the part name matches. `part="a" part="b"`, both declared, is accepted and both are row-checked. D5's selection names one part, and the join key is that shared node span, so both parts claim the same element. The written duplicate rule (two nodes, one name) is implemented; this is the inverse.

**`slot` is true only for a direct `children` child.** `holds_children` (`contract/lower/src/anatomy.rs:426-430`) does not look through `if` / `for` / `match` or an inner element. A part written `column` / `if` / `children` is recorded `slot: false`. The IR field is already emitted; the test only covers a direct `children`.

- **A class row the node overrides is still refused.** `class.rs:42` drops a class row the node sets itself. `anatomy.rs:342-354` refuses that row anyway. The class does contain it; the row does not apply.

## What checks out

**Spelling isolation.** Checks read `Anatomy` only. `take_marks` and `parser/anatomy.rs` are the only readers of the `part` attribute. It is gone from the element before lint, lowering, symbols, class merge, inlining, and source maps. A `part` argument on a use is left alone (uppercase tags are uses). `describe` (`tamber_base.rs:121-192`) never adds `library`. `tamber_serve` does not serialize it. The block is added only in `tamber.rs:451-454`, and only on the IR file.

**Stripping is recoverable.** Each `Mark` keeps the part name, the attribute span, the element span, and `own`. The IR block has names, groups, slot, and variants, no spans. Expansion copies spans, so stage D can join `Mark.node` to the source map. A non-literal is discarded as `""`; only the refusal matters. That is enough for this commit.

**No-parts output.** An empty library keeps the early return at `tamber.rs:436`. An empty anatomy is skipped (`:363`). `parts` was previously an unknown section, and a `part` attribute on an element was not a legal app. Anatomy errors are pushed after style errors and before keyframes and the view, and only for a component that says something about parts. The 47/47 run was not repeated.

**Part checks.** Missing node, missing declaration, two nodes with one name, a non-literal, a bad name, and a mark inside a slot fill each produce `lower-anatomy-part` and the later ones `continue` before row checks. A part inside `for` / `match` / `if` stays `own` and is one mark; two arms with the same name are correctly two nodes. A nested class ternary is already `lower-class-name`. Styles from another file are in the merged style list, so a unique name is checked. `::placeholder color` is `PlaceholderColor`, outside every group, which matches D6 (placeholder color is a role). `buttonStyle` is a prop, so `tags::rows` is empty and anatomy does not refuse it.

**Groups.** `paint` / `text` / `shape` / `space` match the D2 table, including `text-decoration-line` and border color and width. `border-style` and the other `BorderStyle*` ids are in no group, as the commit says. A `border` shorthand is refused because it expands to those style ids; the message names the attribute `border`. Node rows are unlimited except on a native control. State layers go through `state_of`, so `:disabled color` is `TextColor`. Shorthands go through `tags::rows`.

**Control.** `input`, `textarea`, `select`, and `progress` are always native. A button is native unless `appearance` is the string `"none"`. The group must be exactly `control` (so `control control` and `control paint` are refused, and row checks are skipped). Other rows must be `accent-color`, plus `NATIVE_ROWS` on a button. The last `appearance` wins, node after styles. A radius without `appearance="auto"` is refused at `:313-332`. That matches demotion: `fields.rs:104-107` treats the four radii as disabling, and `buttons.rs:98-109` stays native only for a literal `"auto"` before that check. The other disabling rows (background, border width, border style, border color) are already outside `NATIVE_ROWS`.

**IR.** Identity is the existing `{file}#{component}`, with the bare name as fallback (`tamber_params.rs:74`). Variants are enum options or `false`/`true` for bool. Recording every component that declares parts, rather than only exported library components, matches C1; the D0 filter is C3.

**Tests miss:** a part inside `for`/`match`/`if`; two part names on one node; `part=""`; a variant from a non-row attribute or a use-argument; `children` under `if`; `::placeholder`; `buttonStyle` in a style; `border-color` / `border-width` accepted beside a `border` shorthand refusal; `appearance="none"` with a paint group; `control` repeated; a cross-file style; a duplicate style name; formatter round-trip; a `describe` snapshot showing no `library` key.
