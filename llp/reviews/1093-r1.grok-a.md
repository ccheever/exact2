1. **MATERIAL** — D5 (line 116) and §3 (line 182). The balancer stops once the content fits in N columns. Chrome keeps stretching while a taller column, still within N columns and not above the content height, removes a widows, orphans, or `break-avoid` violation.
**Evidence.** Six lines, `column-count: 2`, gap 0, width 400, `column-fill: balance`. Default widows: container height 60, split 3+3 (`/tmp/llp1093-m2.html:7`). `widows: 4; orphans: 2`: container height 80, split 2+4 (`:8`, also `/tmp/llp1093-dom.html:27-28`). Eight lines, `widows: 3; orphans: 3`, `column-count: 3`, stays at height 60 with a 3+3+2 split (`/tmp/llp1093-dom.html:29-30`): no legal three-column split exists, so Chrome does not grow further or drop a column.
**Fix.** Continue the stretch while the new H is at most the content height, still uses at most N columns, and improves the best break appeal. State the six-line pair as the fixture. Keep the “at most N − 1 passes” cap only if each pass adds the entire shortage, including the shortage from a widows or orphans violation.

2. **MATERIAL** — D5 (lines 115 and 119). `column-fill: auto` with an auto height is left as “whatever Chrome does.” Chrome does not balance, and it does not grow overflow columns.
**Evidence.** Six 20px blocks, `column-count: 3`, width 300, both axes auto: container 300×120, every child at x=0, first child width 100 (`/tmp/llp1093-dom.html:22`, `/tmp/llp1093-m2.html:18`). With a definite height of 80 the same fill does walk the columns and then overflows (`/tmp/llp1093-dom.html:23`).
**Fix.** Write that used behavior into D5. The sentence “fills each column in turn” applies when H is a definite height.

3. **MATERIAL** — D5 (line 114). `max-height` does not bound H the way a definite `height` does.
**Evidence.** Four 20px blocks, `column-count: 2`, width 200, `max-height: 200`. `balance`: container height 40, two blocks per column (`/tmp/llp1093-m2.html:22`). `column-fill: auto`: container height 80, all four blocks in column 0 (`:23`). **Fix.** Treat `max-height` as a cap. Below the cap, `balance` shrinks to the content and `column-fill: auto` behaves as the auto-height case in finding 2. At the cap, extra content becomes overflow columns of height equal to the cap.

4. **MATERIAL** — D4 (lines 99–108). “The latest break of the best appeal since the interval began,” and the sentence that a paragraph shorter than `orphans + widows` moves whole, both predict the wrong column.
