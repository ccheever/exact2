Snapback 0.4.33’s own contract (`CLIENT-AND-OPERATIONS.md` around the `dev` flags) says a script must use `--port 0`, read the stdout URL (or `SNAPBACK4_READY`), and prove the polled server with `pid` / `wrapperPid`. `temporary` is not a documented `/dev/status` field; the documented signal is the stderr banner `store: temporary — discarded on exit`.
