**Three blockers remain in HEAD.** The permitted tests pass: **18 tests, 89 assertions**.

1. **blocker — Persisted credentials can mix servers and tokens.** [code.ts:136](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:136), [ui.ts:83](/tmp/rv-e4-2/tools/figma-tamber/src/ui.ts:83). Saving server B succeeds before saving B’s token. If the second write fails or the plugin closes, reopening loads B with A’s previous token. Startup `load` also runs outside `busy` and reads the two keys separately, allowing an interleaved pairing to produce a mismatched pair. **Fix:** store `{server, token}` in one clientStorage entry, and finish initialization before enabling operations.

2. **blocker — Redirects can forward credentials to an unpaired server.** [ui.ts:15](/tmp/rv-e4-2/tools/figma-tamber/src/ui.ts:15). Fetch follows redirects by default. A cross-origin redirect can retain the custom `x-exact-tamber-token` header when the destination permits CORS; the special removal rule covers `Authorization`, not this header. Pairing can also follow a redirect and associate the returned token with the original URL. **Fix:** use `redirect: 'error'` for pairing and authenticated requests, and require pairing with the final endpoint. [Fetch redirect algorithm](https://fetch.spec.whatwg.org/#http-redirect-fetch).

3. **blocker — A refused re-pull is not undone.** [code.ts:83](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:83), [code.ts:108](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:108), [code.ts:157](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:157). `undo()` removes newly created objects but restores none of the existing modes, variables, values or metadata that `write()` changed.

   For example, replace all four contexts in an existing full collection, then encounter a variable-write failure: three old modes have already been deleted and the fourth renamed. Cleanup removes the new modes, leaving one renamed mode while the saved plan still describes the original four. Type replacement similarly deletes the original variable before its replacement succeeds. Migration deletion and baseline/plan writes are outside this cleanup entirely. A removal failure during cleanup also stops subsequent cleanup and masks the original error.

   **Fix:** make the entire apply—including migration and storage—one rollback unit, preserving IDs and bindings. Gather asynchronous reads first, then use an isolated Figma undo boundary or equivalent complete restoration. Account for a stale default mode that cannot be removed, and report cleanup failures without abandoning remaining cleanup. Figma exposes [`commitUndo` and `triggerUndo`](https://developers.figma.com/docs/plugins/api/figma/).

4. **should-fix — Collection and mode names still substitute for identity.** [code.ts:64](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:64), [code.ts:72](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:72), [code.ts:99](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:99). A first pull adopts any existing collection named `Tamber`, marks it owned, and removes its unrelated modes without confirmation. Conversely, renaming a previously pulled mode makes `holding()` ignore its edits; unchanged export contexts produce no context warning, and Apply deletes/replaces that mode. **Fix:** persist owned collection IDs and context-to-mode IDs. Refuse unrelated name collisions and resolve renamed owned objects by ID.

5. **should-fix — Library aliases and unresolved aliases disappear silently.** [code.ts:44](/tmp/rv-e4-2/tools/figma-tamber/src/code.ts:44). The target variable is fetched by ID, but its collection is sought only among local collections. An alias to a library variable therefore becomes `undefined`; Push preserves the baseline and the conflict check ignores the edit. Cycles and missing targets are also silently omitted. **Fix:** fetch/cache target collections through `getVariableCollectionByIdAsync`, and surface unresolved values instead of treating them as unchanged. [Figma’s variable lookup APIs](https://developers.figma.com/docs/plugins/api/figma-variables/).

6. **should-fix — Family parsing handles only double quotes.** [mapping.ts:111](/tmp/rv-e4-2/tools/figma-tamber/src/mapping.ts:111). Entering valid CSS-style `'ACME, Sans', serif` produces `["'ACME", "Sans'", "serif"]`. The new serializer/parser test proves only the serializer’s own double-quoted form. **Fix:** track either quote delimiter, handle escapes consistently, and reject unterminated quoted names.

7. **nit — Byte-equivalent opaque colours compare unequal.** [mapping.ts:83](/tmp/rv-e4-2/tools/figma-tamber/src/mapping.ts:83). Alpha `1` produces `#rrggbb`, while `0.9999`, which rounds to the same byte, produces `#rrggbbff`. `same()` consequently reports a change; for a wide-colour baseline this can unnecessarily replace the original with its sRGB fallback. **Fix:** decide whether to omit alpha after quantizing it, or compare four quantized channels directly.

8. **nit — The new queue entry points to the wrong bridge documentation.** [QUEUE.md:3](/tmp/rv-e4-2/QUEUE.md:3). `docs/recipes/tamber.md` contains no Paper/Pencil bridge. **Fix:** point to `tools/figma-tamber/README.md#paper-and-pencil-no-plugin`.
