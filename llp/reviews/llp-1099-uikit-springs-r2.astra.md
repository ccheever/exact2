NEEDS REWORK

1. **[BLOCKING] The revised sampling rule still fails A5.** [D6:383](llp/1099-uikit-springs.rfc.md:383) promises 10⁻³ accuracy with max(240 Hz, 16 samples/oscillation). Recomputing its interpolation gives **0.01877 moves** error for `spring(100ms, .01)`—still **0.00851 at 1/60 s**—and **0.007117** for `spring(400ms, bounce -.5)`. Use an error-controlled sampler covering oscillatory and overdamped curves. Apply resource refusals consistently across hosts: the currently allowed 60 s duration already requires over 14,400 frames, exceeding the browser-only 8,192 limit.

2. **[MATERIAL] A2 remains incomplete for cut times.** [D6:399](llp/1099-uikit-springs.rfc.md:399) keeps physical/response ends in the existing duration field, which [codec.rs:331](kernel/src/wire/codec.rs:331) decodes as f32. `200ms` becomes `0.20000000298023224s`. At authored time `0.2s`, text parsing has snapped while the wire path still shows **1.77290 moves** for the measured icon spring. Preserve end/delay precision or canonicalize them identically at every ingress; test exactly at authored cut times.

3. **[MATERIAL] The revised last-crossing algorithm still misses the last crossing.** [D3:234](llp/1099-uikit-springs.rfc.md:234) specifies the last root, but [fit.mjs:66](motion/tests/fixtures/uikit-springs/fit.mjs:66) scans backward in fixed increments. For ω=1, v=`1.2261769259289865`, it returns **4.142853 s**, although the last crossing is **5.421647 s**. The narrow intervening excursion exceeds ε. Bracket using the analytic extrema, then bisect the final descending branch; specify termination precision and test near-tangent excursions and large velocities.

4. **[MATERIAL] Release velocity still conflicts with the overdamped branch.** [D4:278](llp/1099-uikit-springs.rfc.md:278) makes the actual derivative `(v+2ζω)Δ`, while [D5:333](llp/1099-uikit-springs.rfc.md:333) substitutes release velocity for `vΔ`. With `400ms, bounce -.5`, Δ=100 and release velocity zero, that substitution launches at **6,283.19 units/s**. Distinguish the API parameter from the actual derivative and explicitly choose which release preserves. Also specify bounce completion with unequal per-axis release velocities and Δ=0; D3’s normalized-velocity formula cannot directly handle those cases.

5. **[MATERIAL] The opacity probe does not establish the blanket zero-velocity rule.** [D5:360](llp/1099-uikit-springs.rfc.md:360) says replacement uses zero velocity, but [probe/main.swift:221](motion/tests/fixtures/uikit-springs/probe/main.swift:221) explicitly passes zero on both calls. [Report:2466](motion/tests/fixtures/uikit-springs/ios-27.0.txt:2466) separately shows opacity accepting authored velocity 1. Keep Q6’s defensible presentation-value restart, but distinguish **discarding inherited velocity** from **discarding newly authored velocity**. Probe nonzero retarget velocity and record k, c and `initialVelocity`; the current R fitter merely prints “velocity 0.”

6. **[MATERIAL] Terminal duplicate offsets do not finish the retarget lowering design.** [D5:306](llp/1099-uikit-springs.rfc.md:306) requires every component’s independent snap; [D6:386](llp/1099-uikit-springs.rfc.md:386) only describes snapping to the target at the final offset. An earlier component’s cut needs duplicate **interior** offsets containing the aggregate values before and after that cut. Also update [timelineEasing:78](host/web/motion-glue.js:78), which reconstructs uniformly spaced offsets and would spread the step into a ramp. Specify propagation through every frame consumer and test a large intermediate snap plus delayed retargeting. [WAAPI supports overlapping offsets.](https://www.w3.org/TR/web-animations-1/#the-effect-value-of-a-keyframe-effect)

7. **[MATERIAL] D6 omits dynamic paint springs on the JS target.** Its [JS plan:380](llp/1099-uikit-springs.rfc.md:380) covers static lowering and removal of two integrators. But [style.rs:534](host/web-js/src/style.rs:534) strips dynamic spring declarations from CSS, while [motion/src/lib.rs:20](host/web-js/motion/src/lib.rs:20) only observes the four compositor properties. A computed `background-color spring(...)` therefore has no playback path. Add runtime lowering through `exact-motion` into the shared paint `linear()` representation, with dynamic-string cross-host tests.

8. **[MATERIAL] D2 validates W but leaves resolved-coefficient overflow unspecified.** [D1:165](llp/1099-uikit-springs.rfc.md:165) accepts arbitrarily small positive durations; [D2:204](llp/1099-uikit-springs.rfc.md:204) only validates W and its residual. For `spring(1e-200s, .8)`, W=`8.994296689…` passes, but **k and c are infinite**. Explicitly validate resolved coefficients and scaled velocities before accepting or mutating motion state, preserving [SpringConfig::validate](motion/src/spring.rs:79). A1 is only partially disposed.

9. **[MATERIAL] The bounce timing approximation needs a separate conformance contract around cuts.** For [U’s negative-bounce case:9646](motion/tests/fixtures/uikit-springs/ios-27.0.txt:9646), D3 computes **0.587817359 s**, versus UIKit’s **0.587920690 s**. At UIKit’s end−1 µs, the proposed animation has snapped to 1 while the measured-coefficient curve is **1.006513**. Thus the small relative timing error does not imply the [renderer’s 10⁻⁴ bound:671](llp/1099-uikit-springs.rfc.md:671). Feed both measured coefficients **and measured end times** into isolated renderer tests; separately test authored end reconstruction and state its discontinuity-window error. Qualify the claim that every form ends where Core Animation does.

10. **[MINOR] A6’s linearity conditions remain incomplete.** [D5:320](llp/1099-uikit-springs.rfc.md:320) requires equal k and c, but timed physical springs also admit different masses. The condition is equal **k/m and c/m**. A matching restart must also start with the **sum of actual component derivatives**, including the new velocity impulse. For k=100, c=10, m=1, successive Δ=100 and Δ=200 moves with v=1, retargeted at 100 ms, that derivative is **746.1265**, versus **546.1265** from merely carrying the old velocity. State the complete initial conditions.

11. **[MINOR] Some mathematical claims still exceed the evidence.** The fit reproduces the reported counts and aggregate residuals, and the dimensionless reduction is sound for normalized oscillator dynamics. However, [“cannot be fixed by tuning”:655](llp/1099-uikit-springs.rfc.md:655) contradicts [the admitted uncertainty:533](llp/1099-uikit-springs.rfc.md:533); the measured band is not a universal guarantee. Limit Q1’s claims to the sampled reference. Label the W/k errors as **relative**, and correct [D2:197](llp/1099-uikit-springs.rfc.md:197): its logarithmic expression is undefined at ζ=1, which requires the separate critical equation/constant. Q2–Q5’s recommendations remain defensible.
