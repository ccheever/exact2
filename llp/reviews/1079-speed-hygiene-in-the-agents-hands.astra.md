# Review: LLP 1079 (speed hygiene in the agent's hands)

**Reviewer:** Astra (codex gpt-6-astra, max), requested by Charlie, 2026-10-02  
**Subject:** llp/1079-speed-hygiene-in-the-agents-hands.rfc.md (draft r1)

**Verdict:** NOT READY — the counter, snapshot and frame-attribution contracts need corrections before implementation.

1. **High — The proposed period can manufacture or conceal dropped frames.** D3 uses `link.duration`, although `host/apple/Sources/ExactKit/Session.swift:1347` explicitly explains why it is wrong for ProMotion and uses `targetTimestamp - timestamp`. Browser `period_ms` starts at zero and eventually accepts sustained double-slot callbacks as a slower cadence (`host/web/pace.js:20`, `host/web/pace.js:79`), potentially normalizing sustained jank. Specify period provenance, bootstrap and rate-change handling; distinguish observed callback cadence from a target deadline. The example’s `41.7 / 8.3` implies four missed intervals, not three.

2. **High — Activity and sampling boundaries are incomplete.** “Something wanted frames” does not exclude the idle interval preceding a newly applied batch or a hidden-tab pause. The proposed hooks also miss work: `timer-glue.js` schedules around timer demand (`host/web/timer-glue.js:19`), JS `paint()` requires a frame task (`host/web-js/rt.js:292`), and GPU frames have another loop (`host/web/gpu-glue.js:350`). Define visible, continuously active sampling segments; reset the previous sample on parking/resume; explicitly cover input, scrolling, CSS motion, canvas work and batches applied outside callbacks.

3. **High — Retiring nodes erases the inefficiency the trace promises to reveal.** D1 resets counters on destruction and D5 exports only the live tree. Consequently, `created` is ordinarily one per surviving node, and repeated creation, updates and retirement disappear before export. Receipts themselves omit creations that died within the batch (`kernel/src/txn.rs:58`, `kernel/src/txn.rs:856`). Keep bounded per-site creation/retirement totals across node lifetimes, or narrow the advertised result to surviving-node changes and explicitly exclude historical churn.

4. **High — `since E` has no defined baseline operation.** D2 cannot reconstruct counters at an earlier epoch merely when first asked for that epoch; four retained snapshots also have no release policy. Epoch alone is insufficient because layout changes retain the current commit epoch (`kernel/src/kernel.rs:509`). Prefer two identity-qualified reads with subtraction in the driver. This also removes `state {"frames":"mark"}`, a mutation presented as a question despite `rules/DEFERRED.md:491` and the observational precedent in `llp/1035.002-native-result-inspection.rfc.md:124`. Correct the example: totals without a baseline cannot report surviving creations as zero.

5. **High — The promised frame-to-commit join is not present in the data.** Web and Apple batch trailers carry clocks but no epoch range (`host/web/src/batch.rs:744`, `host/apple/src/batch.rs:576`). `Runner::log` stamps the runner’s last logical time, not the frame’s observation time (`runner/src/runner.rs:965`). Successful frame tasks lack individual commit lines (`runner/src/runner/commit.rs:173`); JS’s journal is unbounded and successful commits add no such line (`host/web-js/rt.js:127`, `host/web-js/rt.js:178`). Specify bounded records carrying batch identity, epoch ranges and explicit observation times. Missing journal lines cannot establish “nothing else in between.”

6. **Medium — The kernel already compares values, and touches are not binding evaluations.** D1/Q3’s comparison premise is false: equal props, styles and children are skipped at `kernel/src/txn.rs:595`, `kernel/src/txn.rs:669` and `kernel/src/txn.rs:716`. The runner also skips equal binding results (`runner/src/instance.rs:795`), while inherited changes touch descendants without their bindings going stale (`kernel/src/txn.rs:1141`). Correct the motivation and call the metric changed-node receipt membership. If unchanged writes are wanted, count the existing equality branches; do not describe another comparison as necessary.

7. **Medium — JS and Rust assign different units to `commits`.** Rust deduplicates touched nodes per receipt (`kernel/src/txn.rs:862`); D1 counts every JS DOM write. One CSS update alone performs a remove and a set (`host/web-js/rt.js:718`). Node attribution is feasible—the `P`, `S` and `css` helpers receive the element—but needs explicit instrumentation. Count a node once per successful commit, or expose a separately named DOM-write metric. Define creation/adoption and inherited-style differences before comparing targets.

8. **Medium — The runner does not already consume layout receipts.** The cited `runner/src/runner.rs:76` declares receipt containers; it is not an observation point. Apple consumes layout receipts in `host/apple/src/layout.rs:58`, Linux in `host/linux/src/height.rs:129`, including layouts without a runner commit. Add an explicit host-to-tally path covering ordinary, projected and region layouts. Also choose whether “commit” means a kernel transaction or runner action: reorder cleanup merges two receipts at `runner/src/runner.rs:1292`.

9. **Medium — The grouped read lacks identity fields and meaningful work bounds.** Ordinary `tree` emits neither site nor instance nor plan digest (`runner/src/agent.rs:318`); these currently belong to targeted inspection. Calling `site_of` separately for every node repeats recursive searches (`runner/src/instance.rs:1098`). Moreover, 2,000 records do not bound props, child arrays or traversal work: current subtree reads materialize all rows first (`runner/src/agent.rs:279`). Specify a compact counts reply with same-read identity, one-pass site attribution, bounded traversal/bytes and visibly partial aggregates.

10. **Medium — LoAF cannot supply the promised general per-frame layout time.** D3’s layout field needs explicit availability and joining rules (`llp/1079-speed-hygiene-in-the-agents-hands.rfc.md:197`). Long-frame observations leave shorter missed deadlines without attribution. `styleAndLayoutStart` is a start timestamp: spell out the end calculation as `startTime + duration`, guard entries without a rendering span, and label the result as the reported style/layout tail. Define how delayed observer delivery updates an existing frame record; unavailable measurements must remain absent.

11. **Medium — A 600-record ring cannot report unqualified statistics since boot.** D3 retains only 600 frames, while D4 promises summaries since a mark or boot (`llp/1079-speed-hygiene-in-the-agents-hands.rfc.md:176`, `llp/1079-speed-hygiene-in-the-agents-hands.rfc.md:238`). Old worst frames and samples vanish. Choose lifetime counters plus explicitly windowed percentiles, or entirely windowed statistics. Report retained range, sample count and truncation, following the existing journal cursor contract (`llp/1012-agent-api-v1.spec.md:414`).

12. **Medium — The virtual clock does not guarantee repeatable counts by itself.** D6’s “same numbers on every run” excludes neither asynchronous resource completion nor image-driven layout; those remain independent of seeks (`llp/1012-agent-api-v1.spec.md:380`). Platform-timed native animations can also continue under agent mode (`host/apple/Sources/ExactKit/Session.swift:65`). Qualify reproducibility by controlled inputs and completion order. Define virtual frame counts independently of commits—several frame tasks can commit at one display instant (`runner/src/runner/commit.rs:164`)—or return only `virtual: true`.

13. **Medium — Production cost and offline evidence are underspecified.** A cargo-feature ban does not require always-on production collection; the host already knows production trust (`host/apple/Sources/ExactKit/Session.swift:59`). D5 retains instrumentation in production while D7 says it stays out of a bake. Resolve that contradiction, and describe ≤1% as an acceptance target: `--scaling` measures a Rust fixture, not JS instrumentation or frame collection (`scripts/metrics.mjs:258`). Budget snapshots, slot capacity and export work too. Finally, trace files need host/build/session identity, clock/proxy metadata and a source-map locator or sidecar: a digest cannot locate a map (`scripts/agent-inspect.mjs:9`). Reuse the existing sampler’s metadata and JSON-output pattern (`scripts/stress-metrics.mjs:136`), correcting the claim that no existing timing output can survive as a file.
