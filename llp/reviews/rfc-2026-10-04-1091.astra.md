The central erasure claim is correct: components expand, styles become rows, and functions emit inline bytecode ([inline.rs:367](contract/syntax/src/inline.rs:367), [class.rs:29](contract/lower/src/class.rs:29), [expr.rs:275](contract/lower/src/expr.rs:275)). Lean already consumes the loader’s merged AST; `contract types` emits structural, numbered types ([lean.rs:51](contract/cli/src/lean.rs:51), [typescript.rs:29](contract/cli/src/typescript.rs:29)). A sufficiently hygienic loader can preserve those downstream interfaces.

Other string protocols must remain distinct: injection keys match literally, route `pages` calls name data sources, and test files bypass compilation ([inline.rs:398](contract/syntax/src/inline.rs:398), [routes.rs:25](contract/lower/src/routes.rs:25), [lib.rs:379](contract/cli/src/lib.rs:379)).

SOUND WITH CHANGES

1. **Major — D4’s collision domain is insufficient.** “Same kind and name” misses shared lookup namespaces. A private `shape Item` and another file’s private `fn Item` survive D4 unchanged, then fail the global `type-fn-shape-name` check ([RFC:124](llp/1091-contract-modules.rfc.md:124), [types/lib.rs:1097](contract/types/src/lib.rs:1097)). Worse, a private shape `fire` can prevent substitution of another component’s `fire()` action prop: the inliner constructs a **global** constructor set and exempts those call heads from substitution ([inline.rs:139](contract/syntax/src/inline.rs:139), [subst.rs:170](contract/syntax/src/inline/subst.rs:170)). Framework shapes also occupy names without authored declarations ([types/routes.rs:43](contract/types/src/routes.rs:43)). Specify binding-aware hygiene across these lookup domains, including local capture, before promising unchanged downstream passes.

2. **Major — D5 needs an explicit propagation model and broader coverage.** A caller literal such as `Spinner(fx="pulse 1s")` acquires its animation context during prop substitution; rewriting only authored `animation` attributes cannot implement the promised caller-literal behavior ([RFC:159](llp/1091-contract-modules.rfc.md:159), [inline.rs:384](contract/syntax/src/inline.rs:384), [inline.rs:673](contract/syntax/src/inline.rs:673)). Preserve originating scope through substitution, or narrow that promise. Also include `exit-animation`, which resolves against the same keyframes table ([svg.rs:568](contract/lower/src/svg.rs:568)). The “first word” warning misses `` `1s ${name}` ``: shorthand names are not positionally first ([parse.rs:90](motion/src/animation/parse.rs:90)). Template handling must respect token boundaries and shorthand grammar. Preserve the existing timeline-shadowing rules when moving `clock.rs` ([clock.rs:42](contract/syntax/src/clock.rs:42)).

3. **Major — D10 needs a captured resolution graph, not just Contract paths.** D9 consults `package.json`/`exports`, but D10 promises to capture only `.contract` package files ([RFC:220](llp/1091-contract-modules.rfc.md:220), [RFC:246](llp/1091-contract-modules.rfc.md:246)). A non-default export cannot resolve in that mirror. Capture the consulted metadata, package roots, logical import locations and dependency edges; preserve canonical declaration identity across aliases and nested versions. Retain the TS bake’s capture-consistency check ([js/bake/lib.rs:747](js/bake/src/lib.rs:747)). Also distinguish the consumers: the bake recompiles staged Contract, whereas the web JS build compiles its original Contract input and stages only TS/JSON for typechecking ([js/bake/lib.rs:755](js/bake/src/lib.rs:755), [build.mjs:103](host/web-js/build.mjs:103), [build.mjs:170](host/web-js/build.mjs:170)).

4. **Major — Deploy needs frozen package inputs, beyond provenance hashes.** Deployment excludes `node_modules`, discovers app/Exact/Cargo repositories, and subsequently installs from captured lockfiles ([deploy.mjs:113](scripts/deploy.mjs:113), [deploy.mjs:308](scripts/deploy.mjs:308), [deploy.mjs:500](scripts/deploy.mjs:500)). Merely recording package name/version/source hashes does not materialize a linked sibling library or ensure the bake consumes the recorded bytes. Extend snapshot capture and materialization together, bind package metadata and contents into snapshot identity, and cover `file:`/workspace/link dependencies—not just registry packages ([RFC:255](llp/1091-contract-modules.rfc.md:255)).

5. **Major — D10’s watcher implementation scope is incomplete.** The default JS loop already watches the app recursively but excludes `node_modules`; the resident Rust loop compares only the root Contract’s bytes ([dev.mjs:25](host/web-js/dev.mjs:25), [dev.mjs:99](host/web-js/dev.mjs:99), [dev.rs:78](host/web/src/dev.rs:78)). Both need changes, beyond the files listed in §3. TS Cargo bakes already watch captured app files individually ([js/bake/lib.rs:342](js/bake/src/lib.rs:342)). Expose dependencies even after failed compilation, otherwise fixing a newly imported broken library may not retrigger compilation; today loader errors return before any source list escapes ([lib.rs:330](contract/cli/src/lib.rs:330)). Include resolution metadata and link replacement, not only successfully read source files.

6. **Minor — Byte identity is conditional, and “compat id” is incorrect.** Today equivalent declarations merge; D7 deliberately removes that behavior ([sources.rs:417](contract/cli/src/sources.rs:417)). Two previously merged shapes now produce two named plan types—even if unused ([lower/lib.rs:310](contract/lower/src/lib.rs:310)). Existing accepted duplicate imports also become D1 errors ([source_locations.rs:289](contract/cli/tests/it/source_locations.rs:289)). Narrow the guarantee accordingly. Separately, delivery compatibility hashes platform/ABI/capability inputs; the plan SHA is a separate artifact digest ([compat.rs:305](bake/src/compat.rs:305), [compat.rs:361](bake/src/compat.rs:361), [receipt.rs:76](bake/src/receipt.rs:76)).

7. **Minor — The mangled spelling is not universally Rust-safe.** Contract identifiers permit hyphens, while D4 sanitizes only the file stem; `Order-Item__ui` remains invalid as a Rust struct identifier ([lexer.rs:246](contract/syntax/src/lexer.rs:246), [RFC:126](llp/1091-contract-modules.rfc.md:126)). The generator interpolates shape names directly ([rust.rs:109](contract/cli/src/rust.rs:109)). Give Rust emission a collision-safe identifier mapping. Keep tooling identity separate from display spelling, retaining symbol kind and handling source-map class-origin labels too ([symbols.rs:50](contract/cli/src/symbols.rs:50), [map.rs:196](contract/cli/src/map.rs:196)).

8. **Minor — Library font delivery is unresolved.** D6 allows a library to ship a face, but lowering resolves font files exclusively beneath the app’s `assets/`, and D10 captures only Contract package files ([RFC:182](llp/1091-contract-modules.rfc.md:182), [fonts.rs:119](contract/lower/src/fonts.rs:119), [RFC:246](llp/1091-contract-modules.rfc.md:246)). Either require app-supplied assets explicitly or specify package asset capture and relocation. Global family naming alone does not deliver the font.
