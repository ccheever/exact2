1. **[Major] Computed commas still bypass scoping in `animation-name`.** [scope.rs:665](contract/syntax/src/scope.rs:665). Root imports and renders `ui.contract`’s `Card`; both files declare different `spin` and `pulse` keyframes. Card contains:

   ```contract
   state sep = ","
   view
     view animation-name=`spin ${sep} pulse` animation-duration="1s"
   ```
   The longhand branch examines only the first token. It rewrites `spin` to `spin__ui` but leaves `pulse` unchanged. The valid runtime value `spin__ui , pulse` therefore plays **root’s pulse**, despite the library declaration becoming `pulse__ui`.

2. **[Major] The shorthand fix models a comma alone, but not values following that comma.** [scope.rs:1014](contract/syntax/src/scope.rs:1014). Root imports Card; root and library declare different `spin` and `linear` keyframes. Card contains:
   ```contract
   state sep = ", ease"
   view
     view animation=`spin 1s ${sep} linear 1s`
   ```
   The new transition resets the slots without allowing the interpolation to fill the new animation’s easing slot. Consequently, `linear` is classified exclusively as easing and remains unchanged. At runtime, `spin__ui 1s , ease linear 1s` validly names **root’s linear**. This case requires the ambiguity refusal because `linear`’s role depends on the interpolated value.

3. **[Major] The new unconditional rename of `t` breaks an existing function when any module is imported.** [sources.rs:559](contract/cli/src/sources.rs:559), [scope.rs:801](contract/syntax/src/scope.rs:801).

Removing the unrelated import succeeds: [the checker explicitly prefers a declared function](contract/types/src/lib.rs:787). The rewrite must preserve that precedence.
