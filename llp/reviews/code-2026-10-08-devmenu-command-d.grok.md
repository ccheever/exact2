1. **MATERIAL** — With a sheet up, ⌘D still opens the dev menu when the app owns that chord. `ExactView.keyCommands` adds ⌘D only when `DevMenu.installed` is set and no app command has `input == "d"` and `modifierFlags == .command` (`host/apple/Sources/ExactKit/IOS/ExactViewIOS.swift:170-171`). A route sheet moves the viewport into the presented controller and presents it (`host/apple/Sources/ExactKit/IOS/ModalIOS.swift:473`, `:477`). UIKit’s next responder from a presented controller is the presenting controller, then the window, the application, and the app delegate, so `ExactView` is off that chain and the yield never runs. `AppDelegate.keyCommands` still appends ⌘D whenever `DevMenu.enabled` (`host/apple/Sources/ExactIOS/main.swift:185-198`) and `devMenu` calls `DevMenu.toggle()` (`:203`). The same delegate command is what runs for a route inside the navigation controller added as a child of that presenting controller (`host/apple/Sources/ExactKit/IOS/NavigationIOS.swift:276`). **Fix:** one predicate (enabled, installed for this session, and no app `Meta+d`) shared by both `keyCommands` overrides.

2. **MINOR** — `DevMenu.installed` stays true for the process after a single successful `install`. It is set just after the `enabled` guard (`host/apple/Sources/ExactKit/IOS/DevMenuIOS.swift:132-133`), the comment calls it per-window (`:121-122`), and every `ExactView` reads that one bool (`ExactViewIOS.swift:171`) and calls the global `DevMenu.toggle()`. A second scene (`ExactIOS/main.swift:248`) or a second pane (`host/apple/Sources/ExactHostIOS/main.swift:109-117`) then arms ⌘D on a view `install` did not attach gestures to, and the sheet uses the last `controller`. The sample host never calls `install` (`ExactHostIOS/main.swift:218-238`), so both of its sessions leave the flag false and ⌘D does nothing there. `DevMenuIOSTests` never clears the flag (`host/apple/tests/ExactKitTests/DevMenuIOSTests.swift:21`). **Fix:** keep a weak session (and window), add the command only when `self.session` is that session, and clear it when `enabled` is false or the window is gone.
