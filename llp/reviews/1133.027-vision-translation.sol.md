Four MATERIAL concerns remain. No files were modified. Line references below refer to [the reviewed RFC](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1027/cap1/llp/1133.027-vision-translation.rfc.md).

1. **MATERIAL — D8, lines 466–478; D9, lines 504–518; D16, lines 680–688: older Apple sessions cannot guarantee prompt-free translation.**

   The design permits tool and wake origins to translate, promising that removed languages produce `not-installed` and that only creation presents download UI. Apple documents that sessions obtained through `.translationTask()` **always** can request downloads. `notInstalled` applies to sessions that cannot request downloads—the installed-only API introduced in iOS/macOS 26. A prior availability check cannot atomically prevent language removal before translation. [Apple: canRequestDownloads](https://developer.apple.com/documentation/translation/translationsession/canrequestdownloads), [notInstalled](https://developer.apple.com/documentation/translation/translationerror/notinstalled).

   **Decision needed:** define a different caller policy for prompt-capable sessions before 26, restrict unattended translation to the installed-only API, or demonstrate an enforceable no-prompt mechanism. Drive the real pack-removal behavior; scripting the desired error does not establish this guarantee.

2. **MATERIAL — D16, lines 683–688; D17, lines 731–736; §7, lines 830–834: conditional download admission is assumed to exist but does not.**

   The built declaration validator accepts `download`, but [native admission](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1027/cap1/runner/src/runner/modules/admit.rs:450) and [web admission](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1027/cap1/host/web-js/modules.js:629) enforce top-level `origin` and `foreground`, without interpreting `download`.

   A read-only probe of the existing language-model implementation, using an in-memory browser stand-in, confirmed the gap: with availability `downloadable`, origin `tool` and foreground false, production reached `Browser.create`; its agent path returned `NotAllowedError`.

   **Decision needed:** explicitly build conditional admission or assign enforcement to implementations and amend the claimed runner guarantee. Translation also needs an unambiguous association between each create, its availability source and its selecting options. Prove enforcement through the replacement fixture in production mode.

3. **MATERIAL — D12, line 595; D8, lines 434–444: availability cannot query the model selected by `apple.strategy`.**

   `apple.strategy` is offered only on `createTranslator`. Apple’s strategies select different models, supported languages and installation states. Default `highFidelity` availability can be satisfied by installed Apple Intelligence assets while an explicit `lowLatency` create requires traditional language packs. The caller therefore cannot query readiness for the translator it intends to create. This contradicts the inherited same-options availability contract. [Apple: availability strategy](https://developer.apple.com/documentation/translation/languageavailability/preferredstrategy), [strategy-specific initialization](https://developer.apple.com/documentation/translation/languageavailability/init(preferredstrategy:)).

   **Decision needed:** expose the strategy on `translatorAvailability` and use the same effective strategy for availability, download admission, creation and session rebuilding.

4. **MATERIAL — D10, lines 550–553; §10, lines 982–990: the Android consumer omits mandatory Google attribution.**

   The proposed Excord UI displays only “Translated from Japanese.” ML Kit’s translation guidelines require applicable Cloud Translation attribution, including Google attribution beside results and application documentation requirements. The proposed consumer cannot ship as specified. [ML Kit usage guidelines](https://developers.google.com/ml-kit/language/translation/translation-terms), [attribution requirements](https://docs.cloud.google.com/translate/attribution).

   **Decision needed:** assign the required attribution to the consumer’s UI and documentation, making backend provenance available where necessary, or choose a different backend. The package itself can remain a data capability.

5. **MINOR — D5, lines 294–299: background suspension is not inherited universally.**

   Production [VideoTracks.foreground](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1027/cap1/packages/media-capture/apple/VideoCapture.swift:207) leaves macOS capture unchanged; the agent injects background muting. A passive observer can consequently keep analysing while the RFC promises `idle`.

   **Decision needed:** explicitly suspend scanning on foreground changes, or document the macOS behavior and test it outside the substitute.

6. **MINOR — D17 item 3, lines 722–727; §8, lines 853–854: a window does not fulfill the contacts presentation anchor.**

   [LLP 1133.018 D13](/private/tmp/claude-501/-Users-ccheever-projects-exact2/f4b5c629-4ed6-4746-9045-74f6106a629d/scratchpad/r1027/cap1/llp/1133.018-contacts-calendar.rfc.md:970) requires the initiating node’s rectangle in that window. `window` supplies no rectangle, although this RFC claims to build that anchor.

   **Decision needed:** include the event-target/frame propagation, or retain the contacts anchor as outstanding.

7. **MINOR — D18, line 747: Windows language detection is incorrectly declared absent.**

   Windows includes the ELS Microsoft Language Detection service. Its output is relevance-ordered language names rather than the proposed confidence distribution, which warrants an explicit mapping limitation—not “no system API.” [Microsoft Language Detection](https://learn.microsoft.com/en-us/windows/win32/intl/microsoft-language-detection).

   **Decision needed:** record the existing capability and explain whether its output prevents conformance or merely leaves implementation for later.

8. **MINOR — §9, lines 911–914; acceptance drive 7, lines 1033–1036: the substitute contradicts its Japanese acceptance fixture.**

   The fallback inspects the first letter’s script and maps Han to `zh`. The fixture starts with `明`, so it answers Chinese, while the drive requires Japanese.

   **Decision needed:** script that detection explicitly or change the fallback/fixture so the prescribed drive exercises the claimed path.
