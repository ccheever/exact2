NOT READY

1. **MAJOR — §1.6: letting go does not cancel every permitted save.** The executor aborts forgotten requests only when `safe()` identifies GET/HEAD ([executor_core.rs:535](/Users/ccheever/projects/exact2-wt-media23/host/apple/src/executor_core.rs:535), [:643](/Users/ccheever/projects/exact2-wt-media23/host/apple/src/executor_core.rs:643)). The wasm host likewise tracks only GET/HEAD for cancellation ([glue.js:753](/Users/ccheever/projects/exact2-wt-media23/host/web/glue.js:753)). §1.2 permits POST and other methods with `exactSaveTo`, so their files can publish after the answer is forgotten. Specify a publication-cancellation token for **every save**, independent of whether its network operation remains running. Test a forgotten POST save. Declaring Hermes’s separate `signal` limitation does not resolve this part of Astra r1 #3.

2. **MAJOR — §§1.4–1.6: cancellation and deadlines do not cover storage publication.** The prescribed check→sync→rename sequence leaves a cancellation window. The partial implementation checks abort at [executor_save.rs:163](/Users/ccheever/projects/exact2-wt-media23/host/apple/src/executor_save.rs:163), then `publish()` performs blocking sync and rename ([app_fs_unix.rs:755](/Users/ccheever/projects/exact2-wt-media23/vendor/ibex/crates/ibex2/src/stdlib/app_fs_unix.rs:755)). An abort during sync can therefore still replace the target. Web mutations can wait in `mutateIn` without any cancellation token ([storage-fs.js:343](/Users/ccheever/projects/exact2-wt-media23/host/web/storage-fs.js:343)); the JS target saves after `fetchWith` completes ([ts-fetch.js:100](/Users/ccheever/projects/exact2-wt-media23/host/web-js/ts-fetch.js:100)). Define one publication decision synchronized with cancellation, carry the original deadline through admission and storage, and specify how stalled filesystem work relinquishes publication authority. Test abort/timeout during sync, mutation-queue waiting, and IndexedDB commit.

3. **MAJOR — §1.4: absent `Content-Encoding` does not prove identity encoding on the web.** CORS exposes `Content-Length` by default but can hide `Content-Encoding`; the browser still supplies decoded bytes. Consequently, the proposed comparison rejects valid compressed downloads. This follows from Fetch’s [response-header filtering](https://fetch.spec.whatwg.org/#cors-safelisted-response-header-name). The current partial implementation already recognizes this and omits the comparison ([http-body.js:281](/Users/ccheever/projects/exact2-wt-media23/host/web/http-body.js:281)), contradicting the draft’s universal rule. Require browser transport framing checks; compare lengths only where the executor actually knows both representations match. Add a cross-origin gzip test without exposed `Content-Encoding`. Astra r1 #5 is only partially resolved.

4. **MAJOR — §2.6: releasing image bytes after the first bitmap breaks animated images.** Apple’s decode passes `input.url` into the animation owner ([RasterLoader.swift:220](/Users/ccheever/projects/exact2-wt-media23/host/apple/Sources/ExactKit/RasterLoader.swift:220)). Subsequent GIF frames reopen that URL, and WebP reads its file ([AnimatedRaster.swift:173](/Users/ccheever/projects/exact2-wt-media23/host/apple/Sources/ExactKit/AnimatedRaster.swift:173), [:202](/Users/ccheever/projects/exact2-wt-media23/host/apple/Sources/ExactKit/AnimatedRaster.swift:202)). A memory-backed `RasterInput` alone cannot support those paths. Extend the animation source to retain the acquired buffer and decode subsequent frames from memory; keep that allocation charged until its last decoder/owner releases it. Test GIF and WebP continuing after URL revocation, without spooling.

5. **MAJOR — §§2.2–2.3: the wasm Blob-upload carrier remains unspecified.** Saying the realm sends an object URL to the page skips the intervening Rust request. The realm’s request becomes `Request.body` through text/base64 decoding ([js/web/src/lib.rs:347](/Users/ccheever/projects/exact2-wt-media23/js/web/src/lib.rs:347)); `Request` has bytes and an app-file path, but no Blob reference ([runner/src/request.rs:99](/Users/ccheever/projects/exact2-wt-media23/runner/src/request.rs:99)). The synchronous engine-side handoff in §2.3 solves Hermes only. Specify the opaque reference’s field and complete realm→runner→batch→page transport, distinguish it from `exactBodyFrom`, and define acquisition before revocation. Test uploads from both iframe and worker realms, including refusal and disposal.

The status/header gate, preserved refusal body, actual byte count, and client staging/publication split resolve the parent’s Astra r4 #7 **at the design level**. The pseudo-header carrier correction, stream-refusal preservation, filesystem locking, and URL ownership changes address their corresponding Astra round‑1 findings.
