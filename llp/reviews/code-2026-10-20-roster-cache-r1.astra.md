1. **BLOCKING — Cached output need not be constant for one binary.** [host/apple/build.mjs:1259](/tmp/rv-roster-astra/host/apple/build.mjs:1259). `ExactModule.views` is an overridable computed property, documented as read once per process—not as independent of runtime inputs. Concrete repro: force the simulator route and make a factory’s `firstFrame` depend on `#available(iOS 27, *)`; build using an iOS 26 simulator, then an iOS 27 simulator without changing sources. The arm key stays identical, so the second build retains the old `ExactFirstFrameModules` even though executing that probe would print different JSON. Establish an explicit runtime-independent roster contract, or account for supported runtime dependencies before reusing output. The same concern applies to cached Catalyst/macOS probes after OS changes.

2. **NIT — Explicit simulator selection accepts another platform.** [host/apple/build.mjs:1263](/tmp/rv-roster-astra/host/apple/build.mjs:1263). `chooseSimulator` searches **all** available devices for an explicit name/UDID (`devices.mjs:199`); its iOS filter applies only to automatic selection. With a cold roster cache and `EXACT_SIM` naming an Apple TV, this boots that TV and attempts to spawn the iOS probe there, then falls through on failure. Validate the selected runtime before booting. Unknown names are diagnosed, and `bootedHere` correctly limits shutdown to a simulator this call booted.

3. **NIT — Packages prevent warm roster hits.** [host/apple/build.mjs:1158](/tmp/rv-roster-astra/host/apple/build.mjs:1158). When `packages.length > 0`, arguments contain `packageDir` and object paths beneath a fresh `exact-webarm-*` temporary directory. These paths are not normalized by `snapshot.key`, so successive unchanged builds get different probe keys. Probe source lists also omit package-object contents; currently the fresh paths prevent stale hits, but also prevent this optimization working. Normalize those paths and include their contents together.

4. **NIT — Documentation overstates key coverage.** [llp/1024-native-modules.rfc.md:736](/tmp/rv-roster-astra/llp/1024-native-modules.rfc.md:736). “Every input it compiles from” is inaccurate: `.framework` headers and Swift module interfaces are excluded from `frameworkSlice().stamped`; only archive-style `HeadersPath` trees are included. Library stamps use path/size/mtime, not bytes. These are existing arm-cache limitations, rather than new sidecar regressions. Narrow the claim, and retain a QUEUE follow-up for the package case above.
