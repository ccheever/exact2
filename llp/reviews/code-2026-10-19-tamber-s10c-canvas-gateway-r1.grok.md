## Security pass

1. **Tokens, grants, sessions.** Holds. Grant and session are `randomBytes(32)` (256 bits) at `scripts/tamber-canvas.mjs:194` and `:221`. A grant is burned synchronously before the success checks (`:216–218`) and dies at 30 s (`GRANT_MS`, `:44`, `expires <= now()`). The grant compare is SHA-256 plus `timingSafeEqual` (`:76–77`, `:218`). The grant travels in a JSON or form body; any query on the entry is not-found (`:203`) and is not burned. `log` (`:165`) and the errors name the client or a fixed string, not a secret. The cookie is a session id; `sessionOf` (`:231–238`) loads the token from the server map and rechecks `pairing.lookup`. Nothing in `*.mjs` / `*.js` reads `Cookie` except this module.

2. **Cookie.** Holds. `Set-Cookie` at `:226` is `__Host-exact-canvas=<id>; Secure; HttpOnly; SameSite=Strict; Path=/` with no `Domain`. A value the map did not mint fails closed. A tossed cookie is an unknown session, so it grants nothing on the canvas port, and the tool port never reads `Cookie`. Overwrite or delete yields not-found, which forces a fresh grant. Up to four same-name values are tried (`:111–113`); the first live one wins, so a tossed value beside the real one does not hide it.

3. **CSRF / origin.** Holds. The entry allows a missing `Origin`, the canvas origin, or `toolOrigin` (`:204–205`). Every proxied POST requires `Origin` to be the canvas origin exactly (`:255`); missing and the tool origin fail. No CORS header is set, and `access-control-*` is dropped on the way out (`:300`). `SameSite=Strict` covers the GETs.

4. **`forwarded` mark.** (a) Holds. Client `forwarded` is in `DROP_UP` (`:61`); every `x-forwarded-*` is dropped by prefix (`:272`); the gateway then sets `forwarded: for="_exact-canvas"` (`:282`), so a client `Connection: forwarded` cannot suppress it. (b) Holds for the two named tokens. `developmentGate` (`scripts/install-page.mjs:287–293`) sets `local` false when `forwarded`, `x-forwarded-for`, or `x-forwarded-host` is present, even for a loopback peer and a loopback `Host`. Both `host/web/dev.mjs:1329` and `host/web-js/dev.mjs:859` call `gate.check` first. `/__tamber/token` (`scripts/tamber-server.mjs:474–476`) and the install token (`host/web/local-install.mjs:89` and `:98`) require `access.local`. Exact `/__tamber` and `/__tamber/*` are `needs() === null` (`tamber-canvas.mjs:66`), so they are not proxied. The gap is the native admission token on `GET /__dev/open`, which does not consult `access.local` (finding 3).

5. **Header and URL leaks.** Upstream drops `Cookie`, `x-exact-tamber-token`, `Referer`, and the client's forwarding headers (`:61`, `:270–274`). Downstream drops `Set-Cookie` (`:62`). The rewriter (`:82–94`) covers `127.0.0.1`, `localhost`, and `[::1]`, raw and once-encoded, for the loop's own port, in headers and in HTML, JSON, and SSE. It misses other loopback ports and default ports 80/443 (`URL.port` is `''`, so the pattern demands a colon). `frame-ancestors` does strip every loopback source (`:96–103`); the only other loopback origin the dev servers attach is `http://127.0.0.1:7740` in that CSP (`scripts/tamber-server.mjs:1052–1056`), and it is removed. No other loopback URL showed up in the dev glue (relative `/__dev` paths; the resident loop's `--serve-as` pages name the public host).

6. **Allow list.** The scope table matches theme2's ruling and the user brief: POST `/__dev/design`, `/__dev/checkpoint`, and `/__dev/open` are `write`; GET and HEAD `/__dev/open` are `write` (`:70`); GET `/__dev/design` and the beacons, including POST `/__dev/gpu`, are `read` (`:55–67`). Any other `/__…`, `/.exact/`, or the entry is refused (`:72`). PUT and DELETE are refused. A single WHATWG parse already collapses `%2e%2e` to a path `needs()` refuses, and `%2f` stays encoded so it does not hit `/__tamber/token`. The hole is a pathname that still begins with `//` (finding 1).

7. **Revoke and expiry.** Holds. `end()` (`:164–171`) aborts every `AbortController` in `live`, deletes that client's sessions and grants, and unsubscribes. `proxy` registers the controller before any `await` (`:260–264`) and passes it to `fetch` (`:295`). The next request fails `valid()` or finds no session. A grant burned and a session stored in `enter` have no `await` between them, so a revoke cannot land in that stretch. If `onEnd` fires during `watch` because the client is already ended (`:173–179`), `end()` deletes the session just stored. Expiry without `onEnd` fails new requests; live streams wait for `onEnd`, which is A's contract.

8. **Limits.** Holds. Minting is 6 per 60 s per client (`:52`, `:189`), taken only after the token and the `read` check. Bodies are 1 MiB−64 (`:46`), and 16 MiB only when the path is exactly `/__dev/checkpoint` (`:286`) after the `write` check, so a read client never gets the larger budget. Caps are 16 sessions and 8 grants per client (`:53`, `:192–193`, `:222–223`), oldest dropped.

## Findings

1. **SHOULD-FIX.** `scripts/tamber-canvas.mjs:65–74` and `:295`. `needs('GET', '//127.0.0.1/__tamber/token')` returns `'read'` because the path does not start with `/__`. `proxy` fetches `loopOrigin + pathname`. `webRequestURL` (`scripts/origin.mjs:51–60`) parses a request-target `//127.0.0.1/__tamber/token` as scheme-relative, so the dev server's path becomes `/__tamber/token` (also `/.exact/install` and write-only `/__dev/open`). The forwarded mark still withholds the tamber and install tokens. It does not withhold the open-page admission token, and a read client would reach a write route. `new URL(req.url, base)`, which the tests use, collapses a leading `//` first, and `needs()` then refuses it, so this is not a confirmed exploit through that caller. Canonicalize inside `handle` before `needs()` and fetch only that path: reject a `new URL(pathname, 'http://exact.invalid')` whose host or path changed, reject `%2f`, `%5c`, backslash, and NUL, compare `/__` and `/.exact/` case-insensitively, and add those cases to `tamber-canvas.test.mjs`.

2. **SHOULD-FIX.** `scripts/tamber-canvas.mjs:82–94` and `:99–105`. Rewrite every loopback host at any port, including port 80/443 where `URL.port` is empty. Anchor the bare `host:port` rule so `notlocalhost:<port>` is not rewritten. If `toolOrigin` is itself loopback, `frameAncestors` filters it out and then pushes it back (`:104`); refuse a loopback `toolOrigin`.

3. **SHOULD-FIX.** `host/web/dev.mjs:1363–1368`, `host/web/serve.mjs:48–53`, `host/apple/build.mjs:286–295`. `GET /__dev/open` is proxied to a write client and embeds `scheme://open?url=…&token=<admission token>` with no `access.local` check. The rewriter rewrites the once-encoded loopback URL and leaves `&token=`. Omit `developmentLinks` when `access.local` is false, the same way the install token is omitted. This page is already served to `--lan` and `--allow-host` peers, which is why it is not blocking. The JS loop forwards `/__dev/open` to the resident with the gateway's headers (`host/web-js/dev.mjs:944` and `:997–1004`), so the same omission has to hold on the resident.

4. **SHOULD-FIX.** `scripts/tamber-canvas.mjs:137–147`. The additions require `limiter(key, {per, rate})` and `allows(scope, needs)`. The gateway calls `limiter({rate, per, clock})` and then `take(key)`, and `allows(scope, need, false)`. §10 (`llp/1121-tamber.rfc.md:4097` and `:4116`) records the code's shape as A's. A is not in this tree. Reconcile the signatures before the seam at `scripts/tamber-server.mjs:541–542` is pointed at A's exports.

5. **NIT.** `scripts/tamber-canvas.mjs:231–235`. Session lookup is a `Map` get of the SHA-256 hex, with no `timingSafeEqual`. Store the hash buffer and compare it the way grants do (`:218`). At 256 bits this is not a practical leak.

6. **NIT.** `scripts/tamber-canvas.mjs:222–223` and `:260–264`. Dropping the oldest session does not abort a stream that session already opened (`live` is keyed by client). There is no cap on concurrent proxied streams. Abort the evicted session's controllers, or cap `live` per client.

7. **NIT.** `scripts/install-page.mjs:287`. The gate treats `forwarded`, `x-forwarded-for`, and `x-forwarded-host` as non-local, and not any other `x-forwarded-*`. This gateway's own mark is `Forwarded`, so item 4b holds. Treat every `x-forwarded-*` as forwarding so a later mark cannot miss the check.
