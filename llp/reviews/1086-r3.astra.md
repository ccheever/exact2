1. **MATERIAL — D6: monotone unification does not guarantee the claimed convergence bound.**  
   [RFC:243](/Users/ccheever/projects/exact2/.claude/worktrees/agent-ae5e6cce2a46e6a63/llp/1085-what-the-app-diaries-ask-of-contract.rfc.md:243) says each change completes a `?`. However, [Ty::unify:102](/Users/ccheever/projects/exact2/.claude/worktrees/agent-ae5e6cce2a46e6a63/contract/types/src/lib.rs:102) accepts `? → option<?>`; consequently, `derive d = some(d)` grows indefinitely under the proposed iteration. More seriously, `action a(p, q)` used as `press=a(a, a)` repeatedly introduces branching `Action` types through [parameter refinement:460](/Users/ccheever/projects/exact2/.claude/worktrees/agent-ae5e6cce2a46e6a63/contract/types/src/component.rs:460). Their size grows exponentially; unrelated slots increase the proposed round allowance. A hard round cutoff alone therefore does not bound inference memory safely.

   **Evidence:** both examples parse and reach inference with `target/debug/contract build /dev/stdin --json`; the current bounded passes refuse them. The recursive growth is a consequence of applying r3’s repeated joins, not an observed hang in current code.

   **Fix:** specify recursive-type detection or an explicit type-growth guard, plus deterministic refusal on nonconvergence. Add both regressions. Otherwise defer D6 in this final round.

2. **MINOR — D2: `MAX_STRING + 2` needs a cross-segment counting invariant.**  
   [RFC:108](/Users/ccheever/projects/exact2/.claude/worktrees/agent-ae5e6cce2a46e6a63/llp/1085-what-the-app-diaries-ask-of-contract.rfc.md:108) does not state how previously split pairs correct the running count. Summing independently encoded segments overcounts by two bytes **per pair**, so a fixed two-byte allowance is insufficient.

   **Evidence:** a read-only Bun probe of `"😀😀".replaceAll("", "")` gives eight output bytes, while encoding its four individual UTF-16 units gives twelve. With a test limit of eight, that counter incorrectly exceeds `limit + 2`. The same issue scales to the actual limit.

   **Fix:** explicitly carry a pending high surrogate across segments and count the concatenated output, reconciling every pair. Test multiple split pairs at the byte boundary.

3. **MINOR — D2, §3: the existing case link is not a bounded-construction API.**  
   The linked callback returns a completed `Cow<str>` ([case.rs:29](/Users/ccheever/projects/exact2/.claude/worktrees/agent-ae5e6cce2a46e6a63/kernel/src/text/case.rs:29)); its lowercase arm calls whole-string `text.to_lowercase()` before returning ([case.rs:70](/Users/ccheever/projects/exact2/.claude/worktrees/agent-ae5e6cce2a46e6a63/kernel/src/text/case.rs:70)). Calling it and checking afterward violates D2’s allocation requirement. Calling it independently on fragments loses contextual casing.

   **Evidence:** Bun produces `"ος"` for `"ΟΣ".toLowerCase()`, but `"οσ"` when the characters are lowercased separately; `"İİ"` expands from four UTF-8 bytes to six.

   **Fix:** include a bounded or preflight API in the existing kernel link, preserving whole-string casing context, and name that kernel change in §3. This requires no shared JS evaluation budget.
