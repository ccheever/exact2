One fundamental liveness gap remains. R9 fixes late watchdog delivery, but does not guarantee that the watchdog gets armed.

1. **D6 can suppress the wake needed to detect stopped rendering.**

   [D6:267](/Users/admin/Developer/exact2-timer-wait-points/llp/1147-timers-that-may-wait.rfc.md:267) skips a waiting timer’s deadline wake when scrolling is already observed. But [D7’s watchdog](/Users/admin/Developer/exact2-timer-wait-points/llp/1147-timers-that-may-wait.rfc.md:308) detects stopped rendering only after an unanswered `requestAnimationFrame`. Nothing requires keeping such a request outstanding during an observed scroll. The existing runtime supplies no continuous frame loop without frame tasks ([rt.js:361](/Users/admin/Developer/exact2-timer-wait-points/host/web-js/rt.js:361)).

   Consider an otherwise quiet cross-origin iframe containing `after(5000, save, wait=scrollend)`. A fling starts before the deadline. The last visible rendering update completes, leaving the scroller recorded as moving and no animation callback outstanding. The parent then scrolls the iframe offscreen. Chromium can stop its rendering while scripts remain runnable; scroll-completion event delivery belongs to rendering’s scroll steps. ([Chromium throttling](https://chromium.googlesource.com/chromium/src/+/HEAD/third_party/blink/renderer/core/frame#throttling), [CSSOM scroll steps](https://drafts.csswg.org/cssom-view/#scrolling-events))

   At the deadline, D6 permits skipping the wake because the recorded scroll remains active. There is no unanswered animation request to start D7’s elapsed-time test, no delivered `scrollend`, no visibility transition and no cap. The save can remain unfired indefinitely. Removing the punctual-timeout requirement does not close this path.

   **Instead:** Require an independent liveness probe once an uncapped web `scrollend` timer becomes due, even when scrolling is already observed. Keep its deadline wake and maintain an outstanding animation request/watchdog pair until scrolling ends or rendering is classified as stopped.

Syntax, live sampling, repeat phase, gate rollback, refusal continuation, seek/takeover rules and Android’s separate publication acknowledgement otherwise hold up at the design level. Existing JS live-clock tests pass 6/6.
