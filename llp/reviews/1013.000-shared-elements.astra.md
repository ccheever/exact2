The platform split fits Charlie’s goal. Draft r3 needs architectural fixes before implementation.

- **Must-fix — Name uniqueness contradicts UIKit zoom.** D1 permits one live holder per session; D8 requires matching holders in outgoing and incoming routes. Those routes remain mounted together. Scope uniqueness per route/presentation and define which pair selects the controller’s zoom when several names match. ([RFC:90](/tmp/rv-1013-plan/llp/1013.000-shared-elements-native-first.rfc.md:90), [RFC:291](/tmp/rv-1013-plan/llp/1013.000-shared-elements-native-first.rfc.md:291), [ModalIOS.swift:108](/tmp/rv-1013-plan/host/apple/Sources/ExactKit/IOS/ModalIOS.swift:108))

- **Must-fix — Specify the handoff’s phases and coordinate ownership.** Kernel name matching is feasible; presented geometry is host state. Existing `Layout` contains parent-relative geometry and becomes a local offset, whereas D4 seeds window coordinates. Ordinary layout observation would compete with that ownership. Capture before retirement, prepare/layout/scroll the destination, then seed a consistently mapped projection. Also handle multiple receipts folded into one presentation batch. ([RFC:120](/tmp/rv-1013-plan/llp/1013.000-shared-elements-native-first.rfc.md:120), [layout.rs:134](/tmp/rv-1013-plan/kernel/src/motion/layout.rs:134), [host.rs:1202](/tmp/rv-1013-plan/host/apple/src/host.rs:1202))

- **Must-fix — Existing exits cannot supply D5’s ghosts.** The gallery destroys the image’s ancestors. Existing exits require a surviving parent and an explicit exit animation; destroying that parent ends retention. Extract the named descendant before recursive destruction and define ownership through reversal, destination eviction and unmatched departure. D3 currently omits unmatched leavers while D6 promises their fallback fade. ([RFC:180](/tmp/rv-1013-plan/llp/1013.000-shared-elements-native-first.rfc.md:180), [txn.rs:855](/tmp/rv-1013-plan/kernel/src/txn.rs:855), [presence.rs:95](/tmp/rv-1013-plan/host/apple/src/presence.rs:95))

- **Must-fix — Drag takeover and backdrop continuation are not built.** Holds own `Translate`/`Scale`, not the flying `Layout`; the timeline explicitly reads only `Translate`. Destroying the source invalidates its holds. Furthermore, the gallery’s handle is the image’s sibling, so lifting the image leaves its gesture machinery behind; lifting the transform owner violates the adapter’s direct-parent requirement. Define atomic takeover, velocity transfer before removal, and backdrop lifetime explicitly. ([RFC:268](/tmp/rv-1013-plan/llp/1013.000-shared-elements-native-first.rfc.md:268), [timeline.rs:137](/tmp/rv-1013-plan/motion/src/engine/timeline.rs:137), [LLP1002:121](/tmp/rv-1013-plan/llp/1002-motion-v1.rfc.md:121), [gallery:456](/tmp/rv-1013-plan/apps/interaction-gallery/app.contract:456), [TransformDragIOS.swift:134](/tmp/rv-1013-plan/host/apple/Sources/ExactKit/IOS/TransformDragIOS.swift:134))

- **Must-fix — Reparenting changes interaction and accessibility semantics.** A window layer below presentations cannot display a flight inside an opaque modal. Native inertness walks physical ancestors, hit-testing uses view bounds, and accessibility reports the physical frame. Lifting breaks those assumptions; surface-only resizing also leaves larger destination bounds hittable. Define presentation-local flight containers, logical ancestry, hit regions and accessibility placement. ([RFC:138](/tmp/rv-1013-plan/llp/1013.000-shared-elements-native-first.rfc.md:138), [NodeViewIOS.swift:237](/tmp/rv-1013-plan/host/apple/Sources/ExactKit/IOS/NodeViewIOS.swift:237), [NodeViewIOS.swift:690](/tmp/rv-1013-plan/host/apple/Sources/ExactKit/IOS/NodeViewIOS.swift:690), [NodeViewIOS.swift:765](/tmp/rv-1013-plan/host/apple/Sources/ExactKit/IOS/NodeViewIOS.swift:765))

- **Must-fix — The web needs two integration points and asynchronous ordering.** The default JS target directly flushes DOM effects; it does not consume kernel handoff batches. `startViewTransition` delays its callback, and skipping still executes that callback. Later commits must not overtake it. Define update completion, failure cleanup, and a `ready` barrier before agent seeking. ([RFC:310](/tmp/rv-1013-plan/llp/1013.000-shared-elements-native-first.rfc.md:310), [rt.js:174](/tmp/rv-1013-plan/host/web-js/rt.js:174), [navigation.js:345](/tmp/rv-1013-plan/host/web/navigation.js:345), [CSS lifecycle](https://www.w3.org/TR/css-view-transitions-1/#view-transition-lifecycle))
