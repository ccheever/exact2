## Should-fix

1. **Minted-name binding is 48 bits.** `idOf` is SHA-256 truncated to 12 hex digits (`scripts/tamber-relay-server.mjs:346`). The public name is `<id>-tool.<label>.<domain>`. A connector that already has the token can grind a `run` offline until `idOf` matches, then take those names once they are free, same fatal `REFUSED` on the owner. `byName` stops only a live clash (`:373`).
2. **Per-IP limits use the raw address.** Pending, session, and greeting counters key `socket.remoteAddress` (`:232`, `:268`, `:290`). `masked` (`:160`) is logs only, so a rotating IPv6 /64 is a new key each time, and `::ffff:a.b.c.d` is a different key from `a.b.c.d`. `pendingTotal` (4096) and `streamsPerSession` (64) still cap the damage.
3. **TXT work has no in-flight cap.** `txts.take` allows 10 requests a minute (`:333`); each `dnsHook` may run 300s as its own process group (`scripts/tamber-relay.mjs:131`). One account can keep on the order of 50 hooks alive.
