I would not land `8080b3d2b` yet. The journal and digest handling can lose writes or affect files outside the project.

1. **High — Paths are not confined to the project.** [tamber_serve.rs:153](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:153). Recovery joins arbitrary journal paths, allowing absolute paths, `..`, and targets such as `tamber.lock`. Manifest-selected designs also lack containment checks. Ordinary unknown `file` paths are rejected by `plan`, but a manifest can admit an escaping path. Predictable temp files use `File::create`, which follows symlinks. **Fix:** validate all destinations against confined design files, reject unsafe path components and symlink traversal, and exclusively create transaction-specific temps.

2. **High — The commit protocol is not crash-durable.** [tamber_serve.rs:420](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:420). The journal is written directly to its final name; interruption can leave truncated JSON that prevents startup. File `sync_all()` calls do not establish the required ordering of directory entries. No directory is synced before renames, after renames, or after journal removal, so a machine crash can leave a partial transaction without recoverable intent. **Fix:** atomically publish a fully synced journal, sync its directory before applying renames, sync affected directories, then remove and durably retire the journal.

3. **High — Recovery silently accepts incomplete transactions.** [tamber_serve.rs:145](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:145). Journal read errors are treated as absence, malformed entries are skipped, and a missing temp is assumed already renamed. Recovery then deletes the record without checking target contents. A lost temp can therefore leave old bytes permanently installed. **Fix:** use a validated journal schema containing expected postimage digests; accept a missing temp only when its target matches that digest. Preserve the journal and fail closed otherwise.

4. **High — A failed commit leaves pending intent vulnerable to the next request.** [tamber_serve.rs:388](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:388). A rename failure after an earlier rename returns an ordinary error while the server continues serving. The next transaction reuses temp names and truncates the existing journal, destroying recovery information. **Fix:** after publishing intent, complete recovery before serving another request, or terminate while preserving the transaction. Never overwrite outstanding intent.

5. **High — Digest checks, planning, and undo preconditions use different snapshots.** [tamber_serve.rs:323](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:323), [tamber_serve.rs:390](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:390). A hand edit between hashing and planning can be silently accepted or overwritten. Worse, an edit between commit and the subsequent digest read becomes the precondition for restores calculated against different bytes. `describe` similarly reads its IR and digest separately. **Fix:** hash the exact snapshots used for planning and reads, add commit-time external-change detection/coordination, and derive inverse preconditions from the planned postimages.

6. **Medium — Restarted servers reuse undo IDs.** [tamber_serve.rs:134](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:134), [tamber_serve.rs:392](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:392). Restart discards history and resets numbering. After a new transaction issues `inv-1`, an old client’s `undo inv-1` can undo that unrelated transaction. **Fix:** use globally unique or session-qualified IDs with explicit expiration; persist issued records if undo must survive restart.

7. **Medium — Undo unnecessarily depends on every design file.** [tamber_serve.rs:398](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:398). Each inverse stores all project digests. Editing file B therefore prevents undoing an independent edit to A, although A still matches its postimage. **Fix:** retain inverse preconditions only for files that inverse edits.

8. **Medium — Issued inverses grow without a bound.** [tamber_serve.rs:398](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:398). Every successful transaction retains restores and a project-wide digest list indefinitely; only explicitly consumed inverses are removed. A long-running editing session steadily grows memory. **Fix:** define a history byte/count budget and explicit expiration or release behavior.

9. **Medium — Request lines have no size limit.** [tamber_serve.rs:51](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:51). `lines()` allocates until newline or EOF before JSON validation. One oversized or unterminated request can exhaust the sole writer’s memory. **Fix:** enforce a byte limit while reading, before allocating an unbounded line.

10. **Medium — Malformed optional fields can change the wrong thing.** [tamber_serve.rs:488](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:488). A present but non-array `when` becomes no conditions, changing the default instead of a conditional value. A non-string `file` silently selects the main design; malformed metadata is dropped. **Fix:** distinguish absent fields from incorrectly typed fields and reject invalid values consistently.

11. **Medium — `propose` ignores supplied digest preconditions.** [tamber_serve.rs:324](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:324). Even explicitly stale `files` produce a successful proposal, while the identical transaction conflicts. The proposal also returns no snapshot digests for later acceptance. **Fix:** validate supplied preconditions through the shared path and return the exact proposal baseline, especially before held proposals arrive.

12. **Medium — `live` is decided without D13’s dependency closure.** [session.rs:86](/tmp/rv-s3c3/tamber/src/session.rs:86). Comparing declaration shapes misses Contract consumers. For example, changing a color used by a Contract `color-mix(...)` to a host role still returns `live`, although the compiler’s synthetic consumer then fails to fold. Duration/easing cases are additionally outstanding once those kinds arrive. **Fix:** include compiler dependencies and synthetic tokens, validate the affected closure, and establish that the plan outside its design table is unchanged before returning `live`.

13. **Medium — `explain` reports textual matches instead of the dependency chain.** [tamber_serve.rs:306](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:306). It scans only the default expression, omitting references in `when` branches and intermediate chains. It also invents dependencies: a token named `r` matches the channel in `rgb(from #123456 r g b)`. **Fix:** expose semantic dependency edges from evaluation, including conditional branches and canonical role identities.

14. **Medium — Residual resolution omits labelled fallbacks.** [tamber_serve.rs:284](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:284). Host values return only CSS text and `residual: true`; the existing role/platform fallback pairs are discarded. Clients cannot obtain D13’s per-scheme fallback answer without reconstructing evaluator knowledge. **Fix:** return structured light/dark fallbacks explicitly labelled as fallbacks.

15. **Medium — Multi-file writes lack corresponding read identities.** [tamber_serve.rs:228](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:228), [session.rs:38](/tmp/rv-s3c3/tamber/src/session.rs:38). Every read uses `files[0]`, so clients cannot describe or resolve another editable file. `changed` also discards file identity, making identically named tokens ambiguous; adjacent-only `dedup()` inconsistently collapses them. **Fix:** support file-qualified reads and return changed tokens as `(file, token)` identities.

16. **Low — Unjournaled temps are never cleaned up.** [tamber_serve.rs:409](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:409). Failure or interruption before journal publication leaves temps behind, and subsequent processes use different PID-based names. **Fix:** clean up pre-intent failures and safely reclaim orphaned transaction temps under the project lock.

17. **Low — Metadata keys disagree with IR token names.** [tamber_serve.rs:251](/tmp/rv-s3c3/contract/cli/src/tamber_serve.rs:251). A role declared as `label` becomes `-exact-label` in the IR, while its metadata remains keyed by `label`. **Fix:** key metadata by the corresponding checked token’s canonical name.

18. **Low — Multiline diff headers have incorrect hunk lengths.** [session.rs:181](/tmp/rv-s3c3/tamber/src/session.rs:181). `@@ -N +N @@` denotes one line on each side regardless of how many lines are emitted. Additions, removals, and multiline edits therefore produce malformed unified diffs. **Fix:** emit actual old/new counts and preserve missing-final-newline information.
