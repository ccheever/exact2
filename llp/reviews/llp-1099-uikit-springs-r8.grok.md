NEEDS REWORK

Round 7’s dispositions are in the text, and the mapping claims I recomputed match it (`fit.mjs`: 100 misses, all inside the band, 1,916 flagged, 27 refusals; menu k matches; icon curve gap 0.0595; rows X end at 0.9235 s against `settlingDuration` 1). Four holes in the new host and retarget text would make a literal implementation miss the bands §8 tests.

1. **MATERIAL.** The paint placer never builds the terminal pair it requires, so a duration-form snap’s `linear()` is not a single string and fails `COLOR_TOLERANCE` in the last interval. D6 (`llp/1099-uikit-springs.rfc.md:569`) requires `linear(…, x(d⁻) 100%, 1 100%)`, then says to start from the two end stops of 4,096 evenly spaced samples. Those samples have distinct inputs, and `easing.rs:340` only treats an equal-input pair as a step, so the loop cannot add a second stop at input 1. The last open interval, from sample 4095 to the snapped 1, ramps through the snap. For the icon that ramp is the same 0.387 of the move the frame rule already rejects (`:584–586`; left limit 1.773 at `:716`). The 1/510 check only looks at samples, so it accepts the ramp. **Fix:** initial stops are `(0, y(0))`, `(1, y(d⁻))`, `(1, 1)`. Insert only inputs in `(0, 1)`. Judge samples of the pre-snap curve on `[0, 1)` and the snapped value at 1.

2. **MATERIAL.** The step-size envelopes decay in track time, while `A` and `B` are coefficients at each component’s release (`motion/src/spring.rs:108–121`). D6 (`:598–611`, scale `:621–625`) writes `e^(−ζωt)`, `e^(−ωt)` and `e^(sⱼt)` with `t` the frame time (`:598`). A component that began at `tᵢ>0` is under-decayed. The menu retarget at 0.1 s (`k = 497.5361505635245`, `ω = 22.30552`, `ζω = 17.8444`) has `e^(−ζω·0.1) = 0.1679`, so `M` is 5.96× too small, interpolation error is about `3.0·10⁻³·S`, and the parity band is `10⁻³·S` (`:657–658`). §8.4’s retarget-between-frames tests would reject that grid. A component still inside its delay is worse if a negative age is plugged in: the envelope blows up. **Fix:** every exponent and the critical `(t+h)` term uses component age `t−tᵢ`. A component that has not started contributes `Mᵢ = 0`.

3. **MATERIAL.** A retarget that crosses between component mode and restart mode has no rule. Duration, bounce, and any spring with an end time keep additive components (`:402–406`); a physical or response spring without an end time keeps LLP 1003 §5’s restart (`:492–493`). Today’s `spring(k, c, m)` is the restart form, and a later `spring(400ms, 0.8)` is the legal migration. Stage 0 lists mixed-form retargets as a measurement (`:1122`), which does not say what Contract does on that sequence: whether the live spring becomes component 0 (and with which end, the 10 s cap or the relative `10⁻⁶` test at `:450–451`), or the component list collapses into one restart. **Fix:** pick one and test it. Incoming restart form collapses the list into LLP 1003 §5. Incoming component form turns the live spring into component 0 with its `k, c, m`, its current residual and derivative, and its end, or the 10 s cap if it had none.

4. **MATERIAL.** Layout width and height can cross 0 between frames and are not in the clamp-crossing rule. Layout follows `center` (`:409`) and the web plays engine frames in place of `presence-glue.js`’s integrator (`:567`). That integrator clamps size with `Math.max(0, w+dw)` (`host/web/presence-glue.js:239`). The crossing rule names only opacity and `height` (`:671–684`) and cites a 0.37 px error for a 100→0 undershoot, which is already outside `10⁻³·S` for a 100 px move. §8.4 tests the height crossing (`:1080–1081`) and not layout size. **Fix:** add layout width and height to the same 60-step, in-range-endpoint crossing rule. Engine frames stay the 4-vector; the shown size stays LLP 1063’s stand-in.

The `scale-to-zero` sentence just below correctly discards the raw prefix. **Fix:** compare the bfcs rows for `t≥t₁` only, and say the raw prefix is backwards fill and is not the oracle.

7. **MINOR.** “Every colour stays inside `COLOR_TOLERANCE`, whatever its endpoints” (`:569`) is stronger than the harness. Colours are interpolated premultiplied (`motion/src/property.rs:301–304`) and read back straight, dividing by alpha (`:326–332`). A 1/510 progress error on `rgba(1,0,0,1)` → `rgba(0,0,1,0.02)` moves straight red by about 0.047 near `p = 0.99`, about 12 of 255. `COLOR_TOLERANCE` is one 8-bit unit (`host/web/src/parity.rs:43`).
