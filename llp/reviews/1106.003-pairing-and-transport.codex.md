## Concerns and requested changes

### Low: hardware model metadata wording is ahead of the implementation

The WebSocket row says "with known version/model facts". `T3MobileIdentity.Metadata.socketParameters` sends OS major version and app version, then explicitly omits the optional model field pending an exact Expo hardware marketing-name mapping. Say "known version facts; optional hardware model mapping remains unimplemented" or supply the real mapping and test it. This is a documentation correction, not a request to block M2 on a hardware catalog.

### Low: clarify why Swift copies are necessary

Decision calls the nine Foundation copies "the same source-capture workaround" as Gap001, but Gap001's reproducer is specifically the TypeScript bake capture. The Swift copies also carry UIKit/mobile policy adaptations. State which Swift app-module capture rule requires physical local copies, or describe these as app-local adaptations without asserting that the TS capture failure independently proves the Swift restriction. Preserve source headers and explain that the activity implementation and extracted T3PullRequestErrors are additional mobile files beyond the nine transport files.
