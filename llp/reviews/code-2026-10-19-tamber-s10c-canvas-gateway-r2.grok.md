## Findings

1. **NIT.** `scripts/tamber-canvas.mjs:113` and `:126`. `isLoopback` misses a trailing-dot domain: Bun keeps `URL.hostname` of `http://localhost.:8765/` as `localhost.`, and that string is left unchanged. Bare `127.1:port`, `foo.localhost:port`, and `[::ffff:127.0.0.1]:port` also stay; the URL forms of those same hosts are rewritten. The dev server’s own answers use `127.0.0.1` and `localhost`, which rewrite, and the gateway overwrites `Host` before the loop builds `/__dev/open`. Strip one trailing dot inside `isLoopback`, and run a bare `host:port` through `new URL('http://…')` plus `loopbackPort` instead of the fixed `BARE_HOST` list. Add `http://localhost.:port` to the address cases.

2. **NIT.** `scripts/tamber-canvas.mjs:73` and `host/web/dev.mjs:1472` (`sendStaticBody` in `host/web/serve.mjs:929`). `Range` is forwarded. Static HTML/JSON is answered 206 with a slice, and the gateway rewrites that slice, so a loopback URL cut mid-token would survive. `/__dev/open`, `/__dev/hello`, and the SSE handlers send the whole body with `res.end`, so today’s loopback-bearing answers are not sliced. Drop `range` and `if-range` in `DROP_UP`, the same way `accept-encoding` is dropped.
