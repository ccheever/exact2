## Should-fix

1. **No cap on concurrent pre-auth sockets** — `scripts/tamber-relay-server.mjs:199` and `:205`. Every accepted TCP connection is held until `helloMs` (10s). The timer is not refreshed by extra bytes, and a single hello is size-bounded, but nothing limits how many sockets one address, or the process, may hold at once. `greetingsPerIp` (`:272`) applies only after a full greeting is refused, so it does not cover a slow hello or a stalled control handshake. `perIpPerSession` applies only after the SNI hits a live session.

## Nits

- **Certificate may carry extra names.** `scripts/tamber-relay-server.mjs:178` uses `checkHost(domain)` and does not reject other SANs. Docs (`docs/tamber-relay-service.md:65`) and help (`scripts/tamber-relay-server.mjs:431`) say the certificate is for `domain` only. Start still requires that it names `domain`, is valid now, and matches the key. Expiry is checked only at start, which is what the 14:34 ruling asked for.
- **`streamsPerSession` help undercounts.** The cap is carried plus waiting (`scripts/tamber-relay-server.mjs:238`). The config table (`docs/tamber-relay-service.md:69`) and `CONFIG_HELP` (`scripts/tamber-relay-server.mjs:435`) say “clients carried.” The sessions paragraph (`docs/tamber-relay-service.md:41`) is the one that matches the code.
- **Compressed IPv6 is logged whole.** `masked` (`scripts/tamber-relay-server.mjs:158`) keeps the first four colon-separated fields. `2001:db8::1` becomes `2001:db8::1::`.
- **`accounts add` does not catch a `labels.seen`-only refusal.** `scripts/tamber-relay-server.mjs:484`. If the JSON `revoked` list was edited away and only `labels.seen` still has the label, `loadAccounts` throws, the process dumps a stack, and `accounts.json.tmp` is left behind. The rename is skipped, so the label is not reissued.
- **Grace ignores queued clients.** `ended` (`scripts/tamber-relay-server.mjs:360`) starts the grace timer when idle and carried are empty. With `waitMs` greater than `graceMs`, `drop` (`:368`) cuts those waiters early. Defaults are 2s and 60s.
- **Fuzz does not prove the tail is unread.** `scripts/tamber-relay-server.test.mjs:312`. It checks `read <= 5+16384`. A mutated length may legally cover the appended `after`. `helloName` itself only indexes `subarray(5, 5+length)` (`scripts/tamber-relay-server.mjs:54`).
- **The waiting-client test never opens a TXT request.** `scripts/tamber-relay-server.test.mjs:326`. The title says TXT requests are cut. The in-process `dns.publish` (`:46`) also ignores the abort signal. The command path does honor it (`scripts/tamber-relay.mjs:140`).
