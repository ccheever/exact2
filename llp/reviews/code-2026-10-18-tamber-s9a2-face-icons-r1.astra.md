1. **BLOCKING — Translucent Mac tints become opaque.** [FaceSymbol.swift:73](/tmp/rv-s9a2-r1/host/apple/Sources/ExactKit/FaceSymbol.swift:73) composites tint with `.sourceAtop`, preserving the black template’s alpha. A 50%-alpha red tint produces opaque dark red; a transparent tint leaves black. An in-memory Core Graphics probe confirmed this. **Fix:** use `.sourceIn` or fill through the image’s alpha mask. Add pixel assertions for transparent and translucent tints.

2. **BLOCKING — Standard grouped cells give paths different layout space from SF Symbols.** [GroupedListIOS.swift:884](/tmp/rv-s9a2-r1/host/apple/Sources/ExactGroupedLists/GroupedListIOS.swift:884) supplies an ordinary template image without setting `reservedLayoutSize`. UIKit reserves standard symbol space for SF Symbols but uses actual image dimensions for ordinary images. Consequently, adjacent SF/path rows can have different title alignment after the new custom-to-standard conversion. This follows [UIKit’s documented image-layout behavior](https://developer.apple.com/documentation/uikit/uilistcontentconfiguration-swift.struct/imageproperties-swift.struct/reservedlayoutsize). **Fix:** request `.standardDimension` for the relevant image-layout axes and test adjacent rows’ actual geometry.

3. **SHOULD-FIX — Grouped path images retain stale Dynamic Type sizes.** [FaceSymbol.swift:82](/tmp/rv-s9a2-r1/host/apple/Sources/ExactKit/FaceSymbol.swift:82) rasterizes using the global preferred body size, without the owning cell’s traits. Changing Dynamic Type therefore leaves existing path images at their previous dimensions while native text and symbol configurations adapt. **Fix:** resolve dimensions against the cell’s traits and regenerate path images on relevant trait changes. Test a content-size change without changing row data.
