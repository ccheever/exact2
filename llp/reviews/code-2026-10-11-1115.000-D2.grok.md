SOUND WITH FIXES

**BUG** `kernel/src/grouped.rs:169` — `TextLook::of` treats the whole computed font as said when any of the five font rows is. `NodeRef::says` (`kernel/src/kernel.rs:127`) uses `inherited_source` (`kernel/src/arena.rs:513`), which walks every ancestor until a node sets that row. A heading sets only `font-size` and `font-weight`, both implied (`contract/lower/src/tags.rs:1360`). The grouped sheet does not set `font-family`. A page `font-family` (or `font-style`, or `font-variant-numeric`) is therefore said, and the payload includes the heading’s implied size and weight.

Input: `view font-family="Georgia"` around `list listStyle="inset-grouped"` → `section` → `button` → `text role="heading" "Title"`. iOS receives the heading’s size and bold weight as authored, so the cell does not keep UIKit’s font. The new heading case only holds when no ancestor font row is written.

Fix: pass through only the rows `says` is true for, and leave the others unset so UIKit keeps its own size and weight.

The walk has no list or cell bound. It stops at the nearest node that sets the row, at a non-inherited row, or with “no source” when `control_text_start` has the row (`kernel/src/arena.rs:519`), in which case `says` is false. A sheet `color` on the title stops a page `color` there, and that row is implied, so the page colour does not mark the title said. `control_text_start` is a **RISK**: `computed_source` returns that style, while `says` does not read its bit.

**NIT** `kernel/src/export.rs:11` — the envelope comment still says `version u16 = 1` and describes a style as one mask. The constant and the check are 2.

Checked and holding: the bit is set only at emission (parser and class rows true; tag rows, heading, link run, `hr`, grouped `attr`, derived rows, implied `closedby` / `position` / audio / `min-width` false). Last-wins swaps the whole `BindingsRow`, so the survivor’s bit is the one in the plan. `apply_patch` replaces the bit for rows in the patch mask, `clear` drops it, `copy_rows` does not copy it, so a child does not inherit the bit. The Apple `"written"` list is built only from rows that same dictionary emitted, `FlatPaint` ignores it, and `ownColor` / bar tint / swipe accent read `wrote` with no parent or `isSystemColor` guess. The wire patch is one extra mask per style (the export calls that 32 bytes); the interner keys the whole `StyleProps`, so different bits do not share, at a cost of unique styles rather than of nodes.
