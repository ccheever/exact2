   `app.contract` does not import the private `fn save`; `save(1)` should bind its action’s argument.

   Because both files have the same family, `unique_names()` leaves the function named `save`. Scoping leaves the action reference unchanged, but expression inference checks global functions before component actions.    **Fix:** Preserve capture protection within families. Determine whether an unrenamed declaration can capture a call using that call’s bindings and file-local declaration visibility; exempt harmless shared bindings rather than every binding in the family. The existing `taken` check still protects top-level declaration uniqueness—the failure is reference resolution.

2. **MAJOR — Deferred method checks apply component actions to unrelated scopes.**


   This reports **`syntax-method-shadowed`** inside `label`, although `App.trim` is outside the pure function’s scope. Moving the action into `App` directly, while retaining `label` in its own imported file, permits the program.

   **Fix:** Record each check’s owning component or top-level scope. Resolve action-dependent checks against that component’s assembled actions, retaining file-local function/shape visibility. Avoid both the filewide early action test and the loader’s per-unit action union.
