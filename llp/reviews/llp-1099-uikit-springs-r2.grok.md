Fix: in §3.1, attribute k 184.95 / 1.773 to UIKit only; state the procedure’s k 171.05 / left limit 1.738; point §8.3 at that sentence.

2. **MATERIAL** — The web band is not achievable, and the frame cap rejects legal springs. D6 (`:383`) samples at max(240 Hz, 16 per damped period), promises 10⁻³ between frames (`:390`), and refuses above 8,192 frames (`:384`). For the measured spring at `ios-27.0.txt:2` (0.1 s, ζ 0.01, v 0, k 5.302·10⁶) the period is 2.729 ms, so the rule is 5,863 Hz (586 frames). Linear interpolation still misses by 0.0188 of the move near t = 0. 240 Hz misses by 1.368, which is the r1 figure the adaptive rate was meant to fix. Error scales as 1/N²; 10⁻³ needs about 70 samples per cycle, not 16. Critical and overdamped springs have no period, so the rate is undefined for the negative-bounce branch D4 exists to copy. Separately, D1 allows d = 60 s (`:165`) and a 60 s critical spring is 14,400 frames at 240 Hz, above 8,192, so the web refuses a spelling iOS and Linux play (`transition.rs:387` is a flat 240 Hz grid today). Fix: write the rate as max(240, ⌈ω_d/2π·N⌉) with N ≥ 70 for underdamped and 240 otherwise; size the cap for every accepted (d, W), and refuse at parse time on every host.

3. **MATERIAL** — A repeated offset is specified only at the animation’s end, so a component snap in the middle of a retarget is a ramp. D5 (`:307`) drops each component, with its snap, at its own end. D6 (`:386`) repeats an offset only at the final end. Web Animations interpolates toward the first keyframe of a repeated offset and jumps to the last only at that offset, which does implement the final step. A retarget re-lowers one summed track (`:378`), and the first component’s snap sits at an interior offset. `motion-glue.js:585` still builds keyframes with no offsets at all (`llp/1007-web-host-v1.spec.md:164`). The §8 retarget fixture is the ζ 0.8 center case, whose snap is ~10⁻³ and can hide the ramp; the icon’s jump is 0.77 of the move. Fix: emit left-limit then post-snap at every component end, and cover an in-band snap in `uikit-retarget`.

4. **MATERIAL** — Layout springs are a second player, and the new frames are in the wrong space for it. `presence-glue.js:97` integrates with `Math.exp` (not pinned libm) and `:237` plays residual translates with `composite: 'add'` (`llp/1063-presence-and-layout-motion.rfc.md:141`). `Running::spring_frames` (`motion/src/transition.rs:391`) emits absolute `to + displacement`. Stage 4 (`:735`) says to delete that integrator and carry engine frames, while D6 (`:378`) forbids `composite: 'add'`. Absolute frames under add double-count; replace frames would override the element’s own transform. Additivity itself was measured for `center` and opacity only (rows R). Fix: keep layout on residual frames with `composite: 'add'`; keep compositor properties on one replace track of the summed absolute value; say so in D6.

5. **MATERIAL** — The band predicate has no margin, and Q1 still accepts O(1) error with no diagnostic. `:536` defines u > 0 and 1 ≤ u/ζ' ≤ 7. It does cover all 100 misses in the 9,474 (`fit.mjs` §8: 1,550 flagged, 27 refused, 0 of those matched UIKit). The ζ 0.05 miss sits on the boundary: u = 0.05, u/ζ = 1, model stuck at W = 5, UIKit W 0.98, curve Δ 1.65. The sweep step is 0.05, so u ∈ (0, 0.05) is unmeasured and unflagged. Inside the predicate, validation still accepts wrong roots: 50 W-sweep misses pass `|g| ≤ 0.1ε`, worst ζ 0.05, u 0.1, model W 1.96 against UIKit 77.7, curve Δ 1.85. `:554` accepts those silently for a dynamic string because `kernel/build.rs:1306` has no warning channel. Q1 (`:742`) refuses non-roots and otherwise warns on literals only. Fix: widen the predicate by one grid step; for dynamic arguments, `BadEasing` on the whole predicate, not only on non-roots.

6. **MATERIAL** — Rows X are not per-component scaling. `:147` says a scalar velocity scales by each axis’s distance, and that a vector velocity “does the same” because rows X show dx and dy as the velocities. `ios-27.0.txt:2625`–`:2628`: both `CGVector(1, 5)` and `(5, 1)` produce two animations whose stiffness is 497.5361505635245, identical to the scalar v = 1 spring (`:1039`), while v0 is 1 on one and 5 on the other. The scalar v = 5 spring is a different stiffness, 458.251 (`:1041`). One scalar cannot emit two normalized velocities, and UIKit did not solve k per axis. Fix: keep the scalar rule for `UIView.animate`’s single velocity; cite rows X as a shared k plus independent `initialVelocity`s, which stay future work.

7. **MATERIAL** — The v = 0 closed form is wrong at ζ' = 1. `:196` says ζ'W = ln(ζ' / (ε√(1−ζ'²))) gives W = 9.233413476 at ζ' = 1, and that implementations use that closed form. The logarithm is singular there: at ζ 0.999 it is already 10.02, at ζ 0.999999 it is 13.47, and the limit diverges. W = 9.233413476451586 is the critical root of (1+W)e^{−W} = ε, which `durationW(1, 0)` does reach. Fix: logarithm only for ζ' < 1; at ζ' = 1, use the critical equation.
