**Blocking**

- [pen.rs:257](tamber/src/import/dtcg/pen.rs:257): **Uncharged memory amplification.** A 64 KiB variable name with 16,384 entries creates 1 GiB of `path` copies while spending under 1 MiB of budget. Charge names, labels and other repeated allocations before copying. [Axis registration](tamber/src/import/dtcg/pen.rs:132) also performs uncharged quadratic scans before checking the context limit.

- [pen.rs:45](tamber/src/import/dtcg/pen.rs:45): **`--x` and `x` become the same source identity.** Collision detection never sees two paths; one overwrites the other, and `$--x` can resolve to `x`’s value. Preserve original identities through resolution; normalize only output names.

- [dtcg.rs:1205](tamber/src/import/dtcg.rs:1205): **DTCG group replacement is wrong for Pencil’s flat names.** With both `a` and `a.b`, the latter removes `a` from the winners, also breaking `$a` aliases. Both are independent Pencil variables.

- [pen.rs:220](tamber/src/import/dtcg/pen.rs:220), [dtcg.rs:973](tamber/src/import/dtcg.rs:973): **Alias types are not checked.** A `color` alias targeting a `string` containing `"#ff0000"` imports successfully. The shared resolver follows the value without checking the target’s declared type.

- [pen.rs:161](tamber/src/import/dtcg/pen.rs:161): **Valid numeric aliases can fail.** If `a = 8` is used as `gap`, it becomes `{value:8,unit:"px"}`. A number `b = "$a"` used as `lineHeight` then fails number conversion. Resolve Pencil scalars before applying each variable’s inferred kind.

- [pen.rs:74](tamber/src/import/dtcg/pen.rs:74): **Kind inference loses property context.** Gradient `size.width` becomes a pixel length despite being normalized; `strokeWidth.top` becomes a number despite being pixels. Track the containing property/type, as distinguished by the [Pencil schema](https://docs.pencil.dev/for-developers/the-pen-format#typescript-schema).

- [pen.rs:235](tamber/src/import/dtcg/pen.rs:235): An undeclared theme condition is discarded, potentially turning that entry into `Scope::Base`. A later invalid entry consequently masks a valid fallback and prevents the token importing. Keep rejected entries outside active layers.
