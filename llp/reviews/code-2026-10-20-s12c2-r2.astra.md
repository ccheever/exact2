C2 still has blockers.

- **BLOCKING — Base overrides are bypassed.** [anatomy.rs:430](contract/lower/src/anatomy.rs:430) expands built-in columns before consulting declared tokens. With `space.md = 0px`, a chain’s `width="space.md"` is checked against the positive built-in values and passes. Conversely, overriding `radius.sm` to a positive length still triggers the terminal’s built-in zero. Expand columns only for **unset** base names.

- **BLOCKING — SVG text escapes transform checking.** [slot.rs:253](contract/lower/src/anatomy/slot.rs:253) classifies tags without SVG context. `text` maps to ordinary `Text` here, although lowering converts it to `SvgText` inside SVG. Thus `svg → text transform="scale(0)" → children` omits the transform from both checking and IR.

- **BLOCKING — Singular matrices can pass through overflow.** [slot.rs:154](contract/lower/src/anatomy/slot.rs:154) multiplies in `f32` before converting to `f64`. For `matrix(1e20 1e20 1e20 1e20 0 0)`, finite coefficients produce `∞ − ∞ = NaN`; the comparison returns false despite zero determinant. Promote operands before multiplication and handle nonfinite results.

- **BLOCKING — Export discovery still misses supported imports.** [library.rs:79](contract/cli/src/sources/library.rs:79) silently excludes package-name self-imports, such as `use Card from "@acme/lib/card.contract"`, and chains beyond its arbitrary depth limit. Separately, the [entry path](contract/cli/src/sources/library.rs:33) is not canonicalized before resolving its imports: `index.contract → src/index.contract` makes `./card.contract` resolve from the wrong directory. These exported components evade D4. Use the existing resolver and cycle detection.

- **SHOULD-FIX — Shorthand precedence remains incorrect.** [slot.rs:312](contract/lower/src/anatomy/slot.rs:312) merges by authored attribute name, before expanding shorthands. A class supplying `font-size=0` still causes refusal when the node supplies `font="-exact-body"`, which overwrites that size during lowering. Compiler checking and IR both retain the overridden row.

- **SHOULD-FIX — The shared checker disagrees with accepted keywords.** [slot.rs:143](contract/lower/src/anatomy/slot.rs:143) rejects valid `font`/`font-size` values such as `-apple-system-body` and `-EXACT-BODY`; the existing parser accepts both. Conversely, [line 127](contract/lower/src/anatomy/slot.rs:127) accepts arbitrary alphabetic `display`/`visibility` values, including unknown names. Other compiler passes catch those, but `denied()` alone does not satisfy its unreadable-value contract.

- **SHOULD-FIX — Newly read export files are absent from build dependencies.** [library.rs:64](contract/cli/src/sources/library.rs:64) reads entries and barrels without recording them in `Sources`. For a subpath-only import, `source_graph` and Cargo’s `rerun_if_changed` omit those files. Changing an entry’s exports can change D4 applicability without rebuilding the app.

- **SHOULD-FIX — The IR dependency finding remains unresolved.** [tamber_params.rs:330](contract/cli/src/tamber_params.rs:330) still emits only raw `(row, value)` pairs, without the reached-token dependencies D4/D5 require. The new `library` flag fixes the scope ambiguity; it does not fix this half of round one’s finding.
