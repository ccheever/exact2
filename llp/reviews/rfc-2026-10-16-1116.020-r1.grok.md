## 2. The §9 questions

**1. `delete=` or leave the long form. Recommendation: `delete=action` as sugar the compiler expands, including `disabled`. Do not add `slot`. Confidence: high.**

`press` and `contextmenu` are events. `delete` is one platform gesture, the destructive full swipe, and LLP 1116.016 D0 is about effects, statements, and hidden cost, which this is not. The expansion has to carry the pattern's locked row (`disabled=it.locked` in `list-detail`) or the pattern cannot use it and the nine lines stay. Other actions already have the long form. `slot` does not exist on any Contract element today (only this RFC). It reads as a second layout language, and the web would have to ignore it or show the button twice. Fix the styling loss and the repeated-id refusal on the existing attributes either way; those show up on replay, and the attribute does not. The pattern's swipe also opens a confirm alert, which grocery was marked down for. The gesture should run the action. A confirm stays an authored dialog when the app wants one.

**2. Xmark for the sheet's dismiss control. Recommendation: it is an override of the word they wrote. Do not ship it that way. Confidence: high.**

Change the patterns to the system items: dismiss is a symbol whose accessible name is Cancel, confirm is the checkmark whose accessible name is Save, the sheet heading has no level (already inline). On iOS the host draws those symbols. On the Mac and the web the accessible name is the button's title, so LLP 1115.002's Cancel and Save stay words. `projectBack` keeps copying an authored title. A symbol-only back control is already the bare chevron; teach that in the pattern that writes "Back".

The modal inline title can ship, as iOS `largeTitleDisplayMode`, with an authored font size still winning (D12.1).

**3. Count large-text findings, exit 0. Recommendation: yes, in the sentence the agent treats as done. Detect authored absolute sizes, not "any text that stayed the same." Confidence: medium on builders acting; high on the detector.**

The seven who ignored the block were told it does not count. "verify: 3 problems (3 at the largest text size; the tests passed)" and start-here's "clean is done" are the lever.
