# Design review: LLP 1108.001 r1, GPT-6 Astra

Reviewer: GPT-6 Astra (codex exec, xhigh, read-only), 2026-10-08, blind, on lane/media-slices-2-3 at 2f93b0ab4. Same brief for both families (the document, its parent and reviews, the code it names; READY or NOT READY, numbered findings).

NOT READY

1. **BLOCKER — §2.3–2.5: retained responses bypass both memory bounds.** Today response strings occupy Hermes’s bounded heap ([js/src/prelude.js:744](/Users/ccheever/projects/exact2-wt-media23/js/src/prelude.js:744), [js/src/lib.rs:103](/Users/ccheever/projects/exact2-wt-media23/js/src/lib.rs:103)). Moving bytes outside it while expressly excluding `Response` bodies from the 256 MiB bound permits unlimited retained responses, each individually below 64 MiB. Charge all retained backing allocations, including responses and decoder/player acquisitions, against an aggregate bound; sharing must count once and remain charged until the last holder releases it.

2. **MAJOR — §1.2/1.8: wasm early fetch bypasses admission.** [host/web/module-glue.js:129](/Users/ccheever/projects/exact2-wt-media23/host/web/module-glue.js:129) invokes `fetchEarly`, which checks network grants but immediately sends GETs without filesystem admission (:54–56). A stubbed-fetch probe confirmed transmission with `fs.write` absent. Exclude save requests from early fetching, or perform complete save admission there first. The header gate and client publication split resolve Astra r4 #7 conceptually; this executor path still violates the promised admission boundary.

3. **MAJOR — §1.4/1.6: abort does not currently stop host work.** [js/src/prelude.js:849](/Users/ccheever/projects/exact2-wt-media23/js/src/prelude.js:849) explicitly leaves the host request running; :867 only rejects the local promise. A save could therefore publish after its caller received an abort. Specify ticket-level cancellation propagation and a publication decision synchronized with cancellation, covering native sync/rename and IndexedDB commit. Test abort and let-go after EOF but before publication, including stalled storage.

4. **MAJOR — §1.5: `:exact-saved` breaks the wasm response carrier.** [host/web/src/host.rs:82](/Users/ccheever/projects/exact2-wt-media23/host/web/src/host.rs:82) splits headers at the first colon, turning `:exact-saved: 123` into an empty header name. The prelude subsequently constructs `Headers` ([js/src/prelude.js:747](/Users/ccheever/projects/exact2-wt-media23/js/src/prelude.js:747)). Specify internal-header framing/parsing through the complete page→runner→realm path, preserving the count for Rust and stripping it before browser `Headers` construction. Add an end-to-end wasm test.

5. **MAJOR — §1.4: unconditional Content-Length comparison confuses encoded and decoded bytes.** Apple exposes original response headers ([vendor/ibex/crates/ibex2/src/transport/darwin_http.mm:403](/Users/ccheever/projects/exact2-wt-media23/vendor/ibex/crates/ibex2/src/transport/darwin_http.mm:403)) separately from URLSession’s delivered data (:171). HTTP content decoding means the saved byte count need not equal the transmitted Content-Length; [Fetch likewise decodes content codings](https://fetch.spec.whatwg.org/#http-network-fetch). Define which bytes are counted, rely on transport framing for truncation, and compare lengths only when they describe the same representation. Test compressed responses.

6. **MAJOR — §2.3: removing response text from JSON breaks stream refusals.** Responses also pass through [js/src/lib.rs:1018](/Users/ccheever/projects/exact2-wt-media23/js/src/lib.rs:1018), into `__exact_message`, which reads `o.response.body` for a non-SSE HTTP response ([js/src/prelude.js:1432](/Users/ccheever/projects/exact2-wt-media23/js/src/prelude.js:1432)). The proposed handoff only names `__exact_fulfill`. Specify host-body ownership and text extraction for both delivery paths, preserving stream error bodies and releasing untaken bodies on every exit.

7. **MAJOR — §2.2 contradicts parent D5/D8’s bridge guarantee.** The wasm realm currently receives both text and base64 ([js/web/src/lib.rs:402](/Users/ccheever/projects/exact2-wt-media23/js/web/src/lib.rs:402)), serialized again at [host/web/module-glue.js:285](/Users/ccheever/projects/exact2-wt-media23/host/web/module-glue.js:285). Constructing a browser Blob afterward still surfaces the entire photo in JavaScript. Keep the browser-held body outside that JSON carrier and transfer a Blob or opaque reference, including worker placement. Specify upload-reference cleanup on rejection, cancellation and realm disposal, not only successful acquisition.

8. **MAJOR — §2.6: Apple video crosses an unspecified optional-module boundary.** [host/apple/Sources/ExactKit/VideoModule.swift:1](/Users/ccheever/projects/exact2-wt-media23/host/apple/Sources/ExactKit/VideoModule.swift:1) deliberately excludes AVKit from ExactKit; its ABI passes strings. Assets are constructed in [host/apple/videoarm/VideoArm.swift:386](/Users/ccheever/projects/exact2-wt-media23/host/apple/videoarm/VideoArm.swift:386), and posters use `Data(contentsOf:)` (:462). Put the resource loader in that arm and specify an app-scoped acquisition/release bridge carrying MIME type and lifetime. Define active-player behavior after revocation and release on source replacement/destruction; preserve the optional loading boundary.

9. **MAJOR — §1.4/1.8: IndexedDB atomicity does not preserve filesystem locking.** The suggested picked-file path, [host/web/storage-fs.js:230](/Users/ccheever/projects/exact2-wt-media23/host/web/storage-fs.js:230), writes directly. Public mutations separately acquire path/ancestor locks (:345–350), protecting live SQLite files across tabs. Require `saveBody` to use that same locking discipline; otherwise it can atomically overwrite a database that owns its file exclusively. Test a locked destination and concurrent parent rename/removal.

10. **MAJOR — §2.4: repeatable UUIDs can collide across engines.** [js/src/lib.rs:311](/Users/ccheever/projects/exact2-wt-media23/js/src/lib.rs:311) restarts the same `"typescript"` random stream for each engine. Two engines with the same app id and drive seed consequently generate identical first URLs in the proposed process-wide store. Specify distinct engine ownership and collision-safe deterministic allocation, including reloads; one engine’s teardown must never revoke another’s URL.
