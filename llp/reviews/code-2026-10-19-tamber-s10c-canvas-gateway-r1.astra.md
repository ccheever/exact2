**RIGHT WITH CHANGES**

1. **BLOCKING — Path normalization bypasses scopes.** [scripts/tamber-canvas.mjs:72](/tmp/rv-s10c-r1-astra/scripts/tamber-canvas.mjs:72): with the included listener’s parsing, `//a//b/__dev/open` becomes `//b/__dev/open`, classified `read`; the dev server parses it again as `/__dev/open`, which requires `write`. The same construction forwards forbidden `/__tamber*` paths. Encoded prefixes such as `/%2eexact/install/` also evade filtering. Validate the raw target, reject ambiguous separators/encodings, and authorize exactly the canonical path forwarded.

2. **BLOCKING — Revocation does not close every in-flight response.** [scripts/tamber-canvas.mjs:168](/tmp/rv-s10c-r1-astra/scripts/tamber-canvas.mjs:168): aborting the controller interrupts fetch, but neither `readBody()` nor the downstream `drained()` wait observes it. Uploads and responses under backpressure can remain open after revoke. Responses also leave `live` before `res.end()` finishes flushing. Bind cancellation directly to request/response destruction and retain tracking until finish/close; cover stalled uploads and downstream writes.

3. **BLOCKING — `/__dev/open` exposes another local credential.** [scripts/tamber-canvas.mjs:70](/tmp/rv-s10c-r1-astra/scripts/tamber-canvas.mjs:70): when a matching native development build exists, the upstream opening page includes its admission token in `href` query strings, generated by [host/apple/build.mjs:294](/tmp/rv-s10c-r1-astra/host/apple/build.mjs:294). The gateway forwards those tokens unchanged. Suppress local admission links for non-local requests, or provide a separate paired-client handoff.

4. **BLOCKING — URL rewriting both misses and corrupts URLs.** [scripts/tamber-canvas.mjs:88](/tmp/rv-s10c-r1-astra/scripts/tamber-canvas.mjs:88): only the configured loop port is covered. Other-port loopback URLs and encoded hosts such as `http://%6cocalhost:9000/` survive. Conversely, the bare-host rule changes unrelated paths such as `https://example.test/localhost:9000.png`. Match canonical URL authorities, handle each serialization’s encoding, and refuse or remove unsupported loopback destinations. Add header, HTML, JSON and SSE cases.

5. **SHOULD-FIX — Entry Origin is optional.** [scripts/tamber-canvas.mjs:205](/tmp/rv-s10c-r1-astra/scripts/tamber-canvas.mjs:205) accepts a grant POST without Origin. Require an explicit canvas or tool Origin, rejecting missing, `null`, and malformed values.

6. **SHOULD-FIX — Read/propose canvases cannot reload after JS rebuilds.** [scripts/tamber-canvas.mjs:254](/tmp/rv-s10c-r1-astra/scripts/tamber-canvas.mjs:254) correctly denies their checkpoint POST, but [host/web-js/dev.mjs:702](/tmp/rv-s10c-r1-astra/host/web-js/dev.mjs:702) then retains the old page. Keep checkpoint write-only and provide a fresh reload when checkpoint permission is unavailable.
