- [pen.rs:465](tamber/src/import/dtcg/pen.rs:465), [dtcg.rs:1443](tamber/src/import/dtcg.rs:1443): **Uncharged quadratic reporting.** A value list containing 100,000 malformed scalar entries creates 100,000 `unused` records. Reporting searches that vector from its beginning for every definition—about five billion comparisons from roughly 200 KiB of input. Index these records and charge the work; currently the watchdog is the backstop.

- [pen.rs:522](tamber/src/import/dtcg/pen.rs:522): **DTCG alias syntax still leaks through objects.** A colour with `value: {"$ref":"#/s"}`, where `s` is a string containing `"#ff0000"`, imports successfully. It bypasses Pencil’s `$name` type check through [DTCG’s object-alias parser](tamber/src/import/dtcg.rs:908). Validate Pencil value shapes before forwarding them.

- [pen.rs:388](tamber/src/import/dtcg/pen.rs:388): Superseded declarations lose entry counts. A variable declared with two entries, then redeclared with one scalar, produces `source=2` instead of `3`. Report every superseded entry.
