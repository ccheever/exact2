1. **[Major] Baking still splits declaration identity for app-local workspace packages.** [js/bake/src/lib.rs:593](js/bake/src/lib.rs:593).  
   Put `ui/index.contract` inside the app, exporting `Card`, and link `node_modules/ui` to `../ui`. Import `Card` both from `"./ui/index.contract"` and `"ui"`. Original compilation deduplicates the canonical file. Baking copies the relative source into `stage/ui/index.contract`, but links the package to the **original** app directory. Staged compilation therefore sees two declarations and reports `contract-use-duplicate`. Linking fixes round-3’s external-package examples but leaves this valid diamond broken.

2. **[Major] Interpolated easing functions no longer fill the easing slot.** [contract/syntax/src/scope.rs:499](contract/syntax/src/scope.rs:499).  
   Give root and library different `keyframes linear`; the library renders ``animation=`steps(${n}, jump-end) linear 1s` `` with `n=3`. The complete `steps(...)` token contains `HOLE`, so short-circuit evaluation skips `slots.name`. The following `linear` incorrectly fills the easing slot and remains unrenamed. At runtime, `steps(...)` supplies easing and `linear` names the **root’s** animation instead of `linear__ui`. Compiler probes confirm both shorthands are accepted.

3. **[Major] Trimming animation tokens leaves incorrect replacement offsets.** [contract/syntax/src/scope.rs:492](contract/syntax/src/scope.rs:492), [scope.rs:528](contract/syntax/src/scope.rs:528).  
   With colliding `keyframes pulse`, let the library use `animation="\tpulse 1s"`. Trimming produces token `pulse` while retaining offset zero. Replacing bytes `0..5` consumes the tab and `puls`, yielding `pulse__uie 1s`. The compiler accepts the original and rejects that result with `lower-animation-name`, confirmed by probes. Leading U+2003 before a two-byte name such as `go` additionally puts the replacement endpoint inside a UTF-8 character, causing a panic.

4. **[Major] An import in another namespace disables root roster isolation.** [contract/cli/src/sources.rs:390](contract/cli/src/sources.rs:390).  
   Root declares `shape length` with `n: number` and imports `Card`. Its library imports a style using `use Pad as length from "./styles.contract"` and renders ``text `${length("hi")}` ``. `captures` treats **any** import named `length` as importing the callable, so the root shape stays unrenamed. The library’s roster call then constructs that inaccessible shape and fails with `type-record-base`. The downstream failure was compiler-probed. The check must distinguish namespaces.

5. **[Major] TypeScript’s wasm/native dev producer never watches Contract packages.** [host/web/dev.mjs:528](host/web/dev.mjs:528).

The fallback compiler-input watcher also filters those paths at [dev.mjs:822](host/web/dev.mjs:822). No new generation is produced. Adding package watching to the JS target and Rust `Session` left this separate producer uncovered.

6. **[Minor] The `t` intrinsic exception still confuses states with action bindings.** [contract/syntax/src/scope.rs:627](contract/syntax/src/scope.rs:627).

The type checker only lets actions or props suppress translation ([strings.rs:25](contract/types/src/strings.rs:25)); a state does not. Adding that unrelated state changes the call’s meaning.
