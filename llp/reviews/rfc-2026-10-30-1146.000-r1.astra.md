**4. Oversights, ordered by severity**

1. **High — D1 needs a different observation boundary, not merely consolidated teardown diagnostics.**  
   `fail()` already gathers resource failures, refused replies, held requests, pending requests, and clock hints; failed tests also report console output. Verify already retains screenshots and resource information. [agent-test:706](/Users/ccheever/projects/exact2/scripts/agent-test.mjs:706), [agent-test:969](/Users/ccheever/projects/exact2/scripts/agent-test.mjs:969), [verify:777](/Users/ccheever/projects/exact2/scripts/verify.mjs:777)

   The missing piece is preservation **when the assertion fails**. A hook after `runStep()` is potentially too late: it calls `mutationClock.advance()`, which can advance time. Ordinary screenshots also change what is observed: Chrome holds transitions near their ends; iOS settles images, collection work, and native motion. Passing the existing film flag does not remove all those effects. [agent-test:941](/Users/ccheever/projects/exact2/scripts/agent-test.mjs:941), [agent-test:1035](/Users/ccheever/projects/exact2/scripts/agent-test.mjs:1035), [web agent:287](/Users/ccheever/projects/exact2/host/web-js/agent.js:287), [AgentIOS:1213](/Users/ccheever/projects/exact2/host/apple/Sources/ExactKit/IOS/AgentIOS.swift:1213)

   **Resolution:** preserve the assertion’s actual reply before further reads or automatic clock advancement; identify a capture path that does not settle or finish motion. Retain later reads as later observations. Cover failure branches that bypass `fail()`, and continue the remaining tests.

2. **High — references do not yet identify durable artifacts or the build actually observed.**  
   Verify deletes previous host screenshots and recreates deterministic filenames. Referencing those paths would lose evidence or point at another run’s image. [verify:439](/Users/ccheever/projects/exact2/scripts/verify.mjs:439), [verify:1331](/Users/ccheever/projects/exact2/scripts/verify.mjs:1331)

   `recordRun()` computes the build digest when called, at run completion. Meanwhile the web driver can keep running a leased older generation after another build replaces the current one.
