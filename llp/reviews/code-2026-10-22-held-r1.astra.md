- **BLOCKER — Rust module requests lose `held`.** [logic/abi/src/lib.rs:413](/tmp/rv-held/logic/abi/src/lib.rs:413): encoding omits the flag and decoding hardcodes `false`. `Request::held()` therefore becomes an ordinary waited request across the Rust module ABI. - **BLOCKER — Superseded web JS tickets remain held.** [held.js:9](/tmp/rv-held/host/web-js/held.js:9): counting checks `waiting` and `closed`, but not ticket ownership. Plain promise tickets never enter `Open`, so `closeLetGo()` does not retire them. Reproduced: replacing ticket 1 with ticket 2 reports both; when ticket 1’s fetch ends, its obsolete continuation increments `inflight` again.

- **BLOCKER — One held fetch hides ordinary work in the same answer.** [held.js:9](/tmp/rv-held/host/web-js/held.js:9): `call.held > 0` excludes the entire answer. Reproduced with `Promise.all([fetch(heldURL, {exactHeld:true}), fetch(ordinaryURL)])`: both requests remain outstanding, but `inflight` is zero. This breaks F10 and also hides post-reply work while another held fetch remains outstanding.

- **BLOCKER — Held fetches inside `.then()` are still waited on.** [ts-fetch.js:21](/tmp/rv-held/host/web-js/ts-fetch.js:21): explicit promise callbacks do not restore `answering.call`; the async helper covers transformed `await` only. Reproduced with `return Promise.resolve().then(() => fetch(url, {exactHeld:true}))`: `inflight: 1`, no held entry.

- **SHOULD — Wasm cleanup can erase a new incarnation’s held entry.** [glue.js:757](/tmp/rv-held/host/web/glue.js:757): cleanup unconditionally deletes by ticket number. Boot resets ticket numbering and clears/repopulates the map; an old request’s subsequent `finally` can delete the new request with that number. Reproduced the collision. Guard cleanup by incarnation or entry identity.

- **SHOULD — Held mutations are misnamed and absent from inspection.** [rt.js:601](/tmp/rv-held/host/web-js/rt.js:601) uses the source name instead of the mutation target. A mutation `result` calling `poll` reports `heldTargets: ["poll"]`. [agent.js:491](/tmp/rv-held/host/web-js/agent.js:491) lists only resources, so the held mutation is missing from `state.pending` and consequently verify’s held summary.
