3. **[should-fix] Read a theme line the way `.tamber` reads it** — `scripts/scale-check.mjs:143`

`overridesOf` keeps a line only when it is indented `space.<letters> = <n>px` or the same for `radius`, with the `when` on the very next line. This fixture's `space.md = 12px` matches, which is why the reported 12s are real. The grammar (`token = NAME [ ":" kind ] "=" value { meta }`, `//` comments stripped, blank lines skipped) also accepts forms this function drops with no error, and then the box is held to the base column:

- `space.md: length = 12px` (the corpus writes lengths this way)
- `space.md = 12px // ruling 4`
- `space.md = 12px scheme=fixed`
- a blank line before `when` (the lexer skips it, so the `when` still belongs to the token; the checker treats the token as one length)

A host that honors that line draws 12 while the checker expects the column (16 neutral, 10 on the Mac): a false failure. A host that also ignores the line passes. `0.75rem`, `12PX`, a bare `0`, and `gap` do throw once the line matches the simple pattern, so those fail closed. The new test only covers the simple pattern, an immediate `when`, and a non-px word.
