   Input: root imports only `Kit` from `"kit"` but renders both `Kit()` and an unimported `Badge()`. Kit imports `Badge` from its nested `node_modules/ui` version 2, rendering `"two"`. 2. **[Major] Quoted computed animation names cause a false ambiguity error.** [scope.rs:954](contract/syntax/src/scope.rs:954).  
   Input: root and `ui.contract` both declare `keyframes linear`; root imports and renders the library’s `Card`. The library also declares `keyframes spin`, and Card contains:
   ```contract
   state name = "spin"
   view
     view animation=`'${name}' linear 1s`
   ```
   The reader treats the quoted interpolation as an unknown slot, including potentially easing. It consequently classifies `linear` as both easing and a possible name, then rejects the renamed library declaration with `contract-animation-ambiguous`. The actual string, `'spin' linear 1s`, unambiguously names `spin`; the current compiler accepts it and the dynamic template without the collision. Quoted interpolation must retain its name role.
