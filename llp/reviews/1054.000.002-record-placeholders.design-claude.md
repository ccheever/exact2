# Design: LLP 1054.000.002, record placeholders (claude)

- **Family:** Anthropic, Claude (Opus 5.5), the session that wrote LLP 1054.000.002 (so the same session as the synthesis; not independent of it).
- **Method:** written before reading the Astra or Grok designs, from the RFC's constraints and the code as of `70c32393`.
- **Redacted:** no.

## 1. Summary

`else empty` gives a resource its shape's zero value as its placeholder.
`else { field: value, … }` gives the zero value with named fields replaced
by constants, and it nests. Both compile to a constant in the plan: no
source, no bake question, no `#else` row. The runner shows the constant
where it shows a placeholder row's value today, so it is pending. A record
resource without `else` is still refused, and the message now suggests
`else empty`. `else source(args)` stays for the rare placeholder that is
computed.

## 2. Surface

```
resource session = session(clock, time.utcOffset) as shape Session else empty
resource notes = notifications(noteMore, noteFresh, clock) as shape Notes else empty
resource me = currentUser() as shape User else { avatar: "https://api.realworld.show/images/smiley-cyrus.jpeg" }
resource post = article(slug, me.username) as shape Article else empty
resource person = profile(listName, me.username) as shape Profile else { image: AVATAR }
```

The grammar after `as shape T`: `else` then one of `empty`, a `{ … }` of
`name: constant` pairs (a nested record's value may itself be `{ … }`), or
a source call as today. A constant is a literal, a `-` literal, a template
literal with no holes, or a name bound to a constant: a top-level `let`, if
Contract has one, otherwise literals only.

## 3. Semantics

- **Zero values:** `number` 0, `string` "", `bool` false, `unit` (),
  `list<T>` [], `option<T>` none. A record's zero is each field's zero, in
  declaration order. Shapes may only recurse through a list or an option
  (the shape-cycle check), so this terminates.
- **Overrides** replace the named fields of the zero value. Nested `{ … }`
  overrides a nested record's fields the same way. A field of list type
  cannot be given (there are no list literals), so it stays `[]`. An
  option field takes `none` or a constant, which becomes `some(constant)`.
- **Argument-dependent placeholders** (`emptyFeed(id)`) keep `else
  source(args)`. Bluesky's is not a resource placeholder at all; RealWorld
  has none.
- **Pending and `state`:** exactly as a placeholder row's value today. The
  runner shows it only when a source answers later with nothing kept for
  the arguments, or has not loaded (`awaiting`); `pending(r)` is true.
  `state` shows the value.
- **Boot:** the constant shows. **Awaiting a module:** the constant shows,
  and `data_ready` asks. **Failed request:** the source's `parse` shapes a
  failure, as today; a refused parse keeps the previous value. **Carried
  reload:** a kept or carried answer wins; the placeholder only fills a gap.
- **Never an answer:** it is not compiled as `initial` and is never
  `keep_answer`ed. It is written only through the placeholder path.

## 4. Implementation

- **syntax:** `Placeholder` becomes an enum: `Source { source, args }`,
  `Empty`, `Fields(Vec<(String, PlaceholderValue, Span)>)`. `else` parses
  `empty` (a contextual word), `{`, or a call.
- **types:** check each field name exists (`type-placeholder-field`,
  "`Profile` has no field `imag`"), each value's type matches
  (`type-placeholder-value`), each value is a constant
  (`type-placeholder-constant`, "a placeholder field is a constant: a
  literal"), and there are no duplicates.
- **lower:** build the zero `Value` from the resolved type, apply
  overrides, then encode.
- **plan:** `resources` gains `placeholder_value: bytes`: a value, empty for
  none. `placeholder` (the `#else` row) stays for the source form.
- **bake:** nothing; the constant is already there.
- **runner:** `placeholder()` checks `placeholder_value` after
  `placeholder`, then falls back to the list and option empties. That's a
  few lines.
- **Diagnostics for a missing one:** the boot refusal's message says
  `declare a placeholder: … else empty (or else { field: value })`. With
  stage labels, LLP 1048.003 D6's compile error uses the same words.
- **Existing `else source()`:** unchanged. The Bluesky and RealWorld
  placeholders migrate to `empty` or `{ … }`, and their `emptyX` sources
  are deleted.

## 5. Alternatives rejected

- **Implicit zero for every record:** it removes one word but hides the
  choice, and it turns a helpful refusal into a silent default (constraint
  5).
- **Field defaults on `shape`** (`image: string = AVATAR`): the defaults
  would leak into every use of the shape, including answers, where a
  missing field is a bug, not a default.
- **General record literals in Contract expressions:** a larger language
  change (derives building records, equality, spreads) that the finding
  does not need.

## 6. Risks and open questions

- A zero record can read as real data (`followers: 0`). The views in both
  apps already gate on `ready`/`found` or `pending(r)`. The RFC should say
  that a view that shows a record while pending must gate.
- Named constants: without a top-level constant form, the RealWorld avatar
  URL is written inline.
