Two files that both declare `component Card` with `fill`, and a folded `background-color="param.fill"` plus `:disabled background-color="#999"`, get “Edit this template” for the text `param.fill`. A unique name still matches, and a different component name (`Button.fill` against `Card.fill`) does not match the other component. 2. **SHOULD-FIX.** A folded base written as a role spelling is offered as a literal. `token_names` (`runner/src/runner/mode.rs:247-251`) stores the canonical token (`secondary-label`) for `-exact-secondary-label` or any case of that role. `writtenToken` (`scripts/tamber-inspect.mjs:466`) keeps a token only on `names.includes(text)` and otherwise clears `names`. `editable` (`scripts/tamber-inspect.mjs:354-357`) would accept `text.replace(/^-exact-/, '') === names[0]`, but that list is already empty. `background-color="-exact-secondary-label"` with `:disabled background-color="#999999"` gets a template rung for the string.
