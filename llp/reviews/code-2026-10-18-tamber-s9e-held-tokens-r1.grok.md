2. **SHOULD-FIX** — The JS target marks a held answer `provenance: "incomplete"` for values `modes.js` was never supposed to name. `host/web/input-glue.js:403-406` sets `incomplete` whenever `modes.token` returns nothing for a value matching `var(` or `light-dark(`. `host/web-js/modes.js:300-302` only names `var(--x-…)`, and returns `undefined` when none of those map. A literal `light-dark(#fff,#000)`, or a `var(--exact-…)` / `var(--something)` custom property, therefore flags the whole answer. A mix is the other way: `var(--x-ink)` plus an unmapped `var(--x-…)` returns only the known name and leaves `incomplete` false. Fix: collect every `var(--x-[\w-]+)` in the value. If there are none, keep `computed` and do not set provenance. If any reference is missing from `Names` or from the returned `token.names`, set `provenance: "incomplete"`. Attach `token` only when `modes.token` returns one.
