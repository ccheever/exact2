1. **SHOULD-FIX — a classic scrollbar is subtracted twice.** `host/web/geometry-glue.js:142`. Chrome's `getComputedStyle` width/height for `box-sizing: content-box` (the textarea default) is the content box after a layout scrollbar. The twin copies that length and the same `overflow`, then lays out its own scrollbar, so the content box is one scrollbar narrower (about 15px on Windows, and on macOS when scrollbars are set to always show). An empty line whose text wraps, or a centered or end-aligned empty line, is then painted in the wrong place. Overlay scrollbars take no space, which is why the new test can pass. `border-box` round-trips, because that used width is the border box.

2. **SHOULD-FIX — a `position: fixed` field's empty caret is dropped.** `host/web/geometry-glue.js:138`. The probe returns null when the textarea's own computed position is `fixed`, and `range` then answers unavailable. The fit just below already solves a different containing block (it is what the transformed-ancestor case uses). A fixed composer with an empty value is a normal place for `rangeFrame("composer", caret, caret)`.
