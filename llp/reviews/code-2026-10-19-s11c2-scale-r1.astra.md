2. **Should-fix — the bound swap is not reliably verified.** [expect.json](/tmp/rv-s11c2-1/host/web-js/conformance/scale/expect.json:15) expects only the initial `radius.md`; [drive()](/tmp/rv-s11c2-1/scripts/scale-check.mjs:202) never taps. 3. **Should-fix — `host` is incorrectly mapped to terminal.** The new [column map](/tmp/rv-s11c2-1/scripts/scale-check.mjs:107) and test assume `host` means terminal. [agent.mjs](/tmp/rv-s11c2-1/scripts/agent.mjs:527) actually launches the macOS sample embedding host for that name. 4. **Should-fix — gaps and `space.header` have no absolute expectations.** [expect.json](/tmp/rv-s11c2-1/host/web-js/conformance/scale/expect.json:3) checks padding and corners only. Named designs therefore produce incorrect expectations; another Contract entry can pick up overrides the compiler never loaded. Match compiler discovery.
