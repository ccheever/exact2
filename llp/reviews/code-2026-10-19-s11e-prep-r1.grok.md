**6. `live` does not check "no rebuild", and the drive can flake.** `stage11-gate.mjs:148-151` passes when paddings are 20, then 28, then 16. It never reads the dev log. The agent's clocks are not gated on the edit reply. `--port` is `20000 + (pid % 20000)` (`104`) and a taken named port exits (`host/web/dev.mjs:49-53`). Chrome is `detached: true` and the agent has no `SIGTERM` handler (`scripts/agent.mjs:130`, `close` only from `main`'s `finally` at `1493`), so a kill of a still-running agent skips `close()` and leaves the browser. Read stdout with one readline loop and do not take the next layout until the edit reply is in. Kill process groups and await exit. Give the drive a deadline. `--reset-storage`. On failure, let the agent run `close()`, or kill its group only after that.
