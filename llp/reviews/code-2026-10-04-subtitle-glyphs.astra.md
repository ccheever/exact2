1. **Should-fix — The glyph recognizer accepts controls as subtitle containers.** [NavigationTitleIOS.swift:40](/tmp/x12-rg/host/apple/Sources/ExactKit/IOS/NavigationTitleIOS.swift:40) checks only that the container isn’t text and its children are symbols/text. Ordinary sibling buttons are generally excluded by `apart`, but a pressable heading group bypasses that exclusion. A nested symbol-and-text button can consequently become both a bar item and subtitle content; tapping its subtitle representation invokes the outer title action. Decorated badge containers also qualify indiscriminately. **Fix:** require a passive container and passive children, skip `apart` subtrees during traversal, and explicitly define which badge shapes qualify. Add negative recognition tests.

2. **Should-fix — One empty symbol or text discards the otherwise valid line.** [NavigationTitleIOS.swift:44](/tmp/x12-rg/host/apple/Sources/ExactKit/IOS/NavigationTitleIOS.swift:44) rejects the whole candidate when any image has an empty `symbolName`, or any text is empty. For `[empty symbol, “Muted”, timer, “1w”]`, traversal falls back to just “Muted”, losing the valid timer and duration. Empty `symbol:sf/` is explicitly supported by the repository. Conversely, an unknown **nonempty** name qualifies and is silently skipped during rendering. **Fix:** distinguish symbol sources from raster images independently of name resolution; tolerate blank symbols/text while retaining the other pieces. Test a symbol changing between valid, empty, and unavailable names with unchanged text.

3. **Should-fix — Flattening loses the authored direction and text boundaries.** [NavigationTitleIOS.swift:144](/tmp/x12-rg/host/apple/Sources/ExactKit/IOS/NavigationTitleIOS.swift:144) produces one paragraph without recording the row’s `direction`. An authored RTL row containing English status labels therefore becomes an LTR textual sequence. Mixed Arabic/Latin labels can also associate neutral attachment characters with neighboring runs under the [Unicode bidi algorithm](https://www.unicode.org/reports/tr9/). **Fix:** retain resolved direction, set paragraph direction, and isolate constituent text runs so their ordering matches the authored row. Cover explicit RTL with Latin labels and mixed-direction text.

4. **Should-fix — The accessible value cannot preserve meaning supplied by symbols or labels.** [NavigationTitleIOS.swift:57](/tmp/x12-rg/host/apple/Sources/ExactKit/IOS/NavigationTitleIOS.swift:57) excludes every symbol and uses raw text, ignoring authored accessibility labels. “Muted” and “Verified” make their icons redundant, so those icons need no separate announcement. The timer’s meaning, however, disappears into an unexplained “1w”; a meaningful symbol without accompanying text disappears entirely. **Fix:** preserve an authored accessible description for the line, falling back to accessible text names. Give the fixture a spoken description such as “Muted; disappearing messages after one week” without duplicating decorative icon names.

Its title already has an avatar and tap, so it never exercises the new glyph-only reason for `drawn`. **Fix:** add an unpressable, avatar-free title; a glyph-only mutation; the recognition cases above; and appearance/content-size transitions. Make the return-state assertion exact instead of accepting either “Online” or hidden.
