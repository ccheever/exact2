1. **High — Deleting the design file bypasses validation.** [scripts/tamber-inspect.mjs:53](/tmp/rv-dt-t2b5-r3/scripts/tamber-inspect.mjs:53) treats a missing design path as success. The caller recomputes `designPath(appDir)`, which returns null when the file disappears. Delete `app.tamber` while the page retains its last good plan: unchanged Contract files pass, and own token rows remain editable. **Fix:** retain the build’s configured design identity and treat a missing file as a read-only reason.

2. **High — A restored snapshot can be certified against unrelated disk bytes.** [host/web/dev.mjs:273](/tmp/rv-dt-t2b5-r3/host/web/dev.mjs:273) hashes the design file when publishing, rather than retaining the bytes actually compiled. After live design B, start a scrub, save invalid C, then cancel. Restoration publishes committed B but records C’s hash; `designMoved()` consequently accepts B against invalid C. **Fix:** carry source digests with accepted compiler snapshots and preserve them through restoration; track scrub previews separately.

3. **Medium — Successful live edits indefinitely disable explicit outlines.** [scripts/tamber-server.mjs:541](/tmp/rv-dt-t2b5-r3/scripts/tamber-server.mjs:541) checks every source against the generation’s original map, including the design. A value-only edit updates the running design without replacing that generation/map, so subsequent outlines return 409 even after every build applies the edit. `at: []` cannot clear existing marks either. **Fix:** validate span-bearing sources separately from the accepted live design snapshot, and allow clearing without a fresh map.

4. **Medium — An older `uses` result can outline the wrong node after reload.** [scripts/tamber-server.mjs:543](/tmp/rv-dt-t2b5-r3/scripts/tamber-server.mjs:543) resolves unversioned file/line/column locations against the current map. Obtain uses under A, insert a line and let B reload, then submit A’s locations: `staleMap(B)` passes, but the old location may now identify another node. **Fix:** include the source digest with each location and reject mismatches. A plan digest alone cannot detect formatting-only movement.

5. **Medium — An ignored outline still replaces its recorded owner.** [scripts/tamber-builds.mjs:332](/tmp/rv-dt-t2b5-r3/scripts/tamber-builds.mjs:332) assigns ownership on every recipient, although pages reject frames for other plans. While C owns inspect, let A outline a page running P, then let B broadcast Q’s outline. The P page retains A’s boxes but records B as owner: A’s disconnect leaves them, and B’s disconnect clears them. **Fix:** change ownership only for recipients whose accepted plan matches the command, or acknowledge application before transferring ownership.

6. **Medium — Outline geometry becomes stale after a font-size pin.** [host/web/dev.js:614](/tmp/rv-dt-t2b5-r3/host/web/dev.js:614) updates boxes on outline, scroll and window resize, but not after layout-changing commits. Outline a `rem`-sized view, then pin only `rootFontSize`: the view changes dimensions without a window resize, leaving the old fixed rectangle visible. **Fix:** reposition or invalidate marks after layout-affecting commits and pins, and cover this sequence in the browser test.

7. **Medium — The required per-build map resolution remains incomplete.** [host/web/dev.mjs:362](/tmp/rv-dt-t2b5-r3/host/web/dev.mjs:362) exposes only the current map or one disk fallback. A page retaining P after Q publishes loses its source join and ignores Q’s outlines; an initial baked plan differing from the resident compiler’s plan also lacks a join. This is the limitation acknowledged in the dispositions, but D4/D5 still require each build’s own sites. **Fix:** retain verified generation/plan/map associations, including the initial bake, and resolve each recipient separately on the server.

8. **Low — The browser assertion can run before its outline arrives.** [scripts/tamber-server.test.mjs:495](/tmp/rv-dt-t2b5-r3/scripts/tamber-server.test.mjs:495) waits only for nonzero marks, which the earlier selection already guarantees. If the outline command arrives after its HTTP response, the test compares the previous selection’s boxes and can fail spuriously. **Fix:** wait for the requested targets and rectangle equality. Use independently identified repeated instances to establish “every copy,” rather than deriving all expected copies from the same `sites` operation under test.
