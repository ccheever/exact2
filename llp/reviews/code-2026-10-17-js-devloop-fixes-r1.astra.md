Read-only review. Line numbers refer to HEAD. I checked the predicates and scheduling with in-memory stubs; the integration test was not run because it writes files.

1. **P0 — Commit 1 skips backend removal and some creations.** [host/web-js/dev.mjs:452](/tmp/rv-devloop/host/web-js/dev.mjs:452). Rename `.exact` containing `backend-origin` away: a bare `.exact` event now hits the catch and returns, leaving the old backend baked into the app. Moving a directory into place with an older `backend-origin` also returns. Direct `.exact/backend-origin` deletion events still work. **Fix:** compare the backend file’s contents and existence against the last build, including transitions to and from absence.

2. **P0 — Commit 2 mistakes genuine deleted assets for temporaries.** [host/web-js/dev.mjs:308](/tmp/rv-devloop/host/web-js/dev.mjs:308). Set `"tamber": "assets/app.tamber"`, edit its colour, and delete `assets/app.tamber.png` in the same burst. The substring test makes this design-only. The verification build’s `keep` predicate compares design and module changes, so it can discard the new build and continue serving the deleted image. **Fix:** preserve deletions of previously known inputs; restrict temporary recognition to specific editor filename patterns.

3. **P1 — Commit 2’s test permanently deletes existing fixture state.** [scripts/tamber-server.test.mjs:693](/tmp/rv-devloop/scripts/tamber-server.test.mjs:693). A pre-existing `apps/theme-fixture/.exact/backend-origin` is recursively deleted and never restored—even if startup fails. The `finally` restores `app.tamber` on ordinary success or assertion failure, but restores none of `.exact`. **Fix:** use an isolated fixture, or preserve and restore the complete directory inside protected setup/teardown.

4. **P1 — Commit 3’s cleaner can outlive shutdown.** [host/web-js/dev.mjs:226](/tmp/rv-devloop/host/web-js/dev.mjs:226). After the linker failure starts `cargo clean`, send SIGTERM to the dev-loop PID. `tool.child` is already null, and shutdown owns no reference to the cleaner; it can continue deleting shared `host-dev` artifacts after the loop exits. An already-failed build’s queued exit callback can also start cleaning after `stopping` becomes true. **Fix:** guard cleanup initiation with `stopping`, track the cleaner, and terminate and await it during shutdown. The retry itself is bounded, and its completion callback correctly suppresses rebuilding after stop.

5. **P1 — Commit 3 parses unrelated archives and invents package names.** [host/web-js/dev.mjs:200](/tmp/rv-devloop/host/web-js/dev.mjs:200). A diagnostic containing `Undefined symbols`, `.llvm.123`, and linker arguments `libserde_json-abc123.rlib`, `libstd-abcdef.rlib`, and `libexact_kernel-aabbcc.rlib` produces `serde-json`, `std`, and `exact-kernel`. The first two are invalid package selections here; cleanup fails silently, consumes the recovery allowance, and retries unchanged state. **Fix:** extract archives from the relevant undefined-symbol diagnostic, resolve library targets to actual Cargo package IDs, and check cleanup success.

6. **P1 — Commit 2 still counts a late temporary.** [host/web-js/dev.mjs:307](/tmp/rv-devloop/host/web-js/dev.mjs:307). Deliver the `app.tamber` event, let its timer consume `edited`, then deliver the already-gone `app.tamber.tmp` event. Its new burst contains no design, so `temporary()` cannot recognize it. I reproduced a value batch followed by an unnecessary plan reload. **Fix:** retain save association across queued and in-flight work, while protecting known real inputs.

7. **P1 — The burst timer can schedule an empty rebuild; this predates these commits.** [host/web-js/dev.mjs:441](/tmp/rv-devloop/host/web-js/dev.mjs:441), [host/web-js/dev.mjs:472](/tmp/rv-devloop/host/web-js/dev.mjs:472). With `again` set, another event arms a timer. The current build finishes first and immediately consumes those edits through `rebuild()`. The still-armed timer subsequently requests another rebuild with no edits, producing a plan reload. **Fix:** cancel the pending timer when consuming its edits and return when no edits remain. This is not an introduced regression.

8. **P1 — Commit 2’s test can pass before the unwanted rebuild.** [scripts/tamber-server.test.mjs:699](/tmp/rv-devloop/scripts/tamber-server.test.mjs:699). Five seconds does not establish that the design server acquired its lock or that watcher work finished. After saving, the test accepts the first batch message, which precedes verification; the later reload reproduced above escapes the assertion. **Fix:** await server readiness and completion of watcher/build work, then assert that the entire save produced no plan reload.
