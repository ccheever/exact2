2. **blocker — One client can create an unlimited import backlog.** [scripts/tamber-isolate.mjs:36](/tmp/rv-e23-6/scripts/tamber-isolate.mjs:36).

   Every call retains its request behind the module-global promise. There is no queued-byte limit, client quota, waiting deadline, or cancellation. The 10-second timer starts only when the job begins. Enqueuing \(N\) expensive imports delays another client by roughly \(10N\) seconds and retains all pending bodies. The remote listener’s 64-connection limit does not bound this: disconnecting frees the socket while its dispatched import remains queued.

   **Fix:** bound outstanding imports per authenticated client and globally, including retained bytes and waiting time. Reject overload promptly and cancel queued work when its request or server ends.

3. **should-fix — RSS monitoring fails open and leaves probes unmanaged.** [scripts/tamber-isolate.mjs:58](/tmp/rv-e23-6/scripts/tamber-isolate.mjs:58).

   Failed `ps` calls are ignored; slow calls overlap every 50 ms without a timeout. Outstanding probes are not cancelled when the planner finishes, and late callbacks can still call `stop`. Only the leader’s RSS is measured, so compiler or runner descendants are excluded.

   **Fix:** allow one bounded probe at a time, terminate outstanding probes during cleanup, ignore callbacks after settlement, and stop the import when monitoring becomes unavailable. Account for descendants or require a prepared executable.

4. **should-fix — The design read bypasses both the watchdog and the serve’s file checks.** [scripts/tamber-isolate.mjs:44](/tmp/rv-e23-6/scripts/tamber-isolate.mjs:44).

   `readFileSync` runs in the shared parent before either timer exists, follows symlinks, has no size bound, and treats every read error as absence. A design replaced by a FIFO can block the parent indefinitely; a large file consumes parent memory. A manifest or symlink change can also redirect this read outside the app. These require filesystem changes—the HTTP client cannot directly supply the design path.

   **Fix:** use the serve’s validated design identity, require a regular file within the app, and perform a bounded asynchronous read. Preserve the path together with its digest. Treat only genuine absence as absence, and enforce an explicit absence precondition instead of dropping the digest guard.
