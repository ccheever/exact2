## MAJOR

**1. D6 — `style <Name>` is not a package-wide address.** Styles are unique in one file and invisible outside it: `lower-style-duplicate` fires inside that file's map (`contract/lower/src/lib.rs:312-318`), and `class=Name` looks up "in this file" (`contract/lower/src/class.rs:22-36`). Two components can both declare `style Card`. The origin label is only `class:<Name>` (`contract/lower/src/sites.rs:75-80`), so "every node whose row's origin is that style" (`llp/1122-design-tool.rfc.md:400-402`) also outlines the other file. The attribute span already specified two paragraphs earlier is the right address: for a class row it is the attribute on `style <Name>` in the node's own file (the use-site element span stays the wrong patch target). Blast radius is nodes in that file whose origin is that style.

**2. D3/D5 — capture identity is still not the selection check, and the screenshot reply's tags are from before the pixels.** Astra's round-2 fix was to bind both the capture pair and the point-pick to carrier generation, incarnation, epoch, clock, and applied design digest. The pair lists those fields (`llp/1122-design-tool.rfc.md:201-204`). The click refuses only when the epoch moved (`:270-273`). A JS page restarts at incarnation 1 with a fresh epoch (`host/web-js/agent.js:90-92`), so generation 1 and generation 2 can both be epoch 0; the click then lands on the new page using the old picture. Separately, the web carrier reads `picture`/`tags` before the image wait and the PNG (`scripts/agent.mjs:493-509`), and `tagged` keeps those tags because `epoch` is already set (`:1364-1365`). Two replies can agree while the pixels include a later layout. **Fix:** stamp the server's carrier generation into the request, echo it, and drop any reply from the previous socket. Sample epoch, clock, and applied design digest after the image wait, in the same barrier as the pixels and `layout`. Refuse a click unless all five fields still match that capture.

**3. D5 / §3 — the fail-closed rule for boundary rows cannot be evaluated with the sources marked built.** `layout` reports `dynamic`, `authored`, `inherited`, or `initial` (`runner/src/agent.rs:518-528`). A mode boundary writes inherited colour tokens onto the boundary node as its own rows (`llp/1121-tamber.rfc.md:579-581`), so they arrive as `authored` with a token beside them and no attribute in the map. §3 calls "`layout <id>` with sources" built (`llp/1122-design-tool.rfc.md:577`). Preview screens are boundaries (D4), so the node the tool is built to click is the one this mislabels, and the token rung comes back. **Fix:** the kernel flags an implied boundary row and `layout` reports that source; list it as proposed. Until then, an `authored` row the map does not name is read-only, token shown as a link.

**4. D9 — the commit guard still takes unrelated work, and it contradicts the T1 gate.** The gate says commit refuses a file that was dirty before the session (`llp/1122-design-tool.rfc.md:594`). The guard checks only that the working tree equals the server's last write and that HEAD equals the session start (`:472-475`). A file already dirty at start is what the server first read, so the last write includes those edits and the commit sweeps them in. A same-file index entry that differs from HEAD is also unseen: the temporary index commits HEAD plus the working tree and leaves the real index stale against the new HEAD. **Fix:** at session start record HEAD, the index blob, and the working-tree digest. Refuse if the working tree or the index differed from HEAD then, if HEAD has moved, or if the working tree now differs from the last server write. Keep the temporary index for other paths.

**5. D6 — a scrub session is a drive, and no role owns it.** Observers lost `prefer` and `clock settle` in this round. A scrub then pushes live-table batches to every tile for the whole gesture (`llp/1122-design-tool.rfc.md:353-358`) without a `write` requirement. A paired `propose` client is allowed to `propose` and is denied the drive group (`:525-529`); nothing stops it using this other write to the running app. **Fix:** opening or updating a scrub requires `write`. `propose` may answer `live` or `rebuild` and must not push a batch. One scrub at a time; a second is refused.

## MINOR

**6. D8 — a hold re-applied to "the same source node" is every expansion of that span.** D5's source is the span, shared by every `each` copy (`llp/1122-design-tool.rfc.md:275-279`). View ids do not survive the reload. **Fix:** key the hold by site plus `layout`'s `instance` path, and drop it when that mount is gone. Name the state field so it cannot be read as `tap`'s existing contact phase `hold` (`llp/foundation/1012-agent-api-v1.spec.md:226`).

**7. D5 — the web hit-test is the wasm ABI only.** `exact_geometry.point` is `elementsFromPoint`, then `closest("[data-view]")`, returned as `id + 1` (`host/web/glue.js:1435`, `host/web/geometry-glue.js:100-102`). JS-target elements carry no `data-view` (`host/web-js/agent.js:181`). T2b's "row for row" gate has no hit-test to implement. **Fix:** T2b hit-tests with `elementsFromPoint` and the JS runtime's own view id. `id + 1` stays the wasm encoding; `0` is a miss.

**8. D6 / §4 — two gates describe an edit the ladder does not make.** T2's gate says a dial drag updates every tile with no reload (`llp/1122-design-tool.rfc.md:605`). A dial folded into a `duration` or `easing` token rebuilds (D6, `llp/1121-tamber.rfc.md:897-903`). Token and dial are never the default (`llp/1122-design-tool.rfc.md:345-348`), and the param, template, and style rungs arrive at T3 and T5, so an inspect click in T2 has no legal default. The scrub batch also has to be the branch edit, re-resolved per tile; one computed colour pushed at every tile paints the Dim value onto Light. **Fix:** the T2 gesture is an explicit dial or token choice; the no-reload gate is a closure the server classified `live`. State the `prefer mode` value as Tamber's `dark-style=dim` (`llp/1121-tamber.rfc.md:967-969`), not `prefer mode dark-style dim`.

**9. D6 — three edit promises still outrun the bytes.** A shorthand is "edited as the shorthand or refused" (`llp/1122-design-tool.rfc.md:399`); pick one: the control edits the shorthand's value, labelled as the shorthand. Claim a one-line diff only when fmt changes no other line. `commit` includes the `.contract` files the session changed, not only `.tamber` files. On wasm tiles a rebuild also drops focus (`llp/1007-web-host-v1.spec.md:497-498`); the JS checkpoint is the path that restores it (`host/web-js/checkpoint.js:59-75`).
