1. **[Major] A computed comma prevents literal animation names from being scoped.** [scope.rs:1001](contract/syntax/src/scope.rs:1001).  
   Root and `ui.contract` declare different `keyframes spin` and `keyframes pulse`; root imports and renders the library’s `Card`. Card contains:
   ```contract
   state sep = ","
   view
     view animation=`spin 1s ${sep} pulse 1s`
   ```
   The reader models an interpolation as zero or one slot, never an animation separator. It therefore finds no accepted reading: `spin` occupies the name slot and `pulse` becomes an impossible second name. Neither literal is rewritten, although the library’s declarations become `spin__ui` and `pulse__ui`. The actual string, `spin 1s , pulse 1s`, is valid and plays **the root’s animations**. Both that literal and the template pass the retained compiler’s downstream checks.

2. **[Major] Importing a function under an alias can turn its call into a compiler intrinsic.** [scope.rs:794](contract/syntax/src/scope.rs:794), [sources.rs:516](contract/cli/src/sources.rs:516).  
   `ui.contract`:
   ```contract
   fn pending(n: number): number = n
   ```
   Root:
   ```contract
   use pending as identity from "./ui.contract"
   component App
     view
       text `${identity(1)}`
   ```
   No collision forces `pending` to be renamed: the root calls `identity`, so the intrinsic-capture check does not detect it. Rescoping changes `identity(1)` into `pending(1)`. The checker then interprets it as the resource-status intrinsic and returns `type-pending-argument`. The retained compiler confirms that resulting program fails, while giving the function a safe internal name succeeds. Aliasing must preserve declaration identity across intrinsic spellings.

3. **[Minor] The cycle guard misses cycles formed by several automatic repairs.** [uses.rs:72](contract/cli/src/sources/uses.rs:72).

The proposed repairs must be checked together.
