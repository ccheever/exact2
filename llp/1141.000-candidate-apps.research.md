# LLP 1141.000: A hundred candidate apps to port

**Type:** Research
**Status:** Draft, 2026-10-23. Not reviewed. Charlie chooses the pilot from §4 (LLP 1141 §10, question 6).
**Systems:** None. It is the portfolio LLP 1141 §6 draws from.
**Author:** Claude (Opus 5.5) for Charlie Cheever
**Date:** 2026-10-23
**Related:** LLP 1141 (the method: §3 the criteria, §6 the matrix and the pilot); LLP 1054 and 1114 (Bluesky, already ported); `~/projects/euxy-compare/` (euxy, already ported).

## Summary

A hundred open-source apps that a coding agent could port to Exact under LLP 1141, each
checked on the web on 2026-10-22. Each row gives the original's stack, licence, stars, last
commit, a size estimate, what it needs as a backend, and the mechanisms it exercises. They
are grouped by the original's stack:

| Group | Rows |
|---|---|
| Expo and React Native | 18 |
| React web and Ionic React | 10 |
| React desktop (Electron, Tauri) | 6 |
| Apple native (SwiftUI, UIKit, AppKit) | 31 |
| Android native (Compose, Views) | 26 |
| One organisation on several native platforms | 9 |

Section 2 lists apps on a shared backend, which can replicate one another. Section 3 counts
coverage against LLP 1141 §6's matrix. Section 4 proposes the pilot.

## 1. How the list was made

Four research agents read GitHub, READMEs, F-Droid and the projects' sites on 2026-10-22:

- one over seeds across every stack;
- three each over one stack: Apple native, Android native, and React and Expo.

None cloned anything. Stars, licence and last commit come from the GitHub API, the last commit
from each default branch. Public backends marked as reachable were checked with one request.

**Size** is an estimate, not a count: the source bytes in the repository's tree divided by
32–40 bytes a line. Tests, generated code and vendored code were excluded where the tree made
that possible. Read it within ±50%:

| Size | Lines |
|---|---|
| S | under 10k |
| M | 10–50k |
| L | 50–200k |
| XL | over 200k: a slice only |

**Backend:**

| Value | Meaning |
|---|---|
| none | Local data, bundled data or fixtures |
| public API | A public read API, no key |
| key | A free key or token is needed |
| demo | A public demo server (Jellyfin's, Navidrome's, Grocy's) |
| container | A self-hosted backend in Docker |
| account | A free account on the vendor's service |

LLP 1141 §8 forbids a volunteer-run server as a backend. A Mastodon, Lemmy or nostr client
marked "public API" is ported against a local container or recorded fixtures.

**What was merged and cut.** About 170 candidates came back. They were brought to 100 as
follows:

- One organisation's apps on several platforms became one row (§1.6).
- Of near-duplicates, the better-kept app stayed (Read You over Capy Reader and Feeder,
  Aegis over 2FAS).
- Apps were dropped that need a real person's account or a paid key, are archived, are a
  WebView shell, or are a tutorial (§5).

**What is unverified:**

- every size;
- the UI framework where a row says "mixed";
- Amperfy's demo login and Artsy's open-source setup;
- whether each `xcodebuild` or `gradle` build succeeds as the README claims.

LLP 1141 §4.0 builds an original before choosing its slice, which is where each of these is
settled.

## 4. A pilot to choose from

LLP 1141 §6 asks for a native original, an Expo or React Native original, a deep app, and
one app held back as a transfer check. The proposal:

| Role | App | Why |
|---|---|---|
| Expo original | **React Conf app** (#1) | Expo's own current practice (SDK 54, Expo Router, `@expo/ui`, Liquid Glass) at euxy's first size, with bundled data. It tests what Expo considers its best, on iOS first |
| Native original | **Hackers** (#37) | Idiomatic SwiftUI with Dynamic Type and VoiceOver done carefully, on a keyless public API. Its feed and nested comments are one session. Harmonic (#77) gives the Android reference on the same API later |
| Deep app | **Pocket Casts** (#92), the podcast page and player | A commercial app with two native originals, background audio, media clocks and downloads: the depth that produced LLP 1125 for euxy. iOS builds without secrets |
| Held back | **NetNewsWire** (#36) | Lists, panes, adaptive layout and background refresh: the pilot's mechanisms in a different app, unseen until the pilot's fixes land |

There are two alternatives:

- **Web original.** Swap Hackers for **Actual Budget** (#22) if the pilot should include a web
  original. Its tables, money and charts are rows no other pilot app covers.
- **A smaller deep app.** Swap Pocket Casts for **Loop Habit Tracker** (#71). It has custom
  charts, widgets and reminders against an Android original, at a third of the size.
