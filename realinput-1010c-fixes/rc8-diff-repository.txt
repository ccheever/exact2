Verdict: a lane artifact, not a clone bug. With HOME set to <lane>/home and the project at <lane>/projects/work, T3 Code
refuses the project and diffs whatever repository holds the lane home. In a normal launch (HOME = the account's home,
projects under it) the project is inside the root and its own repository is diffed. Next session: keep the project
inside the lane HOME (e.g. <lane>/home/projects/work) or leave HOME alone for this row.
