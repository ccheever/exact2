# Triage labels

Use these names in Linear's Engineering team and on GitHub framework escalations.

| Role | Label | Meaning |
| --- | --- | --- |
| needs-triage | `needs-triage` | Needs evaluation |
| needs-info | `needs-info` | Needs missing evidence or a reporter answer |
| ready-for-agent | `ready-for-agent` | Bounded brief and acceptance checks are ready |
| ready-for-human | `ready-for-human` | Needs a human decision, access or implementation |
| wontfix | `wontfix` | Will not be implemented |

Use exactly one triage-role label on a triaged issue. Preserve unrelated labels.
Linear's status tracks execution; these labels track readiness. Use the tracker's
existing category labels for bugs and improvements. Do not invent synonyms for
the five role labels.
