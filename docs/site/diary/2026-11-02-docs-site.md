### Rough

- Text hidden from sight but kept for agents and screen readers (the usual `clip: inset(50%)`
  pattern): `clip-path` takes only `none` or `path()`, and `width=1` warns `lower-text-px-width`.
  A `0.0625rem` box with `overflow="hidden"` hides it with 0 warnings.
- A deep link opened with the navigation stack [home, page], and `for e in stack(nav)` drew both
  pages: two h1 elements, and 5.11 MB of prerendered HTML. `stack(nav).slice(-1)` draws only the top
  one (3.26 MB). A test for the trailing-slash redirect had passed only because it found the stale
  page underneath.
- The web CSS underlines a link on hover and focus when its children are only text or images
  (LLP 1115.000 item 14). Sidebar, rail, card and footer links showed a blue underline. Wrapping
  each link's children in a `row` or `column` stops it; nothing in the guides names the rule.
- The compiler warned `lower-list-beside-fixed` for the iOS lowering of the route column.
  `navigationBar="none"` on the column clears it.
- The runtime applies persisted state at idle, so a stored dark theme or hidden sidebar showed a
  frame late. `tools/postbuild.ts` injects a script before first paint that reads the same
  `exact.state.*` keys.
- `bun exact.mjs verify` reports "refused adopt" on a URL with a trailing slash (`serve`'s
  directory index) and "relaunch lost" (the cause is not found yet).
- Each icon use stores its SVG path twice (`data-symbol-path`, `data-symbol-source`): 15,424 B
  of `app.js`, 354 B gzipped.

### Lean in

- `render=build` routes prerender every page, so the site is static files for any host.
- The `head` element sets the title, description and 404 status per route.
- `-exact-layout-transition` animates the sidebar and page width with one property.
