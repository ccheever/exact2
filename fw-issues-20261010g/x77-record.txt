Host code (main): MouseEventsMac.swift dispatchContextMenu runs a NodeView's own contextmenu/contextPopover only;
NodeViewMac.swift rightMouseDown calls it on the paragraph's view. A run is not a view: inlineTarget(at:handler:) is
asked for 'press' (mouseUp) and 'hover' (mouseMoved), never 'contextmenu'.
