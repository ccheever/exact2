Found and fixed in this session (7fe081148)
- Before the fix, on the build of 5752b7be2 (10:53Z and 11:00-11:03Z), the sidebar press did not close a pinned
  popover. The window counted the press ("pointerdown view 1 (outsidePressDown#1)", "pointerup view 1
  (outsidePressUp#1)"), but while the pointer crossed the sidebar's resize handle (sidebar-resize, x 247-263) on
  its way to the sidebar, each move gave the handle an enter and then a usage segment's hover an enter again
  ("hover in view 1306 (sidebarHover)", "hover out view 1306", "hover in view 1130 (enterSeg#7408)", five times).
  The last event before the press was the segment's enter, so the hover-opened state kept the popover. Base UI's
  outside press closes a popover however it opened, so the Usage page now keeps the hover only while the
  window's outside-press count is the one at its last enter. On 7fe081148 the same press closes it.
