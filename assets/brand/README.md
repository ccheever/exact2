# Exact brand assets

[`exact-mark.svg`](./exact-mark.svg) is the canonical designed mark for Exact. Its 161.803:100 outer geometry is a golden rectangle; the divider at x=100 partitions it into a square and a reciprocal golden rectangle.

The SVG uses a portable mid-neutral stroke that remains legible on light and dark surfaces. Consumers may tint the monochrome mark for their context, as the Exact Guide does. Preserve its view box, geometry, rounded stroke treatment, and accessible title when deriving other formats.

The Exact Guide keeps an inline adaptation in `js/src/guide/lib/icons.ts` because Contract's `svgSource` API currently consumes SVG markup. That mirror should remain geometrically identical to this asset.
