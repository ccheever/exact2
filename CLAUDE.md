# Agent instructions

**Building an app with Exact rather than working on it?** This checkout is the version to use:
Exact has no releases, tags or npm package, and an app uses the checkout by path. Make it with
`bun scripts/exact.mjs new <path>` and read `docs/start-here.md`, or for a website
`docs/start-here-site.md`: it is the only required reading (LLP 1115 D7). Nothing else here is for you: `AGENTS.md`, imported below, is for work
on exact2 itself.

**Working on exact2 itself:** `AGENTS.md` is the instructions (Claude Code loads it through the
import; other agents read it as their own file).
