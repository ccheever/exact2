with no node about 45 bytes; the final design adds no handler site (the mailto/fragment link reuses the link node and its
menu, the code span reuses the link node and the web link's later-word handler, now a box holding the word or the code span)
and three nodes per FlowRuns use (two code-span texts and that box).

RL-3 is +121.5 KB, over the record's "about 100 KB" and under its 300 KB ceiling, so it is built. A cheaper shape that leaves
a code span out of the link node (the link node holding only the favicon, the code span the web link's pressable box after
it) would save one node per use but leaves a link that starts with a code span as a favicon-sized link (or an empty one for
a mailto link); not built.
