# Extra Heavy feed — the exact2 app

The Extra Heavy feed (`../SPEC.md`) on exact2, bundle `dev.exact.xheavy.exact2`, built against the
checkout this directory is in (the Cargo paths and `app.json`'s `$schema` are relative to it). One app
serves iOS, macOS (`../mac/`) and the web (`../web/`). All 19 kinds are built (the nested `filmstrip`
and `inbox` since LLP 1070 stage 4, origin/main `50a00477`).

| path | what |
|---|---|
| `app.contract` | the screen: one `list virtualized=true`, one keyed `each`, a header and one body per kind |
| `svgs.contract` | generated: the 48 SVG files as components, SVGR style (`gen-svgs.py` from `../data/svgs.json`) + `Icon` / `Chart` / `Art` by name |
| `rings.contract` | generated: the live row's ring and its 101 keyframes (`gen-rings.py`) |
| `lottie.contract` | the four Lottie files ported by hand to SVG + `@keyframes` |
| `data/` | the DataSource: `feed()` (not baked: asked at launch before the first frame, with BENCH_KINDS applied; the rows, the shared inner-list indices and the inbox's message pool; the parsed JSON rows are dropped once the row values exist), `config()`, `draft(id, text)`, `toggle(id, epoch, open)`; the canvas row's Canvas 2D drawing (`canvas.rs`); Markdown → runs (`md.rs`). `feed.json` and `motion-0N.json` beside it are generated copies |
| `gpu/` | the shader row's GPU surface `wave(photo, duoA, duoB, freeze)` (WGSL in `shaders/`) |
| `apple/` | the static library; `build.rs` compiles and bakes the plan |
| `web/` | the web host's crate (the web pair only) |
| `modules/apple/NativeMap.swift`, `modules/web/index.js` | exact2's `apps/map-demo` module, copied (modules live in the app), plus `interactive="false"` |
| `assets/`, `icon.png` | generated by `gen-assets.py`: copies of `../data/images`, `anim`, `video`, `fonts`; `embed/` (132 × 2 pages) and `still/` (frame 0 of each GIF/WebP); the icon |

Everything marked generated, and `Cargo.lock`, comes from `../prepare.sh` and is not committed. Build from
the checkout's root (`bun install --frozen-lockfile` there first):

```sh
A=$PWD/bench/extra-heavy/exact-xheavy
EXACT_APP_DIR=$A bun host/apple/build.mjs --ios exact-xheavy-apple --run                 # a simulator (EXACT_SIM picks one)
EXACT_APP_DIR=$A bun host/apple/build.mjs --device exact-xheavy-apple --phone "$BENCH_DEVICE"
EXACT_APP_DIR=$A bun host/apple/build.mjs exact-xheavy-apple --bundle                    # macOS
```

The benchmark builds are signed archives with the probe embedded: `../ios/build-exact.sh` (iOS) and
`../mac/build-exact.sh` (macOS). `../web/build.sh` builds the web pair.

## How each kind is written

| # | kind | exact2 |
|---|---|---|
| header | | `image … border-radius=18 object-fit="cover"`, nowrap/ellipsis texts, `text-transform="uppercase"` on the kind; `rel()` a Contract `fn` over the 1 Hz `secs` |
| 1 | photo | `image width="100%" aspect-ratio=max(w / h, 0.8) object-fit="cover" border-radius=12` (the 1.25 C cap as a minimum aspect) |
| 2 | thumbs | three `row gap=4` of four `flex=1 aspect-ratio=1` cells; images `animation="fadeIn 200ms linear 1200ms both"`; the skeleton an absolute `linear-gradient` band with `animation="shimmer 1000ms linear infinite"` under a wrapper that plays `skeletonOut … 1200ms both`. Animations start at mount, which is when a row appears |
| 3 | shader | `canvas surface=wave(photo, duoA, duoB, freeze) aspect-ratio=16/9 border-radius=12 overflow="hidden"`: the GPU module asks for the JPEG (`assets` → `asset`), decodes it off the main thread to ≤ 1200 px, keeps 8 textures, samples it through the wave and duotone every frame |
| 4 | canvas | `canvas surface=card(k) height=220 border-radius=12`: Canvas 2D in Rust (`draw_2d`) — `roundRect` + `createLinearGradient`, `bezierCurveTo` with round caps/joins, `arc` under `globalAlpha 0.6`, `drawImage` clipped to an `arc`, `fillText("600 20px system-ui")` |
| 5 | svg | inline `svg` components generated from the files (`Icon(name)`, `Chart(name)`, `Art(name)`), sized by the box around them |
| 6 | video | `video autoplay muted loop playsinline controls=false paused=freeze object-fit="cover"` in a rounded clipping box, the `0:04` pill absolutely positioned |
| 7 | map | `native-map latitude longitude span=0.02 pins="p|lat|lon|place" interactive="false"` in a rounded clipping box |
| 8 | markdown | parsed in the DataSource into blocks of runs (`md.rs`), laid out as nested `text` (h2 20/600, p 16, `•` lists 4 apart, quote with a 3 pt `border-left`), code runs in Space Mono 14 on #F2F2F7, links #007AFF |
| 9 | code | one `row height=20` per line: the number (Space Mono 13, right-aligned 24 wide), then `text white-space="pre"` holding one coloured run per token; the card's `overflow="hidden"` clips |
| 10 | intl | `text direction=(rtl ? "rtl" : "ltr") text-align="start"`, platform fallback |
| 11 | typeface | ten declared `font` families; the family chosen per row by a literal ternary |
| 12 | carousel | a nested horizontal virtualized list (`list virtualized=true display="flex" flex-direction="row" height=170 estimated-item-width=150 scroll-restoration="manual"`), ten cards with `margin-right=10` (gap is refused on a list); a recycled row starts at its first card, so the kept position is opted out |
| 13 | motion | `image` of the GIF and the WebP (they animate natively), and `Lottie` — the Bodymovin file ported to SVG shapes with `@keyframes` on `cy`, `rotate`, `scale` + `opacity`; frozen: first-frame stills and paused animations at 1 s |
| 14 | glass | `backgroundMaterial="ultra-thin"` (the system material, as SwiftUI's `.ultraThinMaterial`) on the bar and the capsule, over an `image` |
| 15 | live | the 1 Hz `secs` drives `Updated`, the countdown and `0:0X`; rings are SVG circles with `pathLength=1` and a per-base `@keyframes` on `stroke-dashoffset` (phase by negative delay); the playhead is a clipping window and its content translated against each other in `steps(48, jump-start)` over 12 s |
| 16 | thread | `line-clamp=(open ? 0 : 3)` in a box whose `height` moves between `54px` and `auto` with `interpolate-size="allow-keywords" transition="height 250ms ease-in-out"`; expansion and the draft live in the DataSource keyed by row id (`toggle`, `draft`), `input value=… change=setDraft(id)` |
| 17 | webview | `iframe src="assets/embed/<id>[-paused].html"` in a bordered rounded clipping box (no `srcdoc`) |
| 18 | filmstrip | a nested horizontal virtualized list over the feed's shared 2,000 indices (`height=136`, `estimated-item-width=120`); each item computes its image and caption from the row's `img0`/`imgStep`/`num0`; the offset is kept across the row's retirement by the runner (LLP 1070 Q1 default) |
| 19 | inbox | a nested vertical virtualized list (`height=399` in a bordered 400 pt box, `estimated-item-height=63`) over the shared 1,000 indices; message j is found in the 997-message pool with `first(filter(pool, p => p.i == …))` (Contract has no list indexing); the offset is kept by the runner |

Freeze, live and start index come from `config()` on a 1 ms `after` at mount. BENCH_START_INDEX
is `scrollIntoView("feed", key)` (LLP 1070.000) 400 ms after mount; `config()` names the key of the
n-th row as the list shows it. BENCH_KINDS (`17`, or a kind list for the per-kind breakdown) filters
the feed the launch asks for, so the first frame is already the filtered feed, as in SwiftUI's app.
