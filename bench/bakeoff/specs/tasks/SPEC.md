# Tasks

An iPhone to-do app with lists.

Data: `data/tasks.json`, 180 tasks (`id`, `list`, `title`, `due`, `done`, `priority`, `notes`) in six lists. Ship them.

1. The main screen shows the lists with how many open tasks each has, plus Today (due today or overdue) and All.
2. A list's screen shows its open tasks, then its completed ones in a collapsible section. Tapping a task's checkbox completes or reopens it.
3. Add a task to a list with a title, optional due date, priority and notes. Edit a task by tapping it.
4. Overdue due dates are marked; high priority is marked.
5. Reorder tasks within a list by dragging; delete with a swipe.
6. Create, rename and delete a list.
7. Everything survives relaunching the app.
