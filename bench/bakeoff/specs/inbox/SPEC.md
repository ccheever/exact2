# Inbox

An iPhone mail inbox (no sending or network).

Data: `data/mail.json`, 320 messages (`id`, `from`, `subject`, `preview`, `at`, `unread`, `flagged`). Ship them.

1. The inbox lists messages newest first: sender, subject, a two-line preview and the time or date, with unread messages marked.
2. Swipe a message to archive it, or the other way to mark it read or unread. Archived messages move to an Archive screen.
3. Flag and unflag messages; a filter shows only unread or only flagged messages.
4. Tap a message to read it; opening marks it read.
5. Pull to refresh adds two new messages at the top (made up locally).
6. The unread count is shown.
7. Read, flagged and archived states survive relaunching the app.
