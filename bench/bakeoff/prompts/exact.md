# Your toolkit: Exact

Build it with Exact. Your working directory is an Exact app that `exact new` made: start with its `AGENTS.md`, which
says where the guide is and how to build, test and drive the app. Set `app.json`'s name and id to the ones above
before the first build. Exact's own commands pick their own ports. Build for the iPhone with
`EXACT_SIM={SIM}` set, or `--sim {SIM}`, and leave the finished app installed there (`bun exact.mjs ios`).
