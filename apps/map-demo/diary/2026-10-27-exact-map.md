## Rough

- A list of records written as `[{ id: "ferry", latitude: … }]` failed with
  "expected an expression, found `{`". Contract builds a record by calling its
  shape: `MapMarker(id="ferry", latitude=37.7955, …)`. The error names handlers
  and plain values but not the shape call, which is the fix for a record
  (`docs/contract-grammar.md`, "Construct a record"). About 10 minutes.
- The map's `zoom` prop was refused: "`zoom` belongs to `iframe`, not
  `exact-map`; … give the module prop another name". CSS `zoom` is a property
  Contract knows, and LLP 1024 D1 binds a known name to the box. The package's
  prop is now `zoomLevel`; the camera that `moveend` reports keeps `zoom`. The
  message said what to do. About 15 minutes, most of it renaming the prop in
  the three implementations.

## Lean in

- The package's view takes the markers as a typed list prop, so the app passes
  `markers=stores` with no string encoding (the old module read
  `pins="id|lat|lon|title"`).
- `moveend` hands the app a typed `MapCamera`, so the zoom buttons start from
  where a pinch left the map.
