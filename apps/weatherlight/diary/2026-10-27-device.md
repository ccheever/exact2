## Rough

The web page never read the device. The document Weatherlight renders at build carried the render's answers to
`powerState()` and `connection()`, which were the declaration's defaults, and the page treats a document's answer
as settled: it never asked Chrome, so `saveData` could not slow the refresh. A rendered document now carries no
module name's answer (`runner/src/runner/checkpoint.rs`).

On the web under the agent, a read the declaration marks unsupported (`powerState`) refused the whole boot instead
of failing its resource. LLP 1133.025 D14 fixed the same on main while this was built (`host/web-js/modules.js`).

## Lean in

`prefer extension device.powerState={"lowPowerMode":true}` set each fact in a drive; the agent's clock made the
ten- and thirty-minute refreshes a matter of `clock +600000`.
