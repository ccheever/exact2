## Rough

- `task prepareIdentity mount` with `send nonce = identityNonce()` as its
  body failed `contract-task-body`: a task's body is `after(ms, action)`
  and friends, never a send. Moved the send into an action the task runs
  `after(1, …)`. The message named the forms. About 2 minutes.
- A `state offering` collided with the existing `derive offering`
  (`type-duplicate-name`); renamed. The message named both lines.
- `exact-sign-in-button provider="apple"` failed `contract-view-prop`:
  a package view's prop declared `enum<apple|google>` takes no string
  literal, so the package declares it `string`. Fixed in exact2 (the
  package's declaration). About 5 minutes.
- Calling `preventSilentAccess()` from the synchronous `signOut` answer
  needed the answer made async so the call is awaited.
