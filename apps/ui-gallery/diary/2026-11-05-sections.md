# UI Gallery sections

## Rough

The iOS host has no general Split View projection. The existing native `tabContainer` hatch accepts the app's route stacks, so this gallery can use UIKit's split controller without adding a framework navigation mode.

The web verifier built successfully but its driver looked for a receipt in another output directory. Explicit `EXACT_APP_DIR` and `EXACT_WEB_DIST` made the build and driver agree; the interaction test then passed.

## Lean in

The native sidebar groups typography and text colors, color profiles and images, and UI/media specimens. Each category has a route and scroll node. UIKit owns sidebar disclosure, compact navigation and column sizes. The browser keeps authored tab navigation. All existing specimens remain reachable.

## Needed

The partition changes the gallery's workload: the global sticky range card and its per-offset authored scroll callback become ordinary range controls inside relevant sections. Do not attribute a change in scrolling to the text renderer without a matched layout comparison. Text and effects toggles have independent state; off-category videos pause.

## Checkpoints

The authored browser test passes across all nine sections. Native simulator screenshots confirm the grouped UIKit sidebar; native v1 recorder and span-ring tests pass. AppDrop revision 3 serves development build `202611050220`, with a verified signature and matching symbols. The standalone real-touch Back/rotation test could not load `_Testing_Foundation.framework`, so it did not exercise those flows.
