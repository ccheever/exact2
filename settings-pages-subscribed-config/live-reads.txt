# settings-pages-subscribed-config: server reads per Settings page, before vs after vs reference (2026-10-10, agent mode / CDP)

Lanes (target/t3-audit, base port 16200): clone = the app's embedded server on 127.0.0.1:16202 (A/clone-drive.sh, --storage audit-<lane>),
reference = T3 Code 1e2ecbd975 Electron (A/ref-app.sh, backend 16200, CDP 16201). Before = the never-edited evidence-base build at 950e8e2e5
(lane settings-pages-subscribed-config-before); after = this branch (lane settings-pages-subscribed-config). Same steps on all three: open
Settings, then each page for 3 s + 30 s while renamer.sh renames the lane project every 7 s through `t3 project rename` (a shell
stream event: the clone's `data` drains, data.revision moves and every open page is asked again). count.mjs counts the lane server's
ws.rpc spans (userdata/logs/server.trace.ndjson) that start inside each window (the screenshots' write times). server.reportClientActivity
(the app's own activity report) is left out of the read columns. The diagnostics process/trace/resource-history reads are not traced as
ws.rpc spans by this server, on either app.
